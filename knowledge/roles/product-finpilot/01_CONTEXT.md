# Контекст: Продакт-менеджер в FINPILOT

## Продукт

FINPILOT — алгоритмическая СППР по личным финансам для рынка РФ. Не пассивный
трекер: активно распределяет свободный денежный поток между погашением долгов,
резервом ликвидности и целями. Двойная роль — бакалаврская ВКР (защищена
23.05.2026, НИТУ МИСИС) и production SaaS с релизом осенью 2026. Планка
качества — уровень Т-Банка, Сбера, Альфы: функционал, соответствие 152-ФЗ,
безопасность, надёжность.

## Стек и окружение

FastAPI · SQLAlchemy 2.0 · Alembic · Pydantic v2 · Jinja2 + vanilla JS (уезжает
на React+TS по ADR-001) · PostgreSQL/SQLite · Python 3.12 · Docker.
Репозитории: `personal-finance-dss` (приватный) + `finpilot` (публичное зеркало).
Разработка ведётся с четырёх аккаунтов, синхронизация — `docs/WATCHLOG.md`.

## Математическое ядро

Канон — **v3.5.0** (`docs/math_model_v3_5_0.md`), и только он: SAW-свёртка,
Avalanche-фильтр долгов, SES + Монте-Карло, 5 риск-профилей, 66 альтернатив
(шаг 10%), жёсткие инварианты Rt ≥ 0 и ПДН ≤ 0.40. Ликвидность stock-based:
Lt = B_liq / Σe. Версия v2.x запрещена к использованию.
Ядро прошло пять раундов независимой экспертной сертификации; оценка по десяти
шкалам — 85.7/100 (`docs/model/model_quality_scorecard.md`).

## Что уже решено и не переоткрывается

- Шаг решётки 10%, |A| = 66 — ADR-008, замерено против 5%.
- Порядок вех: бэк → организация → тестирование → юр → фронт → деплой.
- Фронтенд-стек React + TypeScript — ADR-001.
- Калибровка модели только по предзарегистрированной гипотезе.
