# Журнал работы юриста FINPILOT

## Что сделано

1. **Полный юридический разбор продукта** — 14 вопросов по 6 блокам: статус и форма регистрации, персональные данные (152-ФЗ), финансовое регулирование, кибербезопасность, монетизация, мобильные сторы. Вывод: ЦБ-лицензия не нужна, основной трек — 152-ФЗ.
2. **Разбор рисков де-факто** — неуведомление РКН (для физлица мелочь, часто предупреждение); бот РКН (цепляет по трафику и жалобам, микро-сайт пока вне фокуса); пороги штрафов по числу субъектов (1000); уголовка 272.1 (на хакере, не на операторе); утечка (административка на операторе даже как жертве). Разъяснено, что статус физлица сохраняется, пока сервис бесплатный; деанонимизация — отдельная ручная работа инспектора.
3. **Пакет юридических документов** (md для сайта + docx как официальный экземпляр):
   - Политика обработки ПДн (с разделом 18+, cookie, мерами защиты)
   - Согласие на обработку ПДн (с подтверждением 18+)
   - Согласие на обработку финансовых данных
   - Пользовательское соглашение (18+, «не финансовая организация», претензионный порядок, форс-мажор, дисклеймер 39-ФЗ)
   - Политика использования файлов cookie
   - Согласие на рекламную рассылку (отдельный необязательный чекбокс)
   - UI-сниппеты (баннер cookie, дисклеймер для страницы рекомендаций, тексты чекбоксов) + README
4. **Заметки и чек-лист перед запуском** — отдельный `.md`: живые действия, механика чекбоксов, риски де-факто, триггеры пересмотра, задачи на будущее.
5. **Сверка актуальности** по свежим источникам (июнь 2026) — пакет соответствует. Добавлены уточнения по логированию согласий (IP + время + версия текста) и формулировке цели в чекбоксе.

## Текущее состояние

**Пакет финальный, готов к деплою.** Плейсхолдеров нет, значения зашиты (email, дата, 18+, РФ-хранение). Единственное живое действие пользователя — завести почту finpilot.help@proton.me (если занята — взять запасную и обновить в документах).

## На будущее (не блокирует запуск; переводить в работу по триггерам)

- **Триггеры пересмотра подхода:** реальный трафик/индексация; монетизация; база >1000 пользователей; появление недоброжелателя, способного подать жалобу. При любом — выходить из «тихого физлица» (уведомление РКН и/или ООО).
- Домен + почта на домене → обновить email и адрес сайта в документах.
- Переход на ООО → меняется только блок «Оператор» (реквизиты вместо «сервис FINPILOT»); тело документов остаётся; бонус — ФИО перестаёт светиться в реестре РКН.
- Защита от утечки (РФ-хостинг + шифрование + разграничение доступа + план реагирования: уведомить РКН в 24 ч, отчёт в 72 ч). «Должная забота» снижает санкции в 2–5 раз.
- Уведомление в РКН (отложено; ~30 мин, бесплатно) — подать при росте видимости.
- Активация согласия на рассылку — когда запустится email-маркетинг.
- Платные функции — статус (самозанятость/ИП/ООО), онлайн-касса (54-ФЗ), налоги, публичная оферта с ценой.
- Мониторинг регулирования «финансовых инфлюенсеров» (обсуждается ЦБ; пока не касается).

## Технические задачи (зона команды разработки, НЕ юридические пробелы)

- Модель угроз и уровень защищённости (УЗ), меры ФСТЭК — при росте до масштаба, требующего сертифицированных средств. Для MVP не требуется.
- Независимая вычитка пакета на задеплоенном сайте — сверить, что реальные чекбоксы/формы соответствуют текстам документов. Контроль качества, не признак проблемы.
