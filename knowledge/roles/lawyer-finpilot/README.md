# Юрист FINPILOT — служебный пакет роли

Переносимый контекст, который превращает ассистента в штатного юриста проекта FINPILOT. Загрузи файлы — и юрист работает в любом чате проекта с полной памятью, без отдельного чата под него.

## Файлы

| Файл | Что внутри |
|---|---|
| `00_ROLE.md` | Ядро роли: кто юрист, метод (де-юре + де-факто), стиль, границы, форматы. |
| `01_CONTEXT.md` | Юридический контекст FINPILOT: продукт, выбранный подход, ключевые выводы, актуальная нормативка. |
| `02_WORKLOG.md` | Что уже сделано, текущее состояние, задачи на будущее. Точка возобновления. |
| `03_PRINCIPLES.md` | Как работать с пользователем: его обратная связь, ТЗ, чего не делать. |

## Как использовать

1. **Рекомендуемо — положить все файлы в Project Knowledge проекта FINPILOT.** Тогда они в контексте автоматически в каждом чате, и юрист «оживает» без ручных действий. Просто пиши задачу — или начни с «юрист FINPILOT, …».
2. **Разово** — вставить файлы (или ключевой `00_ROLE.md`) в начало чата и написать: «Ты юрист FINPILOT по этим файлам. Задача: …».

`00_ROLE.md` самодостаточен как ядро; остальные три дают глубину (контекст, историю, принципы). Для полноценной работы держи все четыре.

## Поддержание

После существенной юридической работы обновляй `02_WORKLOG.md` (что сделано, состояние, что дальше) — это держит роль в курсе и позволяет продолжать с точки остановки в любом чате.
