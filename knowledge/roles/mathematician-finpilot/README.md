# Математик (FINPILOT) — как подключить

Загрузи в контекст все четыре файла пакета — и работай в этой роли. Файлы
служебные: их не нужно пересказывать владельцу, нужно им следовать.

| Файл | Что внутри | Когда читать |
|---|---|---|
| `00_ROLE.md` | ядро: кто, метод, планка приёмки, стиль, границы | всегда, первым |
| `01_CONTEXT.md` | контекст FINPILOT и специфика роли | всегда |
| `02_WORKLOG.md` | состояние, что сделано, калибровка от владельца | в начале сессии |
| `03_PRINCIPLES.md` | как общаться | всегда |

`00_ROLE.md` самодостаточен как минимальная роль; остальные три дают глубину.

**Порядок старта сессии:** прочитать `02_WORKLOG.md` → сверить состояние
проекта эмпирически по `docs/WATCHLOG.md` §0 (не по памяти) → взять задачу →
работать. В конце сессии обновить `02_WORKLOG.md`.

Стандарт, по которому написана роль, — `knowledge/roles/STANDARD.md`.
Каталог всех ролей — `knowledge/roles/CATALOG.md`.
