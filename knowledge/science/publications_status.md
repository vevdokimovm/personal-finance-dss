## 2. Что изменилось в статье 0 при переупаковке (важно)

**Научное ядро новое** (этого не было в версии для БИ): вычислительное исследование модели на 3 профилях × 3 режима L_min выявило вырожденность исходной спецификации критериев — corr(R, L) = 0.9998 на множестве альтернатив + патология min-max нормализации → ранжирование схлопывается в «всё в резерв» при любом профиле риска. Предложена модификация: (а) критерий ресурса = прогноз R̂_{t+1} (SES-прогноз интегрирован в свёртку), (б) ликвидность по запасу (B_t + x_r)/(E + ΣP − δP), (в) **нормативная нормализация** (якоря: прогнозный CF, 6 мес BLR по Greninger, D_max = 0.4 ЦБ) вместо выборочного min-max. Результат: монотонная дифференциация по профилям риска (консервативный → резерв, активный → цели, агрессивный → цели + досрочка 19%-кредита; ипотека 8.5% корректно отсечена OCR-фильтром), устойчивость 8/8 (B) и 6/8 (C, граничные флипы ΔU < 0.007), fail-loud на закредитованном профиле сохранён. Цикл < 2 мс.

**Синхронизация цифр:** опрос везде 385/322, 10%/63%/84% (как в статье 1). Формулы согласованы (устранено противоречие R = B + CF − ΣP против расчётного примера в старой рукописи).
