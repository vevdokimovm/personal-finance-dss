# __Этап 1\. Установить Python__

Python — это программа, без которой моё приложение работать не будет\. Устанавливается один раз\.

__1\.1__

__Открой браузер__

Найди на рабочем столе или в нижней панели иконку браузера и кликни по ней два раза\.

- __Google Chrome__ — цветной круглый значок \(красный, жёлтый, зелёный, синий\)\.
- Если Chrome нет — подойдёт __Microsoft Edge__ \(синяя волна\) или __Яндекс Браузер__ \(красная Я\)\.

__1\.2__

__Зайди на страницу скачивания Python__

В самом верху браузера, в длинной белой строке \(там где обычно набираешь адреса сайтов\), кликни один раз левой кнопкой мыши\. Сотри всё, что там написано, и набери:

__python\.org/downloads/windows__

Нажми клавишу «Enter» \(большая клавиша справа на клавиатуре\)\.

__✓  ОТЛИЧНО__

Откроется страница со списком версий Python\. Заголовок будет «Python Releases for Windows»\.

__1\.3__

__Скачай нужную версию__

На странице найди заголовок:

__Python 3\.12\.10 \- April 8, 2025__

Под ним будет несколько строк со ссылками\. Кликни левой кнопкой мыши по этой:

__Windows installer \(64\-bit\)__

Внизу браузера или в правом верхнем углу появится плашка о том, что файл скачивается\. Подожди несколько секунд\.

__ЕСЛИ НЕ МОЖЕШЬ НАЙТИ ЭТУ ВЕРСИЮ__

На странице много версий\. Они идут списком сверху вниз\. Прокрути страницу колёсиком мышки вниз, пока не увидишь именно «Python 3\.12\.10»\. Не более новую и не более старую — именно эту\.

Если её всё\-таки нет, подойдёт любая версия начинающаяся с «Python 3\.12\.» — например, 3\.12\.9 или 3\.12\.11\.

__1\.4__

__Найди скачанный файл и запусти его__

Файл называется примерно так:

__python\-3\.12\.10\-amd64\.exe__

Найти его можно одним из двух способов:

- __Способ 1: __в правом верхнем углу браузера кликни на стрелку «вниз» \(значок «↓»\) — увидишь список скачанных файлов\. Кликни по нужному\.
- __Способ 2: __открой папку «Загрузки» \(или «Downloads»\)\. Для этого нажми внизу слева иконку в виде __жёлтой папки__ \(если её нет — слева на экране найди значок «Проводник», он похож на жёлтую папку с синим зажимом\)\. В открывшемся окне слева кликни «Загрузки»\.

Найдя файл, кликни по нему два раза левой кнопкой мыши\.

__ЕСЛИ ЧТО\-ТО ПОШЛО НЕ ТАК__

Если Windows спросит «Вы хотите разрешить этому приложению вносить изменения?» — нажми «Да»\.

__1\.5__

__Установка Python — самый важный шаг__

__⚠  ВНИМАНИЕ — ОЧЕНЬ ВАЖНО__

__ВНИМАТЕЛЬНО ПРОЧИТАЙ, ПРЕЖДЕ ЧЕМ НАЖАТЬ__

Откроется голубое окно установки Python\. На этом окне внизу есть две галочки\. Тебе обязательно нужно поставить галочку напротив надписи «Add python\.exe to PATH» \(или «Add Python to PATH»\)\. Она находится в нижней части окна\.

Без этой галочки приложение НЕ ЗАПУСТИТСЯ потом\. Это самая частая ошибка\. Проверь два раза\!

Что делаешь по шагам:

__1\.  __Видишь внизу окна квадратик с надписью «Add python\.exe to PATH»\. Кликни в этот квадратик один раз — внутри него должна появиться галочка ✓\.

__2\.  __Убедись, что галочка действительно стоит — квадратик должен быть синим с белой галочкой внутри\.

__3\.  __Только после этого кликни большую синюю кнопку «Install Now» в верхней части окна\.

__4\.  __Дождись, пока полоска заполнится до конца\. Это займёт 1–3 минуты\.

__5\.  __Когда появится надпись «Setup was successful» — нажми кнопку «Close» внизу справа\.

__✓  ОТЛИЧНО__

Python установлен\. Окно установки закрылось\.

__ЕСЛИ ЗАБЫЛА ПОСТАВИТЬ ГАЛОЧКУ__

Не страшно — просто запусти файл python\-3\.12\.10\-amd64\.exe заново и в этот раз обязательно поставь галочку\. Установится поверх, ничего не сломается\.

Теперь нужно скачать с интернета сам код моего приложения\.

Откроется страница с моим проектом\. Сверху будет название «vevdokimovm / personal\-finance\-dss», ниже — много файлов и папок\.

__2\.2__

__Скачай архив с приложением__

Чуть выше списка файлов, справа, найди __зелёную кнопку с надписью «Code»__\. Кликни по ней один раз левой кнопкой мыши\.

Откроется маленькое окошко с несколькими строками\. В самом низу этого окошка будет:

Кликни по этой надписи один раз\.

__✓  ОТЛИЧНО__

__2\.3__

__Найди скачанный архив__

Открой папку «Загрузки» — точно так же, как в шаге 1\.4:

- Кликни внизу экрана на жёлтую папку \(«Проводник»\)\.
- В левой колонке нового окна найди и кликни «Загрузки»\.

Среди файлов справа найди:

__personal\-finance\-dss\-main\.zip__

У этого файла будет иконка в виде папки с молнией — это «архив», его нужно распаковать\.

__2\.4__

__Распакуй архив__

__1\.  __Кликни по файлу personal\-finance\-dss\-main\.zip ОДИН раз ПРАВОЙ кнопкой мыши \(не левой\!\)\.

__2\.  __Появится меню\. Найди в нём строку «Извлечь всё\.\.\.» \(по\-английски — «Extract All\.\.\.»\)\. Кликни по ней один раз левой кнопкой\.

__3\.  __Откроется окошко\. Внизу справа будет кнопка «Извлечь» \(или «Extract»\) — кликни её\.

__4\.  __Подожди несколько секунд\. Откроется новое окно с папкой personal\-finance\-dss\-main внутри\.

__ЕСЛИ В МЕНЮ ПО ПРАВОЙ КНОПКЕ НЕТ «ИЗВЛЕЧЬ ВСЁ»__

Найди в меню строку «Показать дополнительные параметры» — кликни её, появится развёрнутое меню\. «Извлечь всё\.\.\.» будет там\.

На Windows 10 эта строка обычно сразу видна, на Windows 11 — иногда спрятана\.

__2\.5__

__Перенеси папку в «Документы»__

Зайди внутрь только что появившейся папки\. Внутри ты увидишь ещё одну папку с таким же именем — personal\-finance\-dss\-main\. Вот именно её и надо перенести\.

__1\.  __Кликни по этой внутренней папке personal\-finance\-dss\-main один раз ЛЕВОЙ кнопкой мыши — она подсветится синим\.

__2\.  __Зажми на клавиатуре клавишу «Ctrl» \(внизу слева\) и, не отпуская её, нажми клавишу «X» \(буква\)\. Затем отпусти обе\.

__3\.  __В левой колонке окна найди и кликни «Документы» \(или «Documents»\)\.

__4\.  __Кликни в большое белое пустое поле справа один раз правой кнопкой мыши\. В появившемся меню выбери «Вставить» \(или нажми «Ctrl» \+ «V»\)\.

__✓  ОТЛИЧНО__

Папка personal\-finance\-dss\-main теперь лежит в «Документах»\. Окно проводника можешь закрыть\.

# __Этап 3\. Установить дополнения для приложения__

Моему приложению нужно несколько вспомогательных программ — их тоже надо скачать\. Это делается одной командой\.

__3\.1__

__Открой «Командную строку»__

__1\.  __Кликни левой кнопкой мыши по значку Windows в левом нижнем углу экрана \(это квадратик из четырёх частей или флажок\)\.

__2\.  __Откроется меню «Пуск»\. Прямо в нём, не закрывая, начни печатать на клавиатуре буквы:

__Командная строка__

__3\.  __Сверху появится иконка с такой надписью\. Кликни по ней один раз левой кнопкой мыши\.

__✓  ОТЛИЧНО__

Откроется чёрное окно с белыми буквами\. Сверху будет написано «Командная строка»\. В окне будет строчка с твоим именем пользователя и мигающий курсор\.

__3\.2__

__Зайди в папку с приложением__

В чёрное окно надо ввести две команды по очереди\. Печатай их аккуратно на английской раскладке, потом нажимай «Enter»\.

__Команда первая:__

__cd Documents__

Нажми «Enter»\. В строке внизу должно появиться слово Documents\.

__Команда вторая:__

__cd personal\-finance\-dss\-main__

Нажми «Enter»\. В строке внизу теперь добавится personal\-finance\-dss\-main\.

__ПОДСКАЗКА__

Чтобы не печатать длинное «personal\-finance\-dss\-main» вручную, можно начать набирать «cd per» и нажать клавишу «Tab» \(над «Caps Lock»\)\. Windows сама допишет название\.

Команды можно вставить из этой инструкции: выдели команду мышкой здесь в документе, нажми Ctrl\+C, потом в чёрном окне нажми правую кнопку мыши — текст вставится сам\.

__3\.3__

__Запусти установку дополнений__

Теперь скопируй или набери в чёрное окно эту команду:

__py \-3\.12 \-m pip install \-r requirements\.txt__

Нажми «Enter»\.

Начнётся скачивание и установка\. В окне побегут строчки с надписями «Collecting…», «Downloading…», «Installing…»\. Это нормально\. Жди 2–5 минут, ничего не трогай\.

__✓  ОТЛИЧНО__

Когда увидишь в окне зелёную надпись «Successfully installed» с длинным списком названий — установка прошла успешно\. Снова появится строчка с курсором, готовая принять следующую команду\.

__ЕСЛИ ВИДИШЬ КРАСНЫЙ ТЕКСТ С ОШИБКОЙ__

Самая частая причина: ты не поставила галочку «Add python\.exe to PATH» в шаге 1\.5\. Вернись к этому шагу, поставь галочку и попробуй снова\.

Если ошибка «could not find a version» — у тебя нет интернета\. Проверь соединение\.

В крайнем случае — позвони мне, прочитай красный текст вслух или сфотографируй и пришли\.

# __Этап 4\. Запустить приложение__

Этот этап ты будешь повторять каждый раз, когда захочешь открыть приложение\. Этапы 1–3 больше делать не нужно\.

__4\.1__

__Открой «Командную строку»__

Точно так же, как в шаге 3\.1: значок Windows внизу слева → напечатать «Командная строка» → кликнуть по найденной иконке\.

__4\.2__

__Перейди в папку приложения__

Введи две команды \(нажимая «Enter» после каждой\):

__cd Documents__

__cd personal\-finance\-dss\-main__

__4\.3__

__Запусти приложение__

Теперь введи главную команду:

__py \-3\.12 run\.py__

Нажми «Enter»\.

В чёрном окне появится несколько строчек текста\. Самая важная — последняя, она будет выглядеть примерно так:

__Uvicorn running on http://127\.0\.0\.1:8000__

__⚠  ВНИМАНИЕ — ОЧЕНЬ ВАЖНО__

__НЕ ЗАКРЫВАЙ ЧЁРНОЕ ОКНО__

Это окно — теперь твой работающий сервер\. Пока оно открыто — приложение работает\. Если его закрыть \(кликнуть крестик в правом верхнем углу\) — приложение остановится, и сайт перестанет открываться\.

Просто оставь это окно открытым и сверни его \(кликни на чёрточку «—» рядом с крестиком в правом верхнем углу окна\)\.

__4\.4__

__Открой приложение в браузере__

__1\.  __Открой Google Chrome \(или любой другой браузер\)\.

__2\.  __В самой верхней длинной строке \(там, где обычно вводятся адреса сайтов — НЕ в чёрном окне\!\) кликни левой кнопкой мыши, сотри всё что там написано и набери:

__http://127\.0\.0\.1:8000/dashboard__

__3\.  __Нажми «Enter»\.

__⚠  ВНИМАНИЕ — ОЧЕНЬ ВАЖНО__

__ЭТОТ АДРЕС — В БРАУЗЕР, А НЕ В ЧЁРНОЕ ОКНО\!__

Адрес http://127\.0\.0\.1:8000/dashboard вводится только в адресную строку браузера \(Chrome\) — туда, где обычно сайты открываются\. В чёрное окно «Командной строки» его вводить НЕ НАДО\.

Если случайно ввела в чёрное окно — ничего страшного, оно выдаст ошибку, но приложение продолжит работать\. Просто перейди в браузер и введи там\.

# __Если что\-то пошло не так__

Спокойно\. Самые частые проблемы и их решения:

__Проблема: __В чёрном окне написано «"py" не является внутренней или внешней командой»

__Решение: __Это значит, что Python установился без галочки «Add python\.exe to PATH»\. Вернись к Этапу 1, снова запусти файл python\-3\.12\.10\-amd64\.exe и ОБЯЗАТЕЛЬНО поставь галочку перед нажатием Install Now\.

__Проблема: __В чёрном окне написано «Системе не удаётся найти указанный путь» после команды cd

__Решение: __Ты находишься не в той папке\. Закрой чёрное окно, открой его снова и начни Этап 4 сначала\. Проверь, что папка personal\-finance\-dss\-main действительно лежит в «Документах»\.

__Проблема: __После команды py \-3\.12 run\.py появилась красная ошибка про «ModuleNotFoundError» или «No module named …»

__Решение: __Ты пропустила Этап 3 \(установку дополнений\) или он не прошёл до конца\. Сделай Этап 3 ещё раз\.

__Проблема: __В браузере по адресу 127\.0\.0\.1:8000 пишет «Не удалось подключиться» или «This site can't be reached»

__Решение: __Чёрное окно «Командной строки» закрылось\. Запусти его снова и сделай Этап 4 с шага 4\.1\.

__Проблема: __В чёрном окне написано «Address already in use» или «порт занят»

__Решение: __Приложение уже запущено в другом чёрном окне\. Найди его на панели задач внизу и используй его\. Если не находишь — перезагрузи компьютер и начни заново с Этапа 4\.

__Решение: __Сфотографируй экран на телефон и пришли мне\. Или позвони — разберёмся вместе\. Это нормально, что с первого раза непонятно\.
