Источники — `sources_registry.md`, разделы 2 и 3.

## Часть I. Skills, Connectors, Plugins

### 1. Два разных каталога, которые путают

- **Маркетплейс Claude Code** — плагины для терминала: `frontend-design`, `playwright`,
  `chrome-devtools`, `typescript-lsp`. Ставятся на машине разработчика.
- **Directory внутри claude.ai** — три вкладки Skills / Connectors / Plugins, работают прямо
  в чате и Проекте, без терминала.

Оба нужны, но для разного. Контур зафиксирован в ADR-011.

### 2. Как устроены Skills [Ф]

Открытый формат: папка с `SKILL.md` (обязательный фронтматтер `name` + `description`), плюс
необязательные `scripts/`, `references/`, `assets/`, `evals/`.

**Прогрессивное раскрытие, три уровня:** метаданные (~100 токенов на скилл, всегда) → тело
(до 5000 токенов, по триггеру) → референсы (по требованию). Это и есть ответ на вопрос,
почему скиллы дешевле серверов MCP: у MCP описания инструментов грузятся заранее.

**Оговорка.** [Ф] Есть подтверждённая жалоба на Claude Code: тела скиллов грузятся целиком
на старте, а не по триггеру; при множестве плагинов это десятки тысяч токенов до первого
сообщения. Проверять через `claude doctor` и `/context`, лишнее выключать.

**Лимиты.** `description` в claude.ai — до 200 символов (в спецификации до 1024); `name` —
до 64, строчные с дефисами, совпадает с именем папки; тело рекомендуется держать до 500 строк. [Ф]

### 4. Плагин Design [Ф]

Репозиторий `anthropics/knowledge-work-plugins`, версия 1.2.0, Apache-2.0. Внутри семь скиллов:
`accessibility-review` (WCAG 2.1 AA), `design-critique` (usability, иерархия, консистентность),
`design-handoff` (спека: layout, токены, пропсы, состояния, брейкпоинты, крайние случаи),
`design-system` (аудит системы, поиск хардкода и несогласованных имён), `research-synthesis`
и другие. Плюс девять серверов MCP (Figma, Slack, Linear, Asana, Atlassian).

**Разграничение с нашими субагентами.** Плагин Design — это дизайн-**процесс** общего вида.
Наши `design-critic` и `a11y-auditor` проверяют **наш** бриф и **наш** контракт. Дублировать
общее не нужно; специфику никто за нас не напишет.

### 5. Connectors [Ф]

Filesystem (14 инструментов, требует Claude for Desktop), Control Chrome, pdf-viewer,
Word и PowerPoint, Apify, Desktop Commander, Windows-MCP (не наш случай — Mac).

**Риск.** Вредоносный скилл или коннектор может увести данные: «Skill can direct Claude to
invoke tools in ways that don't match its stated purpose». Ставим только доверенное, читаем
`SKILL.md` перед установкой. Для продукта с персональными данными это не паранойя.

### 6. Свой скилл для claude.ai — порядок [Ф]

Включить исполнение кода и создание файлов → собрать папку с `SKILL.md` → упаковать в ZIP так,
чтобы папка скилла была корнем архива → Customize → Skills → Create skill → загрузить → включить →
проверить промптом. Скиллы из каталога только для чтения. Версионирование — своё.

## Часть II. Дизайн-язык российских финтехов

### 7. Что открыто [Ф]

- **Т-Банк — Taiga UI**: большая открытая библиотека на Angular, контракт CSS-переменных,
  локализация, компонент, скрывающий баланс при записи экрана. Экосистема — Maskito
  (маскирование полей, используется и другими банками).
- **Сбер — Nova**: супергарнитура SB на 50 начертаний, двухуровневые токены (референсный
  и системный уровни) в Platform V UI Kit.
- **Альфа-Банк**: открытая система, mobile-first, принцип «в библиотеку попадает только
  проверенное».

Код чужой (Angular), но воспроизводимы **правила**. Их и берём.

### 8. Числа и деньги [Ф]

- **Табличные цифры обязательны**: `font-variant-numeric: tabular-nums`. Без них колонки сумм
  не выравниваются по разрядам. Сценарии применения — финансы, таймеры, таблицы.
- **Знак рубля после числа через пробел** (Ководство, §116). Сокращение — «руб.». Десятичный
  разделитель — запятая, разделитель разрядов — неразрывный пробел, не запятая.
  Пример: `1 234,56 ₽`. Символ ₽ — U+20BD.
- Доллар наоборот: перед числом, без пробела.

### 9. Негативные данные [Ф]

- **Цвет никогда не единственный носитель смысла** — WCAG 1.4.1, уровень A, основа
  ГОСТ Р 52872-2019. Масштаб проблемы: примерно 1 мужчина из 12 и 1 женщина из 200 имеют
  нарушения цветовосприятия. Красный для убытка — ожидаемая конвенция в РФ, но обязателен
  второй признак: знак, иконка, подпись. Проверка — прогнать интерфейс в оттенках серого.
- **Соразмерность.** Резкий красный и модальное окно — только для настоящих блокеров.
  Для мягкого негатива — нейтральное оформление. Преждевременная ошибка (до того, как
  пользователь закончил ввод) — враждебный паттерн.
- **Тон.** Официальный регистр, «вы», спокойно, без обесценивания долга и без паники.

### 10. Прогнозы [Ф]

- Не показывать одиночное число как точное. Показывать диапазон, расширяющийся с горизонтом.
- Термин верный — **интервал предсказания**, не доверительный интервал среднего: последний
  существенно уже и покрывает не то. У нас интервал 80%, то есть p10–p90.
- Эталон подачи — **веерный график** Банка Англии: он появился именно чтобы не создавать
  «ложного впечатления точности». Эмпирика показывает, что веер лучше прочих способов
  одновременно передаёт и ожидание, и неопределённость, а публика систематически
  недооценивает разброс.
- Формулировка для пользователя: «в 8 сценариях из 10 результат попадёт в этот диапазон».
  Слова «гарантированно», «точно» — запрещены.

### 11. Регуляторика на экране [Ф]

- **Согласие по 152-ФЗ**: с 1 сентября 2025 требования ужесточены — согласие конкретное,
  предметное, информированное, сознательное и однозначное. На экране: отдельный несовмещённый
  чекбокс, не отмеченный заранее, ссылка на политику, цель обработки. Штрафы за нарушение —
  сотни тысяч рублей за первое, миллионы за повторное.
- **ПДН**: с 1 января 2024 (601-ФЗ) при значении выше 50% кредитор обязан письменно уведомить
  о рисках. Для нас — обязательный спокойный дисклеймер на экране.
- **Локализация**: первичный сбор и хранение персональных данных россиян — только в базах
  на территории РФ. Отсюда запрет на внешние CDN, шрифты Google и зарубежную аналитику.
- **Доступность**: ГОСТ Р 52872-2019 на базе WCAG 2.1.

### 12. Ниша FINPILOT [О]

Дзен-мани и CoinKeeper — трекеры: фиксируют прошлое, синхронизируются с банками, жалобы на
ошибки синхронизации и привязку данных. У Сбера и Т-Банка аналитика встроена в банковское
приложение. **Никто из них не отвечает на вопрос «куда направить свободные деньги в этом
месяце и почему именно так».** Многокритериальная оптимизация с объяснимостью — это и есть
отличие, и подавать его надо через объяснимость, а не через количество графиков.
