**ЦБ РФ, «Основные принципы и этапы внедрения Открытых API на финансовом рынке»**
https://www.cbr.ru/Content/Document/File/165674/document_2024-09-02.pdf — подготовлен проект
федерального закона «О внесении изменений в отдельные законодательные акты Российской
Федерации (в части осуществления информационного обмена на финансовом рынке)», дополняющий
нормы ФЗ от 10.07.2002 № 86-ФЗ «О Центральном банке Российской Федерации». Функция ЦБ как
регулятора информационного обмена с использованием Открытых API; ЦБ устанавливает критерии
для участников (поставщики и потребители данных), порядок ведения реестра, порядок обмена,
требования к информбезопасности, условия получения и предоставления информации (наличие
согласия клиентов) и подходы к тарификации.
Оттуда же: «До 2026 года использование Открытых API для всех участников финансового рынка
будет носить рекомендательный характер. С 2026 года начнется внедрение обязательных Открытых
API в три этапа с постепенным расширением перечня участников».
Дорожная карта в документе: ФЗ — 2025; нормативные акты ЦБ — 2025 и далее; проект ФЗ по модели
Открытых данных — 2026.

поддержан министерствами, мог быть внесён в Госдуму в осеннюю сессию 2024 (и.о. директора
департамента финтеха ЦБ Станислав Короп). Первый этап — крупнейшие банки, брокеры, страховые;
обязательность с 2026, вступление в силу ожидалось в январе 2026.

**Интерфакс 25.07.2024** (https://www.interfax.ru/business/972527): обязательность могут

(https://vfokuse.mail.ru/news/69631873, оригинал rg.ru недоступен — DNS-отказ на `curl`,

Газпромбанк... принятие закона планировалось в 2025 году, обязательный запуск — в 2026-м,

более 700 тысяч пользователей уже применяют технологию через пилотные проекты... требования

Официальная страница ЦБ РФ по теме (https://www.cbr.ru/fintech/api/, дата обновления

согласий... находится в стадии пилотирования».

**Итог по Open API (закрывает вопрос 1а):** закон не внесён в Госдуму, находится на стадии
подготовки текста Банком России (координация с министерствами) с 2024 года, сроки дважды
сдвигались (изначально ФЗ — 2025, обязательность — 2026; затем «обязательность позже 2026,
новые сроки — после принятия закона»); на июль 2026 крупнейшие банки просят ЦБ ускорить,
ответа от регулятора на момент публикации не было; на сентябрь 2026 в СОЗД по-прежнему нет
зарегистрированного законопроекта. Внедрение остаётся **добровольным** (10 стандартов ЦБ
утверждены в декабре 2025, пилот на 700 тыс. пользователей), обязательных сроков для
автоимпорта банковских операций через Open API в 2026–2027 гг. **не существует** — продукту
рассчитывать на легальный обязательный автоимпорт в этом горизонте не стоит, только на
добровольное подключение отдельных банков к пилоту ЦБ.

## Отдельные ответы по ключевым вопросам постановки

**ИИ — определение (предмет 3 постановки).** 🟢 Легальное определение ЕСТЬ: **ФЗ от 26.07.2026
№ 243-ФЗ «О поддержке развития технологий искусственного интеллекта в РФ»** (СОЗД 1271570-8,
действует с 01.09.2026, часть норм — с 01.03.2027). Предмет регулирования — исключительно
**большие фундаментальные модели** (ст. 1 ч. 1), а БФМ по ст. 3 п. 2 — программа, «**обучающаяся
(ранее обученная) на составах данных**... содержащая **не менее 1 миллиарда параметров**».
Общее определение ИИ (ст. 3 п. 1) требует способности «выполнять **поиск решений без заранее
заданного алгоритма**». **FINPILOT — детерминированная система на формулах с заранее заданным
алгоритмом, без обучаемой модели и без 1 млрд параметров — под это определение не подпадает.**
Определения ИИ через «автоматизированное принятие решений» в периметре закона нет (такая
формулировка — в ст. 16 152-ФЗ про решения на основе автоматизированной обработки ПДн, другой
закон, другой предмет). Для финсектора отдельно: Кодекс этики ИИ на финрынке — рекомендательный
(приложение к письму ЦБ от 09.07.2025 № ИН-016-13/91), Методрекомендации ЦБ от 16.06.2026
№ 3-МР по ИБ при ИИ; с 01.03.2027 Правительство по согласованию с ЦБ вправе ограничивать
применение БФМ на финрынке (ст. 5 ч. 2 пп. 3–4 243-ФЗ) — к нашему продукту неприменимо, так как
он не БФМ. Полные дословные цитаты статей 1, 3, 4, 5 — в `..._subA.md`.

**ПДН — методика (предмет 3 постановки).** 🔴 Указание Банка России **№ 4892-У** от 31.08.2018
(на которое ссылается матмодель продукта) **утратило силу с 01.01.2022** (цепочка: 4892-У →
5782-У с 01.01.2022 → 6411-У с 01.06.2023 → **действующее Указание № 6579-У от 16.10.2023**,
в силе с 01.01.2024, ред. от 24.03.2025). Методика **меняется** Указанием ЦБ от 19.01.2026
**№ 7286-У** (Минюст 26.02.2026 № 85485), поэтапно: с 01.04.2026 — выписки по счетам только для
подтверждения зарплаты/пенсии/соцвыплат/аренды, ЦБ прекращает принимать внутренние модели оценки
доходов банков, ИП нельзя использовать самовыданные документы; с 01.07.2026 — дисконт 10 % к
заявленным доходам; с 01.07.2027 — полный отказ от упрощённого подхода. Порог продукта 0,40
(отношение платежей к доходу) методикой не задаётся и не меняется — меняется только то, КАК
считается сам доход в числителе/знаменателе. 🔴 **Нужна правка ссылки в математической модели
продукта: с 4892-У на 6579-У (с учётом 7286-У)** — это расхождение канона с действующим правом,
подробности и полные цитаты — в `..._subA.md`, раздел «Вызовы 9–12».

**Цифровой рубль в выписке (предмет 3 постановки).** 🟢 Это **отдельный счёт/кошелёк на платформе
Банка России**, а не строка в обычной банковской выписке. Открывается по желанию физлица через
раздел «Цифровой рубль» в приложении банка, у кошелька собственная история операций и личный
кабинет; в обычной выписке по банковскому счёту видны только переводы между счётом и кошельком
(пополнение — до 300 тыс. ₽/мес.). Первичный документ по операции — «Извещение об исполнении
распоряжения» платформы, не банковская выписка; для юрлиц выгрузка истории операций по счёту ЦР
идёт отдельным файлом в формате XML (1С:Бухгалтерия 8 ред. 3.0.164+). Массовое внедрение —
с 01.09.2026 (крупнейшие банки), 01.09.2027 (универсальная лицензия), 01.09.2028 (базовая
