# Г13 — Сплошной обход магазинов приложений (App Store, Google Play, RuStore), 2026-09-12

## Г13.0 — метод и каналы

Дата обхода: 12.09.2026. Исполнитель: агент Г13.

**Канал 1 — iTunes Search API (App Store), без ключа, рабочий.**
`curl -s --get "https://itunes.apple.com/search" --data-urlencode "term=<запрос>" --data-urlencode "entity=software" --data-urlencode "country=<ru|us>" --data-urlencode "limit=200"`
HTTP 200, JSON. Отдаёт `trackName`, `sellerName`, `description` (полное описание,
локализованное под `country` — для `country=ru` описания приходят ПО-РУССКИ, это ключевое:
классификация возможна машинно), `formattedPrice`, `averageUserRating`, `userRatingCount`,
`genres`, `currentVersionReleaseDate`, `trackViewUrl`. Все JSON сохранены в `/private/tmp/g13/`.

**Канал 2 — RuStore, НАЙДЕН НЕДОКУМЕНТИРОВАННЫЙ ПУБЛИЧНЫЙ API (новое, в задании не было).**
`curl -sk --http1.1 "https://backapi.rustore.ru/applicationData/apps?query=<urlencoded>&pageSize=50"`
→ HTTP 200, 28 052 байта JSON. Поля: `appId`, `packageName`, `appName`, `shortDescription`,
`averageUserRating`, `totalRatings`, `roundedDownloadsText` (!— число установок, которого нет
у Apple), `price`. Это лучший канал по РФ-Андроиду, чем разбор HTML витрины.

**Канал 3 — Google Play.** `curl -sk --http1.1` с браузерным UA на
`play.google.com/store/search?q=...&c=apps&hl=ru&gl=ru` → HTTP 200, ~1.1–1.4 МБ HTML.
Ограничение канала названо честно ниже в Г13.3: витрина отдаёт карточки БЕЗ полных описаний,
только имя + разработчик + рейтинг. Классификация «по описанию» на этом канале напрямую
невозможна, нужен доп. заход на карточку приложения.

**Классификация — три класса, по описанию, не по названию:**
- **трекер** — показывает, что было (учёт, категории, отчёты);
- **планировщик** — даёт правила, шаблоны, калькуляторы; считает и решает пользователь;
- **советник** — сам вычисляет, куда направить конкретные деньги, и говорит это.

🔴 **Рабочее уточнение, возникшее по ходу и важное для трактовки всего результата.**
Внутри «планировщика» пришлось выделить подкласс, которого не было в исходной рамке:
**оптимизатор одного вида долга** — приложение, которое само ранжирует долги по ставке
(лавина) и выдаёт график с датой закрытия. Оно ВЫЧИСЛЯЕТ и ГОВОРИТ, то есть формально
подходит под «советника», но решает задачу в **одном контуре — только долги**, при
заданной пользователем сумме доплаты. Оно не спрашивает, сколько свободных денег есть,
и не выбирает между долгом, резервом и целью. Дальше такие помечены как
**«советник по долгам (одноконтурный)»**, и это отличие несущее — см. ИТОГ Г13.

### Отрицательный результат Г13.1 (точная формулировка)

Среди 618 уникальных приложений русской витрины **ноль** таких, где описание заявляет
расчёт распределения свободных денег между погашением долга, резервом и целями.
Ближайшее по смыслу — «Рекомендации по свободным активам» у мёртвого с 2023 года
«Баланс», без раскрытия механики.

6. **Bright Money:** цена $97/год снята с карточки App Store; сходится ли она с ценой

7. **«Карма», «Финздоровье» Т-Банка, «Финансовое Здоровье» Финуслуг** — по условию задания

🟢 **WebSearch не использовался ни разу.** Весь материал получен прямыми обращениями

## Г13.6 — ДОБОР: сплошной срез категорий (чарты App Store, витрины Google Play и RuStore)

### Почему поправка справедлива — доказательство внутри самой выборки

🔴 **`Snowball Income`** (Egor Babichev, RU, 4,90 при **1 516** оценках) — по названию
идеальный кандидат в советники по долгам («снежный ком»). По описанию:
> «передовое мобильное приложение для эффективного управления и анализа вашего
> **инвестиционного портфеля**… объединить несколько **брокерских** счетов… контролировать
> **дивиденды**… Календарь поступлений от дивидендов и купонов».

Это **трекер инвестиционного портфеля**, к долгам отношения не имеющий. Любая
классификация по названию или по слову «snowball» записала бы его в советники.
Ровно тот эффект, о котором предупреждал владелец.

1. **Независимый продукт нашего жанра в российский чарт не попадает в принципе** — не

   калькуляторы.** Платный топ РФ показывает готовность платить $9–25 за инструмент расчёта.
