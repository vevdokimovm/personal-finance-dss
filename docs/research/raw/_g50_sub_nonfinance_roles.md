### 6. Интеграционный слой — Битрикс24 Маркет (вызов 2, Exa search)

**Класс: документация вендора** (apidocs.bitrix24.ru — официальная докуменация для разработчиков),
обращение 2026-09-18.

Ключевая механика монетизации — НЕ «комиссия с продажи приложения», а **подписка
«Битрикс24 Маркет Плюс»** с распределением общего пула выручки:

> «Базовый способ монетизации решений для Битрикс24 Маркет - это участие в подписке
> Битрикс24 Маркет Плюс. Клиент оплачивает фиксированную стоимость Битрикс24.Маркет Плюс
> для своего тарифа Битрикс24 и получает возможность устанавливать любые решения, входящие
> в состав Битрикс24 Маркет Плюс. Полученную выручку 1С-Битрикс, за вычетом своей комиссии,
> распределяет между теми решениями, которые клиент установил и использует на своём Битрикс24.»
> — https://rest-docs.bx24.net/pub/market/monetization/index.html (и зеркало
> apidocs.bitrix24.ru/market/monetization/)

> «Важно понимать, что в этой модели вы не сможете заранее рассчитать размер своей выручки
> с каждого отдельно взятого клиента, поскольку это будет зависеть и от тарифа клиента,
> и от того, какими другими приложениями он будет пользоваться.»
> — там же.

🔴 **Числовой размер комиссии 1С-Битрикс в тексте страницы поиска НЕ приведён** — формулировка
«за вычетом своей комиссии» без процента. Требует добора (см. недобытое).

**Статусы решения** (apidocs.bitrix24.ru/market/preparing-to-publish/publication-requirements.html):
- «Монетизируемое» / «Немонетизируемое». Немонетизируемое допустимо только для: миграторов
  данных в Битрикс24; решений, которые не требуют оплаты своего функционала, но требуют оплаты
  внешнего сервиса разработчика; полностью бесплатных. Дословно: «Все остальные виды Решений
  должны быть опубликованы как "Монетизируемое"».
- Монетизируемое требует заключения Лицензионного договора с 1С-Битрикс.
- 🔴 Важное ограничение аудитории: «Решения, опубликованные в Каталоге 1С-Битрикс24.Маркетплейс,
  могут устанавливать и использовать только Пользователи, оплатившие Сертификат
  "1С-Битрикс24.Маркетплейс" ... или включившие пробный период использования Сертификата.»
  То есть доступная аудитория = не все пользователи Б24, а купившие Маркет Плюс.
- Разрешена доп. монетизация: «Разработчики Решений в статусе "Монетизируемое" могут также
  предлагать Пользователям оплачивать стоимость дополнительного функционала, снятия встроенных
  лимитов и т.д. Оплату ... Разработчики могут принимать через 1С-Битрикс или самостоятельно.»

**Требования к вендору (контрагенту) для платного размещения** — дословно,
apidocs.bitrix24.ru/market/documents/index.html:
1. Действующее российское юр. лицо или ИП (не в ликвидации).
2. «Только на системах налогообложения УСН/АУСН/ОСНО.»
3. «С контрагентами на ПСН и НПД мы технически и юридически не может заключать данные соглашения.»
4. «Наличие кодов ОКВЭД, связанных с разработкой - категорий 62 или 63.»
5. Автоматическая проверка контрагента на стороне 1С-Битрикс.
- Физлицо может публиковать ТОЛЬКО бесплатные приложения (по Оферте, без ЭДО).
- В кабинете вендора может быть только ОДИН активный контрагент.

**Типы размещения:** БЕСПЛАТНО (все регионы) · ПО ПОДПИСКЕ (только РФ и Беларусь) ·
ПО ОТДЕЛЬНОЙ ЦЕНЕ (только для модулей 1С, Агентский договор).
Для Казахстана и «Запада» — только бесплатные, встроенные покупки реализуются самостоятельно.
🔴 «если решение опубликовано по подписке Битрикс24 Маркет Плюс в России, то его нельзя будет
опубликовать как бесплатное в других регионах» — нужно два отдельных приложения.

**Порядок публикации** (rest-docs.bx24.net/pub/market/preparing-to-publish/how-to-add-app.html):
карточка решения → Настройки продаж + контрагент → соглашения (оферта сразу / ЭДО 1–2 раб. дня) →
кнопка «На модерацию» → **модерация 1–3 рабочих дня** → при успехе публикация сразу, но
«индексация для поиска происходит раз в сутки». Возврат на доработку за одну ошибку, решение
попадает в конец очереди. Модератору нужен доступ к тестовому окружению; интеграция, работающая
только с одним конкретным Б24 разработчика, к публикации не допускается. Тестирование —
«в стандартном облачном Битрикс24 на верхнем тарифе»; требование доп. ПО = право отказать.

**Выплаты** (apidocs.bitrix24.ru/market/documents/payments.html): автоматический биллинг,
Отчёт лицензиата по ЭДО «в первых числах каждого месяца (не позднее 10-го рабочего дня)»,
перевод после подписания отчёта. Приостановка выплат при неподписанном >30 дней отчёте,
неактуальных реквизитах, ликвидации/претензиях.

#### 🔴 Вызов 3 (Exa fetch) — критерии «Монетизируемое/Немонетизируемое» ПРЯМО БЬЮТ В FINPILOT

Источник: https://apidocs.bitrix24.ru/market/monetization/index.html — **документация вендора**,
обращение 2026-09-18. Дословно:

> «Мы не делимся доходом от подписки с решениями, которые: являются точкой входа в платный
> внешний SaaS или сервис; используют Маркетплейс в первую очередь как канал привлечения
> трафика; продают собственный основной продукт (телефония, SMS, мессенджеры, API-сервисы и т.п.).»

> «Под "внешним сервисом" мы понимаем продукт самого разработчика, который он продаёт как
> отдельный сервис. Это сервис: 1. который может работать без Битрикс24; 2. который разработчик
> продаёт как самостоятельный продукт; 3. который может интегрироваться не только с Битрикс24,
> но и с другими CRM или аналогичными системами; 4. где приложение в Маркетплейсе выступает
> способом подключения к этому продукту.»

> «2. Эксклюзивность по отношению к Битрикс24 (ключевой признак). Признаком немонетизируемого
> решения является ситуация, когда: продукт явно позиционируется как универсальный сервис;
> существуют интеграции или активное продвижение под другие CRM / платформы; Битрикс24 – один
> из каналов подключения, а не основная среда использования.»

**Вывод по FINPILOT (оценка подагента, не цитата):** самостоятельный SaaS, работающий без Б24 и
планирующий интеграции с несколькими системами, по этим критериям попадает в
«Немонетизируемое» — то есть **выручку подписки Маркет Плюс он не получает вовсе**, Маркет
работает только как канал привлечения, оплату надо принимать самому. Монетизируемый статус
потребовал бы эксклюзивной привязки к Б24 («решение работает только с Битрикс24; нет
аналогичных интеграций с другими системами»). 🔴 **Развилка, ждёт владельца:** либо
эксклюзивная Б24-версия ради доли подписки, либо Маркет как лид-канал с внешней оплатой.

Что при этом разрешено монетизируемым (п. 4.1, 4.3): инфраструктурные доплаты за AI-токены,
API-вызовы, хранение — «если объём или необходимость доплаты зависит от интенсивности
использования, а не от самого факта установки решения»; допускаются «лимиты, пакеты,
pay-as-you-go модели».

🔴 **Числового процента комиссии 1С-Битрикс на этой странице нет** — только «за вычетом своей
комиссии» и отсылка «Узнайте подробности о том, как это работает» (страница how-it-works.html
через Exa не открылась, CRAWL_NOT_FOUND).

**Содержательное ограничение, важное для FINPILOT:** «Решение должно расширять пользовательский
функционал Битрикс24, используя встроенные инструменты платформы или интеграцию Битрикс24
с внешними системами» — то есть автономный финансовый калькулятор без привязки к данным Б24
формально не проходит; нужна интеграция с сущностями Б24. Авторизация — только OAuth 2.0,
запрос пароля пользователя запрещён.

### 6б. amoCRM Маркет — канал мёртв (вызовы 5, 6, 7: curl + WebSearch + r.jina.ai)

Замер 2026-09-18:
- `curl` с браузерным UA: `https://www.amocrm.ru/developers/content/platform/monetization`
  → **HTTP 404** (57 956 байт — страница-заглушка); `.../platform/marketplace` → **HTTP 404**.
- `r.jina.ai` без UA на `.../platform/marketplace_intro` и `.../platform/widgets_public`

- `WebSearch` «amoCRM маркет условия разработчику комиссия»: выдача целиком —
  **маркетинг интеграторов** (gnzs.ru, amgbp.ru, bcip.ru, myrubikon.ru, cmdf5.ru) и
  неофициальная база знаний amocrm.support. 🔴 **Числом не считается.**
  Единственное содержательное из выдачи (класс: сторонняя база знаний, не вендор):
  публичные интеграции добавляются в amoMarket по решению разработчика; ключи авторизации
  генерируются в разделе amoMarket личного кабинета; сборка — `manifest.json` + `script.js`
  + `widget.zip`. **Процент комиссии amoCRM не добыт.**

**Вывод по каналу:** условия amoCRM Маркет для сторонних разработчиков закрыты за логином
в кабинет разработчика — публично не документированы так, как у Битрикс24. Это само по себе
факт: прозрачность вендорских условий у Б24 несопоставимо выше.

### 6г. 🔴 МойСклад — ЕДИНСТВЕННЫЙ вендор с ОПУБЛИКОВАННЫМ числом комиссии (вызов 10, Exa)

Источник: **документация вендора**, `https://dev.moysklad.ru/doc/api/vendor/1.0/`
(Vendor API 1.0, раздел «Расчет вознаграждения и комиссия»), обращение 2026-09-18. Дословно:

> «Вознаграждение разработчика – 75% от стоимости подписки, которую мы получили от клиента
> (конечного пользователя или партнера). Если ваше решение продается с НДС, то вознаграждение
> 75% рассчитывается после вычета НДС из стоимости подписки. Например, если клиент купил
> подписку на 1 месяц на решение стоимостью 1000 рублей/месяц, которое включает в себя НДС 22%
> (180,33 рублей), то разработчик получит за него 615 рублей за этот период. Если купленное
> решение находится в Реестре российского ПО, то вознаграждение разработчика составит 750 рублей.»

**Итого комиссия МойСклад = 25 %** (против 40–50 % у Инфостарта — известно заранее) — но
эффективная доля разработчика с НДС 22 % без Реестра ПО = **61,5 %**, то есть эффективная
«стоимость площадки+НДС» ≈ 38,5 %. 🔴 **Реестр российского ПО поднимает выплату с 615 до 750 ₽
с тысячи** — прямой денежный аргумент за включение FINPILOT в Реестр.

> «Решение можно купить на 1 месяц и на 12 месяцев. При покупке сразу на 12 месяцев для клиента
> действует скидка 20%, вознаграждение разработчику при этом рассчитывается от итоговой суммы,
> которую заплатил клиент: (Цена решения х 12 месяцев – 20%) – 25%.»

> «Решения также могут покупать наши партнеры, которые внедряют и настраивают МойСклад клиентам,
> им доступна скидка 30% на все решения. При покупке решения через партнера вознаграждение
> рассчитывается от итоговой суммы, которую получил МойСклад: (Цена решения – 30%) – 25%.»
> → через партнёра разработчик получает 0,7 × 0,75 = **52,5 %** прайса (до НДС).

**Приватные решения — цена по прайсу вендора, с датой обращения 2026-09-18:**
> «Использование приватных решений платное, стоимость — 1300 рублей/месяц или 12 480 рублей/год,
> оплачивается на каждом аккаунте, где оно установлено... Вознаграждение разработчика с этой
> суммы не предусмотрено.»

**Требования к разработчику** (дословно): «вы должны быть ИТ-компанией с соответствующим
основным ОКВЭДом (например, 62.01 «Разработка компьютерного программного обеспечения»),
у вас должно быть зарегистрировано юрлицо или ИП в РФ или странах СНГ, банковский расчетный
счет в российских рублях для получения вознаграждения». Для **приватного** решения требование
о профильной деятельности не предъявляется (moysklad.ru/poleznoe/shkola-torgovli/api-moysklad/).

**Выплаты:** отчёт в кабинете в начале месяца → Акт передачи прав (или УПД, если плательщик НДС)
→ подпись через **ЭДО Диадок** (идентификатор МоегоСклада `2BM-7736570901-773601001-201410200137255142560`)
→ «Выплата поступит в течение пяти рабочих дней с даты подписания акта в ЭДО».

**Порядок публикации:** анкета разработчика → доступ в кабинет → разработка (JSON API 1.2 для
бизнес-логики + Vendor API для жизненного цикла; опционально Loyalty/Phone/Fiscal/QRPay API) →
тест → модерация → управление версиями и статистикой в кабинете.

**Оферта разработчика** (полный текст — `https://www.moysklad.ru/upload/files/marketplace.pdf`,
цитируется через datasklad.com/offer-developer, класс: **перепечатка оферты на сайте партнёра**,
не первичный домен): п. 8.1 «Разработчику запрещено копировать, хранить, обрабатывать любые
данные Пользователя, доступ к которым появляется у Разработчика после установки Пользователем
Приложения, в рекламных или иных целях, не связанных напрямую с выполнением функций Приложения»;
п. 8.3 «Установка приложения Пользователем не считается согласием на предоставление своих
данных». 🔴 Для FINPILOT это прямое ограничение на любую вторичную аналитику по данным клиентов
МоегоСклада. Споры — Арбитражный суд г. Москвы; МойСклад вправе менять договор односторонне
без уведомления (п. 11.3). Юрлицо МоегоСклада — ООО «Логнекс», ИНН 7736570901.

**Объём аудитории партнёрской сети (класс: маркетинг вендора, числом считать осторожно):**
partners.moysklad.ru — «> 300 разработчиков»; moysklad.ru/poleznoe — «более 600 партнеров,
которые профессионально занимаются внедрением». Партнёрам — скидка до 50 % на тарифы.

**Исторический замер щедрости площадки (класс: акция вендора, архив):** конкурс приложений
2023–2024 — «Стоимость вознаграждения за разработанное и опубликованное в срок приложение —

(partners.moysklad.ru/contest-2024/). Показывает готовность площадки платить за наполнение
