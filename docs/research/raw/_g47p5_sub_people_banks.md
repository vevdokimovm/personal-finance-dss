## 2. Концентрация по людям (топ-1/5/10, HHI, динамика 2021→2026)

- 🔴 **ВАЖНАЯ ОГОВОРКА:** весь найденный материал по индексу Херфиндаля-Хиршмана (HHI) и топ-5/топ-10 в российском банковском секторе считается по АКТИВАМ, ВКЛАДАМ (в рублях) или КРЕДИТАМ — то есть по ДЕНЬГАМ, не по ЧИСЛУ КЛИЕНТОВ-ФИЗЛИЦ. Прямого HHI по количеству розничных клиентов в найденных источниках НЕТ ни у ЦБ, ни в академических работах.
- Историческая точка (Банк России, цитата по академической статье): для российской банковской системы в целом (957 банков) значение HHI по некоему совокупному показателю (не указано явно, по контексту — активы) составляло **907** — оценивается как достаточно конкурентный рынок. Доля 5 крупнейших банков по вкладам физлиц выросла с 58,3% (01.01.2013) до **62,0%** (01.01.2016), при этом почти половина всех вкладов приходилась на один Сбербанк. Класс: наша оценка на основе академической статьи (вторичный источник, первичные данные ЦБ не проверены напрямую). URL: https://cyberleninka.ru/article/n/statisticheskie-pokazateli-otsenki-urovnya-konkurentsii-bankovskoy-sistemy
- Динамика HHI по кредитному портфелю физлиц у топ-6 банков (Сбер, ВТБ, Альфа, Газпромбанк, Т-Банк, Россельхозбанк), 2010→2023 (по объёмам кредитов в млрд руб., НЕ по числу клиентов): академическая работа приводит таблицу абсолютных объёмов и делает вывод, что «российский банковский рынок характеризуется высоким уровнем концентрации» и является олигополистическим с Сбербанком-лидером; общий тренд HHI/CR3 — снижение с 2010 по 2023 гг. (рост числа значимых игроков). Класс: наша оценка на основе академической статьи. URL: http://repo.ssau.ru/handle/Problemy-ekonomiki-sovremennyh-promyshlennyh-kompleksov/Analiz-koncentracii-bankovskogo-rynka-RF-v-20102023-gg-113657
- 🔴 **Наша оценка (расчёт) грубой доли по ЧИСЛУ КЛИЕНТОВ на базе найденных выше цифр отчётности эмитентов, не независимый источник:** сумма активных розничных клиентов у 5 крупнейших раскрывшихся банков ≈ Сбер 110,7 млн + Т-Банк 34,3 млн + ВТБ 30,3–31,3 млн + Альфа-Банк ~37,6–40 млн + Ozon Банк 41,7–43 млн ≈ **254–260 млн "клиентских отношений"**. Это заведомо БОЛЬШЕ населения РФ (~146 млн), что прямо подтверждает и количественно иллюстрирует масштаб мультибанкинга: один человек считается "активным клиентом" в нескольких банках одновременно. Это не HHI и не доля рынка — это иллюстративная арифметика, показывающая, почему подсчёт "клиентов" по банкам не сводится к подсчёту людей.

### Главное число (пункт 4 вопроса, по прямому опросу ВТБ 2024 — лучшая найденная точка)

**Типичному пользователю FINPILOT для покрытия ВСЕХ своих счетов нужна поддержка форматов выписок в среднем ~2–3 банков, а не одного.** Разбивка (ВТБ, 2024, N не указано в найденном фрагменте): 1 банк — 27% людей, 2 банка — 33%, 3 банка — 22%, 4+ банка — 16%. Средневзвешенная оценка (наш расчёт, консервативно считая "4+" как 4,5): **(1×0,27 + 2×0,33 + 3×0,22 + 4,5×0,16) ≈ 2,45 банка на человека** — это НАША ОЦЕНКА на основе процентов ВТБ, не готовое число из источника. Более свежий опрос «Авито Рекламы» (2026, иная методология) даёт более резкий сдвиг: 63% пользуются несколькими банками, 32% — одним, что означает средневзвешенное значение ЕЩЁ ВЫШЕ ~2,45, но без разбивки на 2/3/4+ банка посчитать точнее нельзя.
🔴 Практический вывод для продукта: чтобы покрыть **80%+ типичных пользователей со всеми их счетами**, достаточно поддержать форматы выписок/API **топ-5–7 банков по охвату** (Сбербанк, Т-Банк, ВТБ, Альфа-Банк, Ozon Банк — судя по данным ВЦИОМ о приоритетности и охвате, плюс Газпромбанк/Совкомбанк как system-significant), а не десятки — потому что распределение сильно хвостатое (Сбербанк — почти у всех как минимум "второй" банк).

## Недобытое и причина

1. **Число активных клиентов-физлиц: МКБ, Яндекс Банк, Wildberries Банк, Почта Банк, Райффайзенбанк, Россельхозбанк, Русский Стандарт, Уралсиб, Дом.РФ.** Причина: бюджет вызовов исчерпан на приоритетных крупных банках (Сбер/Т-Банк/ВТБ/Альфа/Газпромбанк/Совкомбанк/Ozon/МТС); по МКБ и Яндекс Банку целевые документы найдены, но НЕ содержат числа розничных клиентов (МКБ раскрывает только средства розничных клиентов в рублях и корпоративный сегмент; Яндекс Банк — только формальная бухгалтерская отчётность без операционных метрик).
2. **Точный, официальный, актуальный (2025/2026) HHI или доля топ-1/5/10 ПО ЧИСЛУ КЛИЕНТОВ-ФИЗЛИЦ (не по деньгам).** Причина: ни ЦБ РФ, ни Frank RG/Markswebb, ни академические источники не публикуют HHI именно по количеству клиентов — вся методология концентрации в РФ считается по активам/вкладам/кредитам в рублях. Это, по всей видимости, системный пробел индустрии, а не наш недосмотр — стоит явно отметить это в итоговом отчёте по Г47.
3. **Официальная актуальная (2025/2026) цифра ЦБ или НАФИ на прямой вопрос "сколько банков в среднем у россиянина" с чёткой методологией и годом.** Причина: НАЙДЕНЫ близкие заменители (ВТБ-2024 опрос по числу банков с картами: 27%/33%/22%/16%; НАФИ-2016 по числу банков: 63%/22%/5%; Авито-2026 по бинарному "1 банк vs несколько": 32%/63%), но ни один не является ОФИЦИАЛЬНЫМ регулярным индикатором ЦБ РФ формата "Мониторинг финансовой доступности" — этот отчёт (найден и частично прочитан, https://www.cbr.ru/Content/Document/File/194198/acc_indicators_17072026.pdf) в извлечённых фрагментах содержит только инфраструктурные индикаторы (банкоматы, точки обслуживания, доля безнала), а НЕ долю мультибанковских клиентов. Полный PDF (десятки страниц) не прочитан целиком — за пределами бюджета захода; возможно, искомые данные есть в неполученных разделах документа.
4. **Данные СберИндекса и НБКИ/ОКБ по мультибанкингу.** Причина: целевой поисковый запрос не дал релевантных прямых попаданий за один заход; не пробовано через r.jina.ai или прямой сайт sberindex.ru — бюджет исчерпан раньше.
5. **Разрезы мультибанкинга по возрасту/доходу/город-село.** Причина: не найдено ни в одном источнике этого захода в явном виде с процентами; ВЦИОМ "Банки нового поколения" содержит поколенческую разбивку по ДРУГИМ метрикам (осведомлённость о необанках), но не по числу банков на респондента.
6. **Полный официальный текст "Всероссийского обследования домохозяйств по потребительским финансам — 2024"** (ЦБ РФ, 6-й раунд) — только 2-страничная презентация с общими индикаторами долговой нагрузки прочитана; сырые данные обследования (доступны исследователям по заявке ЦБ) не запрашивались — вне формата подагента.
7. Число розничных клиентов Ozon/Яндекс/Wildberries Банков в разрезе именно БАНКОВСКОГО (не всего финтех-сегмента с МФО) юрлица — цифры выше (41,7–43,1 млн у Ozon) относятся к ВСЕМУ финтех-сегменту Ozon (банк + МКК «Озон Кредит»), возможна двойная выдача внутри сегмента.

Бюджет добывающих вызовов на момент остановки: использовано ≈18 из 25 (WebSearch/WebFetch по счётчику Exa). Остановка — по исчерпанию отдачи на приоритетные банки, не по жёсткому лимиту.
