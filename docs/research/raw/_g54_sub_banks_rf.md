Итог: **ни у одного из четырёх не найдено функции, которая по данным клиента детерминированно делит свободный остаток месяца между досрочным погашением, резервом, целями и инвестициями.** Ближе всех по заявленному направлению — Т-Банк («Тая», учёт кредитной нагрузки в планах, публичная нейтральность); по уже работающему плану накоплений — Сбер («Цели» + ГигаЧат). Все банковские реализации — на LLM; воспроизводимость и объяснимость решения никто не заявляет (эксперты в Ведомостях называют это требованием) — это отстройка FINPILOT.

Регулятор: жёсткого режима для ИИ-советов по бюджету/долгам нет; Кодекс этики ИИ (09.07.2025) — рекомендательный, адресован финорганизациям (раскрывать ИИ, давать отказаться, пересмотр человеком); консультационный доклад 20.11.2025 подтверждает курс на мягкое регулирование. Конфликт интересов формально урегулирован только для инвестсоветников (39-ФЗ ст. 6.1, 5014-У). Открытые API — рекомендательные, версии 2.0.0 вводятся 01.10.2026, обязательность — в проработке; «сервисы планирования личных финансов» ЦБ прямо называет целевым сценарием, но участники — по критериям ЦБ.
