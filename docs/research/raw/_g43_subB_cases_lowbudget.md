[замер] Правило: "Упоминать свою компанию или продукт можно только в корпоративном блоге или в хабе «Я пиарюсь»" — то есть личный (не корпоративный) аккаунт технически МОЖЕТ писать без покупки блога, но ограничен хабом-гетто «Я пиарюсь» для явной саморекламы.
[замер] Последствие нарушения: "Если основная часть вашей активности связана с одной компанией или продуктом, Хабр может ограничить такие публикации" — то есть регулярные статьи в личном блоге о СВОЁМ продукте без покупки корп-блога рискуют ограничением аккаунта.
ВЫВОД ДЛЯ FINPILOT: для одиночки без бюджета — писать НЕ рекламные статьи (технический разбор, как считал матмодель, аваланш-фильтр долгов, SES+Монте-Карло) с редким/непрямым упоминанием продукта, не через корп-блог (106k+ ₽ недоступно), и не злоупотреблять частотой, чтобы не попасть под ограничение.

### VibeLing-кейс (см. §1) прямо называет VC.ru неработающим каналом ("0 установок"), а Habr — рабочим (13K охвата, 100-300 установок со статьи) для пет-проекта без бюджета. Перенос на нишу личных финансов требует осторожности (другая аудитория), но порядок величин ориентировочен.
