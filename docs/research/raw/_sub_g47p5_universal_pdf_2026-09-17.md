# Подагент G47.P5 — Универсальный разбор PDF-выписки банка без шаблона (2026-09-17)

Тема: как индустрия и наука делают разбор банковских PDF-выписок БЕЗ шаблона под
конкретный банк. Продукт FINPILOT. Ядро разбора — без ML (ML только как эталон сравнения).

## Состояние каналов (обновляется по ходу)
- WebSearch: доступен, короткие запросы.
- WebFetch: пробуется первым на каждую находку.
- curl с браузерным UA: канал 2.
- curl r.jina.ai без UA: канал 3.
- Exa (mcp__exa__*): канал 4.
- GitHub: gh api / raw.githubusercontent.com.
- pdftotext: установлен, /usr/local/bin/pdftotext.
