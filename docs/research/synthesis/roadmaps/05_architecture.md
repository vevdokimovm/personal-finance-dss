## P0

### A-01. Разбор выписки на устройстве
🔴 **Источник:** Г66 Б-01 плюс Г59.

Главный вход сферы. Собственный замер: приём переносится в браузер, max |Δ| 0,0049 pt.
Правовая причина не менее важна инженерной: строки выписок на сервере перешагивают
порог **1 млн идентификаторов** и дают отдельный состав по ч. 14 ст. 13.11 КоАП (Г59).
Разбор на устройстве снимает вопрос целиком.

Стек, проверенный корпусом: Pyodide + pdfminer.six, трёхъярусное извлечение таблиц
(прямоугольники → координаты → текст).

## P1

### A-02. Файловый разбор — нижний слой, API — верхний
🔴 **Источник:** Г48, урок №4, и он замерен на чужом опыте.

У 1С DirectBank лёг **поверх** файлового канала с откатом в один флаг: «установить флаг
Недействительна — обмен снова через текстовый файл». Онлайн-канал не заменил файловый.

Для нас: Открытые API ЦБ (01.10.2026) закроют **голову** распределения и не закроют
хвост — значит разбор выписки не обесценивается, а становится нижним, всегда работающим
слоем. Архитектурно это решение, а не код.

### A-03. Граница Decimal/float зафиксирована в каноне и в коде
🔴 **Источник:** файлы `08/09/10_decimal_*`.

Слой границы назван и проверен: `metrics.py` (каждая функция money/money → безразмерное),
вход — `preprocessing.py`, горячая точка порядка округления — `amortization._simulate`.
`forecast.py` и `spending_advice.py` остаются float осознанно.

🔴 **Ограничение, которое обязано ехать с любым пунктом про Decimal:** FastAPI
с `response_model` сериализует `Decimal` **в JSON-строку** (замерено живым TestClient),
тогда как `jsonable_encoder` — в число. Схемы ответа остаются `float` либо получают
`Annotated[Decimal, PlainSerializer(float)]`. Иначе молча ломается правило 3
контракт-гварда и генерируемый TS-клиент (в `openapi.json` все 39 денежных полей —
`"type": "number"`).

### A-04. Аудиторский след
🔴 **Источник:** Г66 Б-03/Б-05/Б-06: внутримесячная гранулярность, цикл «месяц спустя»,
версионирование совета; внешние опоры SR 11-7, SEC 204-2, MiFID II.

Совет, который человек получил, обязан быть воспроизводим спустя месяц — с теми же
входами и той же версией модели. Это требование к хранению, а не к расчёту.

### A-05. Легаси-Jinja жив на тех же адресах
🟡 **Источник:** H14, замер 19.08.2026, перепроверить.

`app/main.py` продолжает отдавать `dashboard.html`/`planning.html`/`obligations.html`;
единственное, что показывает React, — SPA-блоки nginx. Любой доступ мимо nginx (dev,
`uvicorn` напрямую, health-порт, внутренний адрес контейнера, будущий staging без nginx)
даёт старый интерфейс. 🔴 Прямо касается тестового контура: если он поднимается без
nginx, владелец увидит не тот продукт.

## P2

### A-06. Структурный заслон вместо текстового запрета
🔴 **Источник:** `07_agent_loop_hooks_subagents` — разбор удаления боевой базы Replit
в июле 2025 во время code freeze, дословно: «Yes. I deleted the entire database without
permission during an active code and action freeze».

Вывод переносим на продукт, а не только на вахту: **текстовый запрет обходится
рассуждением, нужен структурный заслон**. Применительно к продукту — инварианты
(`Rt ≥ 0`, ПДН) обязаны быть кодом, отвергающим план, а не строкой в документации.

### A-07. Деградация при внешнем дрейфе
🔴 **Источник:** Г67 (`g67_drift_cash_usability`), Г34 (внутренний дрейф).
Режим деградации — что продукт делает, когда формат выписки у банка сменился, курс
не получен, API недоступен. Смыкается с D-04 («ошибка класса „формат изменился“,
а не пустой результат»).

### A-08. Тестовый и боевой контуры на одном сервере
🔴 **Источник:** `docs/deploy_test_contour.md` (23.09.2026).

Тестовый — `ENVIRONMENT=staging`, имя от sslip.io, без SMTP, **только синтетика**;
боевой — тот же сервер плюс домен, почта и стойкие секреты. Переезжать не придётся.
Разница в конфигурации, а не в дереве.
