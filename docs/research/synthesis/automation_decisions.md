# Решения по инструменту: как вести работу над продуктом

> **Что это.** Прикладной файл слоя `synthesis/` — тот самый «забытый пласт» из `README.md`:
> семь тем про сам инструмент лежат в `raw/`, выжимки по ним в корне `docs/research/`,
> а в решения они не превращались ни разу. Плюс весь измеренный опыт сессий 08–11.09.2026.
>
> **Зачем отдельно от CLAUDE.md.** В `CLAUDE.md` — правила, которые вахта обязана соблюдать.
> Здесь — **обоснования и замеры**, из которых эти правила выведены, и решения о том, что
> автоматизировать механизмом, а что оставить суждению. Правило без замера через месяц
> снимают как «лишнее» — так уже произошло с гейтом поиска (v9.9.5), и это стоило четырёх
> доборов, прошедших с мёртвым каналом.

## 1. Главный урок сессии: цена молчаливого отказа

**Что случилось.** Лимит `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION=400` стоял в нашем
собственном `~/.claude/settings.json`. Канон при этом утверждал, что «лимита нет, число 400 —
наша выдумка». Вахта полтора суток отвечала владельцу, что снимать нечего, — при том что он
прямо просил снять (`PIT-213`, класс `PIT-I`).

**Цена, измеренная в работе:** доборы Д3, Д4, Д5, Д6 прошли с `WebSearch = 0`. Все четыре
закрыли числовую и научную часть (API метаданных и прямой `curl` работают отлично), и все
четыре провалили обнаружение: нормативку, лицензии, зеркала статей, отраслевые данные.
Перепроверки с живым поиском дали по каждому из них минимум одно опровержение собственного
вывода. Самый показательный замер — добор Д5 сам назвал механику отказа:

> «API метаданных находят работу **по известному названию**, но не находят её **зеркала**.
> Поэтому весь блок improper linear models остался без единого прочитанного текста: зеркала
> Dawes 1979 в вебе почти наверняка есть — их нечем было искать.»

Перепроверка Д3 нашла эти зеркала первым же поиском (Dawes 1979 на сайте CMU) — и опровергла
тезис, на котором стояло сравнение нашего SAW с простыми правилами.

**Решение.** 🟢 Гейт мёртвого канала восстановлен механизмом (v9.10.0), но по другому принципу,
чем снятый:

| Свойство | Гейт v9.9.0 (снят) | Гейт v9.10.0 (действует) |
|---|---|---|
| На что смотрит | собственный счётчик до 400 | **дословный текст отказа** харнесса |
| Маркеры `429`, `rate limit` | были — дали два ложняка 09.09.2026 (при 7 и при 42 поисках) | 🔴 **запрещены**, оставлены в тестах регрессией |
| Выдача, упоминающая текст отказа | подорвала бы канал | не поднимает гейт (отказ короткий и без ссылок) |
| Протухание метки по таймеру | было (v9.9.1) — лечило следствие | нет; метка живёт по `session_id` |
| Что делает при срабатывании | блокировал агента молча для владельца | **код 2**: кричит в тот же ход и требует перезапуска сессии |

26 тестов, `tests/test_websearch_budget_hook.py`, проверен живьём четырьмя событиями.

**Правило, которое из этого выведено и должно жить:** канал добычи мёртв → агент **не
запускается**, вахта сообщает владельцу с выводом инструмента. В промпт агенту **не
дописывается** «обходись без поиска».

## 2. Порядок каналов добычи — замерен, не предположен

Сводка по 12 доборам. Каждая строка — наблюдение с HTTP-кодом, не догадка.

| Канал | Где работает | Где бесполезен |
|---|---|---|
| **WebSearch** | обнаружение: зеркала, препринты, нормативка, отраслевые данные, адреса PDF | ничего не скачивает сам |
| **WebFetch** | PDF: **отказывается разбирать, но сохраняет файл на диск и печатает путь** — дальше `Read` с `pages` или `pdftotext` | 🔴 **пересказ PDF малой моделью ошибается в числах** (замер: «40 оценок из 36 статей» против «607 estimates from 150 articles» в тексте) |
| **`curl -sk --http1.1`** с браузерным UA | основная рабочая лошадь: cbr.ru, rosstat.gov.ru, economy.gov.ru, NBER, arXiv, институтские репозитории, consultant.ru | ScienceDirect, Wiley, SSRN, Springer, ResearchGate, ACM DL, MDPI |
| **`r.jina.ai`** | антибот на части сайтов (замер: MDPI 403 → **HTTP 200, 136 504 байта**) | 🔴 **не пробивает Cloudflare и Yandex SmartCaptcha**; бывает пустышкой на 300–500 байт при HTTP 200 |
| **API метаданных** (OpenAlex, Crossref, Unpaywall, Semantic Scholar, EuropePMC) | реквизиты; **Unpaywall отличает «мы не нашли» от «открытого доступа нет вовсе»**; EuropePMC `resultType=core` отдал авторский абстракт наглухо закрытой статьи NEJM | не находят зеркала |
| **Wayback с суффиксом `id_`** | 🟢 **четыре раза выдал полный текст, закрытый на живом сайте**: Hamilton 2023, Samuelson & Zeckhauser 1988, кодбуки PSID, аналитика НБКИ. Адреса снимков искать через CDX API | 404, если снимка нет |
| **Espacenet / OPS / Lens** | Espacenet подтвердил семьи двух патентов из четырёх | Cloudflare JS-челлендж, OPS 403 «Fair Use», Lens 401 и Turnstile |

**Два приёма, которые стоит запомнить отдельно:**

- 🔴 **«HTTP 200» не значит «добыл».** Проверять размер: ScienceDirect отдаёт 403 с телом
  ~1,2 МБ HTML; Springer — 200 с 3 КБ страницы проверки; SSRN `Delivery.cfm` — 200 с HTML
  антибота. Большое тело часто означает как раз отказ.
- 🟢 **DSpace 7:** 405 на `/bitstreams/<uuid>/download`, **200** на
  `/server/api/core/bitstreams/<uuid>/content`. Приём переносится на любой DSpace 7.
- 🟢 **`bsdtar` берёт RAR5** штатно — так открылись объединённые файлы всех волн ОДПФ.
- 🟢 **`Read` с `pages`** читает сканы без текстового слоя, где `pdftotext` возвращает обложку.
- 🟢 **XLSX разбирается** скриптом через `zipfile` + `xml.etree` — `openpyxl` в системе нет.

## 3. Агенты: что измерено про их запуск

### 3.1 Правило одного агента подтверждено ценой

08.09.2026 веерный запуск сжёг **три лимита подряд**: 5 агентов верхнего уровня, каждый плодил
4–7 подагентов, до 35 контекстов одновременно. Из ~16 агентов дошли 4; работа остальных
исчезла, потому что промежуточный результат никуда не сохранялся.

**11.09.2026 правило проверено ещё раз, уже в мягкой форме.** Все 12 доборов шли по одному
агенту. Из них **шесть оборвались по лимиту аккаунта** посреди работы. Итог:

| Что делал агент | Что осталось |
|---|---|
| писал сырьё в файл по ходу (Д9, Д13, Д4-перепроверка) | 🟢 всё записанное; после `/login` работа продолжена с места обрыва |
| держал результат «в голове» до итогового ответа (первый запуск Д7) | 🔴 **ничего**, полный перезапуск |

🔴 **Это и есть главное требование к промпту агента, важнее всех остальных:** сырьё пишется
в файл **до** итогового ответа, дописыванием в конец, без `Write` по большому файлу.

### 3.2 Что даёт возобновление вместо перезапуска

Замер этой сессии: агент, оборвавшийся на лимите, **возобновляется сообщением** с явным
перечислением уже записанных разделов и их номеров строк. Пять агентов так продолжили работу
без потерь. Условие — знать, что именно уже в файле: проверяется `grep` по заголовкам разделов,
а не по отчёту агента.

### 3.3 Права агентов — проверять в новой сессии

- **WebSearch у подагентов есть**, их вызовы идут в тот же счётчик сессии.
- **Bash, Edit и Exa** добавлены в канон `base-kit:researcher` 09.09.2026.
- 🔴 **Правка прав видна только в НОВОЙ сессии** — харнесс читает список агентов один раз
  на старте (`PIT-035`).
- Exa в этой сессии недоступна (сервер отдаёт 404) — канал не пробовался ни одним агентом.

## 4. Что автоматизировать механизмом, а что оставить суждению

Критерий выведен из истории двух гейтов: **ложное срабатывание дороже пропуска**, но
**молчание дороже ложного срабатывания, если цена пропуска — потерянные сутки работы**.

| Задача | Решение | Основание |
|---|---|---|
| Мёртвый канал поиска | 🟢 **механизм**: дословный отказ ловится однозначно | §1 |
| Исчерпание поиска «по ощущению» (пустые выдачи подряд) | 🔴 **суждение вахты**: машинно отличить от узкого запроса не удалось за две попытки, третьей не делать | опыт v9.9.0–v9.9.1 |
| Относительный путь в аргументе читающей утилиты | 🟢 **механизм** (`block-relative-read-path.py`): иначе харнесс задаёт владельцу вопрос, который тот читает как вопрос вахты | `PIT-018` |
| Секреты в коммит | 🟢 механизм (`block-secrets.sh`) | правило 7 CLAUDE.md |
| Расхождение версий в пяти файлах | 🟢 механизм (`preflight`) | правило 4 CLAUDE.md |
| Чекпоинт-архив на сдаче батча | 🟢 механизм (Stop-хук `checkpoint-gate.sh`) | правило 10 CLAUDE.md |
| Первичный материал из внешних источников | 🟢 механизм невозможен, 🟡 **правило + аллоулист**: гейты `CJK-канарейка` и `legacy-паттерны` ловят дословные цитаты, и лечение — аллоулист с обоснованием, а не правка сырья | правило 9 CLAUDE.md |
| Длительность прогона | 🔴 **суждение**: один и тот же срез шёл 40,8 с и 83,4 с без правок кода; перед долгим прогоном смотреть `uptime` | `INV-MACHINE-LOAD`, восемь эпизодов |

## 5. Расход: что стоит знать перед следующей кампанией

Замеры 11.09.2026 по 12 доборам (значения из отчётов агентов):

| Показатель | Диапазон |
|---|---|
| Токенов на агента | 141 000 – 313 000 |
| Вызовов инструментов на агента | 22 – 125 |
| WebSearch на агента | 0 – 28 |
| Обрывов по лимиту аккаунта | 6 из 17 запусков |
| Смен аккаунта за сессию | 5 |

🔴 **Практический вывод для планирования:** один добор ≈ один агент ≈ до 300 тыс. токенов,
и вероятность обрыва посреди работы близка к одной трети. Поэтому длинную кампанию надо
планировать как **последовательность восстановимых шагов**, а не как один прогон: каждый шаг
пишет результат в файл, каждый шаг возобновляем по `grep` заголовков.

**Про Fable 5.1 (проверено 11.09.2026):** на Pro-плане модель **не входит** в лимиты подписки,
только pay-as-you-go usage credits ($10/$50 за 1M токенов против $5/$25 у Opus 5). На Max
входит и расходует до 50 % недельного лимита. Подписка через App Store: credits включаются
**только в веб-версии**. Для этой работы Fable не нужен — узкое место в лимитах и живости
каналов, а не в мощности модели.
