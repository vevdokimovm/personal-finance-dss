## 🔴 Главный вопрос сравнения — один

Не «есть ли у них красивые графики», а:

> **Даёт ли приложение СОВЕТ — или только показывает?**

Почти весь жанр личных финансов — это **трекеры**: они записывают траты, раскладывают
по категориям и рисуют отчёт о прошлом. Решение «гасить долг или копить резерв» человек
принимает сам, без помощи.

FINPILOT отвечает на этот вопрос числом с обоснованием: Avalanche-фильтр по ставкам,
SAW-свёртка по 66 альтернативам, лексикографический выбор с floor резерва, прогноз
SES + Монте-Карло с коридором p10–p90. Поэтому сравнение по числу экранов и цветов
бессмысленно — сравнивать надо по способности **ответить на вопрос о деньгах**.

## Как заполняется карточка приложения

По каждому — одинаковая рамка, чтобы сравнение было сравнением, а не набором впечатлений:

1. **Что делает** одной фразой: трекер / конвертный бюджет / агрегатор счетов.
2. **Как вносятся траты:** вручную, импорт, банковская синхронизация, фото чека.
3. **Категории и бюджеты:** как устроены, есть ли лимиты.
4. **Цели:** есть ли, как считается взнос.
5. **Долги:** учитываются ли, есть ли стратегия погашения.
6. 🔴 **Совет:** есть ли алгоритм, оптимизация, скоринг — или только отчёты.
7. **Прогноз:** предсказание будущего, сценарии, вероятностные оценки.
8. **Деньги:** бесплатно / подписка / разовая покупка, порядок цены.
9. **Платформы и совместный доступ.**
10. **Россия:** доступность в App Store, русский язык, рубль, работа с банками РФ.

## Правила честности разбора

🔴 **Отделять заявленное разработчиком от подтверждённого независимо.** Страница
в App Store — это реклама, а не описание поведения.

🔴 **«В источниках не описано» — законный ответ.** Выдуманная механика хуже пробела:
пробел видно, выдумку — нет.

🔴 **Неоднозначные названия называть неоднозначными.** «Cents», «Envy», «Lumy», «Stats» —
под каждым существует несколько разных приложений. Если не удалось определить, какое
имелось в виду, это пишется прямо, и уточняется у владельца (скриншот иконки).

🔴 **Не заглядывали внутрь — так и сказать.** Ни одно из приложений не установлено
и не оплачено; всё, что известно, — из публичных материалов.
