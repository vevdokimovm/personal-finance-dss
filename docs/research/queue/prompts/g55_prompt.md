# ЧТО СДЕЛАТЬ — по каждой потере отдельный раздел
Для каждой: (а) лучшие алгоритмические/статистические методы с первоисточниками;
(б) замеры их точности (числа, датасет, дата), рядом — число ML из Г53 для сравнения;
(в) открытые реализации (лицензия! GPL/AGPL для закрытого продукта запрещены — помечать);
(г) что нужно из данных/справочников и где их взять в РФ (открыто, лицензия);
(д) оценка: какую долю разрыва с ML закрывает, что остаётся незакрытым;
(е) сложность внедрения (часы/дни порядком) и O-сложность алгоритма.

1. 🔴 ГЛАВНОЕ — категоризация операций со свободным текстом (переводы, СБП, назначение
   платежа). MCC-справочники (НСПК, ЦБ, Visa/Mastercard — открытые списки), нормализация
   имени мерчанта, словари/регулярки, нечёткий поиск (Левенштейн, Jaro-Winkler, триграммы,
   Aho-Corasick), ИНН контрагента → ОКВЭД (ЕГРЮЛ/ФНС открытые данные, datagov уже частично
   на диске: /Users/vasyaevdokimov/raw-originals/finpilot-data/datagov/), БИК/счёт получателя,
   детерминированная «память правок» пользователя (таблица соответствий), периодичность как
   признак. Как это делают open-source PFM (Firefly III rules, Actual Budget rules,
   GnuCash, hledger/beancount importers, ZenMoney — чем устроены). Есть ли замеры accuracy
   rule-based категоризации — искать настойчиво (Г53 не нашла; «не нашли» ≠ «нет»).
   Если замеров нет — предложи протокол своего замера на синтетике.
2. Выписки неизвестного формата — только ссылка на Г47 П5.2, не исследовать.
3. Прогноз дохода/расходов: автоматический выбор метода по скользящей валидации на истории
   пользователя, комбинации прогнозов (M4: простая комбинация сильна), Theta, Croston/SBA/TSB
   для прерывистых рядов, робастные оценки, детекторы разладки (CUSUM, Page-Hinkley,
   Bayesian online changepoint — Adams & MacKay 2007), прогнозные интервалы без ML
   (эмпирические квантили, бутстрап). Что лучше на рядах 3–12 точек — числа.
4. Риск срыва платежа без скоринга: ПДН, подушка в месяцах, стресс-сценарии, правила ЦБ
   (макропруденциальные лимиты), эвристики с замерами предсказательной силы (есть ли
   исследования, где простое правило ПДН/буфер сравнивается со скорингом по AUC).
5. Персональные пороги: эмпирический байес, сжатие Джеймса-Стейна, иерархические априоры
   из популяционной статистики (Росстат, ЦБ) — без обучения на данных наших пользователей.
6. Подписки, регулярные платежи, аномалии: детекция периодичности по интервалам,
   автокорреляция, допуск по сумме; выбросы MAD/IQR/Хампель. Как это делают открытые
   проекты (детекторы подписок в open-source).
7. Текст объяснения без LLM: template-based NLG (SimpleNLG, Reiter & Dale), примеры
   в финансах, объяснимость, воспроизводимость.
