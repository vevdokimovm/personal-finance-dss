   пригодность для коммерческого закрытого продукта.

   лицензия, свежесть. 🔴 Обе ушли из РФ — применимы ли их коды к операциям российских банков
   в 2026 (карты «Мир», СБП).
3. 🔴 Сверка наших копий с первоисточником ЧИСЛОМ: сколько кодов совпало, сколько лишних,
   сколько недостающих, где расходятся наименования и группы. Считай своим кодом, файлы на диске.
4. 🔴 Канал «ИНН → ОКВЭД»: открытые данные ФНС (opendata, egrul.nalog.ru, API «Прозрачный
   бизнес»), Росстат, DaData и аналоги. По каждому: объём, формат, частота, лицензия,
   ограничения на коммерческое использование, ЗАМЕР доступности (HTTP-код, размер, время).
   🔴 Российский корневой сертификат НЕ ставить ни при каких условиях. ERR_CERT_AUTHORITY_INVALID
   = канал закрыт принципиально; искать обход (поддомен, зеркало, r.jina.ai) и честно записать.
5. Справочник БИК ЦБ (канал уже замерен и работает:
   https://www.cbr.ru/vfs/mcirabis/BIKNew/YYYYMMDDED01OSBR.zip, XML ED807, WINDOWS-1251):
   что из него полезно для категоризации и как часто обновлять.
6. Практика: категоризация по ОКВЭД контрагента у банков и бухгалтерских систем (1С, «Мое дело»,
   «Контур»); подводные камни — у ИП ОКВЭД часто формальный и не совпадает с фактической
   деятельностью, есть ли замеры этого расхождения.
