# ПРОДУКТ (минимум)
Человек вводит доход, расходы, кредиты (остаток, ставка, платёж), накопления, цели; может загрузить
банковские выписки. Продукт детерминированным алгоритмом отвечает: как распределить свободные деньги
в этом месяце (досрочное погашение / резерв / цели / инвестиции), с прогнозом и планом во времени.
Не продаёт финансовые продукты (независимость от продавца). Монетизация — подписка.
