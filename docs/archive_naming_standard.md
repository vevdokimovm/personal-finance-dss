# Стандарт именования выходных архивов

**Тип:** нормативный документ · **Введён:** v7.2.0 · **Заменяет:** прежнюю
схему `finpilot_vX_Y_Z_intl.zip`.

---

## 1. Правило

| Назначение | Имя архива | Корневая папка внутри |
|---|---|---|
| Приватный репозиторий (основной) | `personal-finance-dss-vX.Y.Z.zip` | `personal-finance-dss-vX.Y.Z/` |
| Публичное зеркало (открытый код) | `finpilot-vX.Y.Z.zip` | `finpilot-vX.Y.Z/` |

**Разделители — точки, не подчёркивания.** Имя архива = имя репозитория + `-v` +
версия по SemVer.

**Постфикс `_intl` отменён.** Он появился как временная пометка международной
сборки, международной сборки как отдельной ветки не существует, и с тех пор он
только вводил в заблуждение: деплойер каждый раз печатал «имена не по стандарту»
и переименовывал архив сам.

**Имя `finpilot` зарезервировано за публичным зеркалом.** Внутренние сборки
называются по имени приватного репозитория. Раньше архив назывался `finpilot`, а
уезжал в `personal-finance-dss` — деплойер разруливал это через `REPO_MAP` и
честно предупреждал о расхождении. Теперь расхождения нет.

---

## 2. Что это чинит на стороне деплойера

Из лога прогона `deploy.sh v4.0.0`:

```
имена не по стандарту (обработаю, но переименуй у себя — канон это ТОЧКИ):
  finpilot_v6_25_1_intl.zip → канон: personal-finance-dss-v6.25.1.zip
  finpilot_v6_26_0_intl.zip → канон: personal-finance-dss-v6.26.0.zip
  finpilot_v6_26_1_intl.zip → канон: personal-finance-dss-v6.26.1.zip
  finpilot_v7_0_0_intl.zip  → канон: personal-finance-dss-v7.0.0.zip
```

Четыре предупреждения на четыре архива. Скрипт справлялся, но каждое
переименование — это место, где однажды уедет не в ту репу.

|---|---|

---

## 4. Что НЕ меняется

- Версия внутри `app/config.py`, `CHANGELOG.md` и WATCHLOG — та же SemVer.
- Правило «номер вехи = MAJOR».
- Структура архива: **ровно одна** корневая папка, деплойер разворачивает один
  уровень обёртки.
- Содержимое: полный репозиторий, включая `docs/`, `knowledge/`, `tools/`.

---

## 5. Публичное зеркало

`finpilot-vX.Y.Z.zip` собирается **только** из санитизированного дерева:
whitelist-публикация, без личных имён, без ссылок на приватный репозиторий, без
экспертного сырья сертификации. Сборщик — `tools/publish/finpilot_publish_public.sh`;
его санитайзер пока не реализован (пункт в ROADMAP), поэтому до его готовности
публичные архивы этим именем **не выпускаются**.
