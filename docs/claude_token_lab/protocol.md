# Протокол замеров

## Правила, без которых числа несравнимы

1. **Чистая сессия на каждый прогон.** История и кэш искажают и токены, и латентность.
2. **Не меньше трёх прогонов на комбинацию.** Один прогон — это анекдот, а не замер.
3. **Меняем ровно один параметр за раз.** Модель, усилие, длина промпта, набор MCP.
4. **Фиксируем окружение:** версия Claude Code, включённые коннекторы и плагины,
   заполнение контекста на старте (`/context`), время суток.
5. **Медиана, не среднее.** Хвосты латентности длинные, среднее по трём прогонам врёт.
6. **Сырое сохраняем до выводов.** Выгрузка в `raw_harvest/`, потом строка в `results.md`.

## Что замеряем

| Эксперимент | Как | Метрика |
|---|---|---|
| Расход на задачу | `/context` до и после | Дельта по категориям |
| Стоимость сессии | `/usage` | USD, остаток лимитов |
| Латентность по усилию | 5–10 типовых задач FINPILOT, effort low→max, ≥3 прогона | TTFT, полное время, прошли ли тесты |
| Вклад компонентов | Baseline, затем поочерёдно отключать MCP, плагины, скиллы | Дельта в токенах |
| Деградация на длинном контексте | Одна задача при 20/40/60/80% заполнения | Корректность, число ошибок |
| A/B формулировок | Две версии промпта, ≥3 прогона, изолированные сессии | Токены, время, качество по рубрике |
| Активация скилла | `evals/evals.json`: позитив, негатив, edge; 3 прогона на кейс | Precision, recall, trigger-rate |

**Негативные кейсы в евалах обязательны.** Скилл, который срабатывает всегда, так же плох,
как не срабатывающий никогда. Типовая ошибка — гэп в *описании* скилла: описывает WHAT,
а не WHEN.

## Инструменты

```bash
export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318
export OTEL_EXPORTER_OTLP_PROTOCOL=http/json
export OTEL_METRICS_EXPORTER=otlp
export OTEL_LOGS_EXPORTER=otlp
```

Быстрый срез без стенда: `npx ccusage@latest daily`.

## Чего не делать

Не сравнивать свои числа с чужими напрямую. Наш контекст, наши MCP, наша длина промптов.
Чужие замеры задают порядок величины и направление, свои — принимают решение.
