# Лаборатория токенов Claude

Наши собственные эмпирические данные о расходе токенов, латентности и поведении моделей —
в дополнение к чужим замерам из `docs/research/`. Причина существования: значительная часть
операционных чисел публично **не существует** (раздел 9 `docs/claude_operating_table.md`),
а те, что существуют, измерены на чужих задачах.

| Файл | Назначение |
|---|---|
| `protocol.md` | Методика: что и как замеряем, чтобы числа были сравнимы |
| `harvest_prompt.md` | Промпт для сбора служебной информации из любого чата |
| `results.md` | Таблица накопленных замеров |
| `raw_harvest/` | Сырые выгрузки из сессий, дословно |

**Правило.** Сюда идут только собственные замеры. Чужие числа живут в `docs/research/`
и в операционной таблице с указанием источника. Смешивать нельзя: как только своё и чужое
окажется в одной таблице без пометки, через месяц будет непонятно, чему верить.

**Дисциплина исходников.** Сырая выгрузка кладётся в `raw_harvest/` дословно, до того как
из неё сделан вывод. Это то же правило §18, что и для исследований.
