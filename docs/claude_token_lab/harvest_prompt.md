# Промпт для сбора служебной информации из чата

Вставить в любую сессию Claude Code, когда нужен срез состояния. Ответ сохранить дословно
в `raw_harvest/YYYY-MM-DD_<что-мерили>.md`.

---

```
Собери служебный срез этой сессии. Без интерпретаций, только факты и числа.

1. Выполни /context и выпиши разбивку токенов по всем категориям, включая свободное место
   и autocompact buffer. Дай абсолютные числа и проценты.
2. Выполни /usage и выпиши стоимость сессии и остаток лимитов плана.
3. Выполни /memory и перечисли все загруженные CLAUDE.md и rules с путями.
4. Выполни /hooks и перечисли все активные хуки с указанием, какой settings-файл их дал.
5. Если подключены MCP-серверы — выполни /mcp и дай стоимость по каждому.
6. Укажи: версию Claude Code, текущую модель, уровень усилия, включённые плагины.

Формат — markdown-таблицы. Числа не округляй. Если команда недоступна или вернула пусто,
так и напиши: "недоступно" или "пусто". Не подставляй оценку вместо факта.
```

---

## Вариант для claude.ai (где нет слэш-команд)

```
Опиши текущее состояние контекста этого чата настолько точно, насколько можешь наблюдать:
какие файлы Проекта загружены, какие инструменты и коннекторы доступны, есть ли признаки
приближения к лимиту. Явно перечисли, чего ты НЕ можешь измерить изнутри. Не оценивай там,
где нет данных — пиши "данных нет".
```

Второй вариант даёт меньше, но фиксирует важное: границу самонаблюдения модели.
Расхождение между тем, что модель считает загруженным, и тем, что загружено на самом деле, —
само по себе результат.
