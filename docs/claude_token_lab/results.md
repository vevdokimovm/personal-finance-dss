## Наблюдения без чисел

Сюда — то, что заметили, но пока не измерили. Кандидаты в гипотезы.

- Стена контекста («conversation is too long») и стена лимита («out of usage credits») —
  разные вещи. Первая лечится новым чатом, вторая нет. Пойманы одновременно 05.08.2026.
- Code Execution включает авто-суммирование ранних сообщений при подходе к лимиту чата
  и не расходует лимит плана. Проверить эффект на длине жизни сессии.
