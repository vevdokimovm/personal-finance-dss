# Снятый интерфейс Jinja (архив, v8.47.0)

Здесь лежит фронтенд, работавший до вехи 8: шаблоны и статика вместе с `app.js`
на 2658 строк. Каталог **не участвует в сборке и не читается кодом** — это архив
на случай, если понадобится восстановить формулировку, разметку или поведение,
которое переносили на React по памяти.

## Почему снято

`base.html` нёс полную старую оболочку: навигацию по семи экранам вехи 8, селектор
демо-кейсов и `app.js`. Последними на нём жили `/validation` и `/contacts` — и человек,
открывший ссылку на контакты, попадал **в другой продукт**: другая навигация, другой вид,
другой способ выбрать демо-портрет. Разбор — `docs/reports/decisions/
2026-09-04_jinja_removal_and_validation.md`, гейт — `tests/test_no_second_interface.py`.

## Почему архив, а не удаление

Удаление необратимо, и стоп-класс авто-режима его запрещает без владельца. Перенос
в архив даёт тот же результат для продукта (файлы не собираются, не отдаются, не
импортируются) и оставляет возможность вернуться.

🔴 **Удалить каталог целиком — решение владельца.** Разумный момент — после того, как
React-версия отработает на проде хотя бы один релиз: до этого архив дешевле, чем
восстановление по памяти.

жив и покрыт тестами, но публичного экрана под него нет; это инструмент проверки модели.
