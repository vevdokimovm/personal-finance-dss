> Термины проекта одним файлом: метрики модели, домен, процесс, юр. Канон формул —
> `docs/math_model.md`; здесь — быстрые определения для фронта, юриста, нового участника.

## Метрики и модель (v3.0.0)

- **Rt (ресурс)** — свободный денежный поток месяца: `Rt = CF − ΣP`. Баланс в Rt НЕ входит.
  Жёсткий инвариант допустимости: `Rt ≥ 0`.
- **Lt (ликвидность)** — stock-based запас автономии в месяцах: `Lt = B_liq / Σe`. Ортогональна Rt.
- **Dt (долговая нагрузка)** — отношение платежей по обязательствам к доходу; связана с ПДН.
- **ПДН** — показатель долговой нагрузки (регуляторный термин ЦБ). Жёсткий инвариант: `ПДН ≤ 0.40`.
- **BLR** — buffer-to-liabilities ratio, буфер к обязательствам (вспомогательная метрика ранга).
- **CF / Σe / ΣP / B_liq / Bt** — денежный поток; сумма расходов; сумма платежей по долгам;
  ликвидный баланс; общий баланс.
- **SAW** — Simple Additive Weighting: свёртка критериев с весами риск-профиля в `u_score`.
- **Альтернатива** — вариант распределения свободного ресурса (доли: долги/резерв/цели).
  Дискретизация шагом 10% → **|A| = 66**.
- **Риск-профиль (1–5)** — набор весов целей SAW; веса **нестрого** монотонны по профилю
  (плато 0.20 между профилями 2–3) — в тестах сравнивать `>=`, не `>`.
- **Avalanche** — стратегия гашения долгов от самой дорогой ставки; в конвейере — фильтр
  досрочных платежей по `rk ≥ r_bench`.
- **r_bench** — бенчмарк-ставка: ключевая ставка ЦБ × (1 − НДФЛ); фолбэк 0.14 при недоступности
  cbr.ru. Кэш — таблица `cbr_key_rate_cache`.
- **SES** — simple exponential smoothing, прогноз доходов/расходов.
- **Monte-Carlo** — стохастический прогон прогноза; доверительный интервал **80% (p10–p90)**.
- **L_min** — мягкий порог ликвидности при отсеве; по умолчанию 0 (выключен).
- **Портрет** — синтетический или реальный профиль пользователя (доходы/расходы/долги/цели/активы)
  для валидации модели (веха 6).

## Домен и интеграции

- **СБП** — Система быстрых платежей; **НСПК** — её оператор. Реестр участников — источник списка
  банков (`knowledge/product/banks_registry.md`, 226 на 03.2026).
- **Выписка** — экспорт операций из банка. Паттерн РФ: физлица → PDF, юрлица → 1C; плюс CSV/XLSX.
- **1C-формат** — текстовый обменный формат «1CClientBankExchange» (юрлица).
- **Universal-парсер** — стратегия покрытия ~200 банков без парсера-на-банк: роутер детекции
  формата + 4 семейных парсера + словарь колонок (`docs/universal_statement_parser_strategy.md`).
- **Гостевой режим** — работа без аккаунта: данные с `user_id IS NULL` (первоклассный сценарий).
- **Household** — домохозяйство (семейный доступ): `household_id`-оверлей на 6 доменных таблицах.

## Процесс

- **Веха** — крупный этап = мажорная версия (v4–v9), порядок строгий. **Батч** — один заход работы
  = один архив + бамп версии. **Вахта** — смена аккаунта (V/J/M/S) через `docs/WATCHLOG.md`.
- **Указатель «СЛЕДУЮЩАЯ ЗАДАЧА»** —механизм самоприоритизации в шапке `docs/ROADMAP.md`.
- **PIT-xxx** — pitfall, задокументированные грабли (`docs/pitfalls.md`). **BUG-xxx** — карточка бага.
  **ADR** — architecture decision record (`docs/reports/adr/`). **UT-xxx** — юзабилити-тест.
- **Fast / Full / Deep** — ярусы CI (пуш · теги · крон). Гейт покрытия — 90%, жёсткий.
- **Timewarp** — `tools/timewarp/warp.py`, сдвиг часов приложения для ловли календарных мин.

## Юридическое

- **152-ФЗ** — закон о персональных данных РФ. **ПДн** — персональные данные; карта — 
  `docs/pdn_data_map.md`. **Оператор ПДн** — мы после запуска (реквизиты на `/contacts`).
- **НДФЛ** — налог на доходы физлиц (в формуле r_bench).
