## Задача

Завести `PreToolUse`-хук на `Bash`, который **блокирует** команду, где читающая утилита
(`grep`, `cat`, `sed`, `head`, `tail`, `awk`, `wc`, `diff`, `jq`, `rg`, …) получает
**относительный** путь-аргумент.

Такая команда заставляет харнесс эскалировать вопрос владельцу («…only you can approve
running it anyway. Do you want to proceed?»), потому что он не может сопоставить
относительный путь с `deny`-правилами `Read()` — рабочий каталог ему статически неизвестен.
Диалог внешне неотличим от вопроса, заданного вахтой, и в авто-режиме читается как прямое
нарушение приказа «не спрашивать».

За сессию 2026-09-04 сработало больше десяти раз. Разбор и неверный первый диагноз —
PIT-018.

## Приёмка

| # | Команда на входе хука | Ожидаемый код выхода |
|---|---|---|
| 1 | `cd /abs/repo && grep -n "^## " docs/pitfalls.md` | **2** (блок) |
| 2 | `grep -n x /abs/repo/docs/pitfalls.md` | 0 |
| 3 | `cd frontend && npx vitest run` | 0 (не читающая утилита) |
| 4 | `grep -n "docs/pitfalls.md" /abs/repo/f.md` | 0 (путь внутри кавычек — это шаблон, не файл) |

🔴 Проверять **мутацией**, а не запуском на удачном примере: сломать условие
(`if arg.startswith("/")` → `if False`) и убедиться, что случай 2 покраснел. Гейт, который
не краснеет от порчи, ничего не проверяет — урок гейта шрифта v8.39.0.

## Шаг 1 — файл `.claude/hooks/block-relative-read-path.py`

```python
#!/usr/bin/env python3
"""Не выпускать команду, которая заставит харнесс СПРОСИТЬ владельца (PIT-018).

В `.claude/settings.json` настроены `deny`-правила `Read(./.env)` и подобные. Чтобы
решить, попадает ли команда под запрет, харнесс должен знать, КАКОЙ файл она откроет.
Относительный путь-аргумент он сопоставить не может: рабочий каталог команды статически
неизвестен. Разрешить не вправе, отказать молча — тоже, поэтому спрашивает владельца,
а тот читает диалог как вопрос вахты.

Значение имеет путь В АРГУМЕНТЕ читающей утилиты, а не путь у `cd`: первый диагноз назвал
корнем `cd` с относительным путём, обход «делать `cd` абсолютным» был соблюдён и не помог.
`cd` для не-читающих команд (`npx`, `npm`, `python -m`) вопроса не вызывает и не трогается.
"""
from __future__ import annotations

import json
import re
import shlex
import sys

READERS = {
    "grep", "egrep", "fgrep", "rg", "cat", "bat", "head", "tail", "sed", "awk",
    "less", "more", "wc", "diff", "nl", "cut", "sort", "uniq", "jq", "yq", "xxd", "od",
}
FILE_SUFFIX = re.compile(
    r"\.(md|py|ts|tsx|js|jsx|json|css|html|txt|xml|ya?ml|toml|cfg|ini|sh|sql|log)$"
)


def offending_paths(command: str) -> list[str]:
    """Относительные пути-аргументы у читающих утилит.

    Аргументы в кавычках пропускаются: это шаблон поиска, а не файл — в
    `grep -n "^## " docs/pitfalls.md` путь только второй.
    """
    found: list[str] = []
    for segment in re.split(r"&&|\|\||\||;|\n", command):
        try:
            parts = shlex.split(segment.strip(), posix=False)
        except ValueError:
            continue
        if not parts:
            continue
        head = parts[0].rsplit("/", 1)[-1]
        if head not in READERS:
            continue
        for arg in parts[1:]:
            if arg.startswith("-") or arg[:1] in {'"', "'", "$"}:
                continue
            if arg.startswith("/"):
                continue
            if "/" in arg or FILE_SUFFIX.search(arg):
                found.append(arg)
    return found


def main() -> int:
    try:
        payload = json.load(sys.stdin)
    except (json.JSONDecodeError, ValueError):
        return 0
    if payload.get("tool_name") != "Bash":
        return 0
    command = (payload.get("tool_input") or {}).get("command", "")
    bad = offending_paths(command)
    if not bad:
        return 0
    print(
        "PIT-018: относительный путь у читающей утилиты — "
        + ", ".join(sorted(set(bad)))
        + ".\nХарнесс не сможет сопоставить его с deny-правилами Read() и СПРОСИТ "
        "владельца, а в авто-режиме вопросы запрещены приказом.\n"
        "Перепиши аргумент абсолютным путём от корня репозитория. Абсолютный `cd` "
        "не помогает — значение имеет путь в аргументе, а не в `cd`.",
        file=sys.stderr,
    )
    return 2


if __name__ == "__main__":
    sys.exit(main())
```

Затем `chmod +x .claude/hooks/block-relative-read-path.py`.
