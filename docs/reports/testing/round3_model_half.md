## 1. Дизайн прогона

- **Срез дат параметризован:** `model_outcome(today=...)` — v3 гоняется на
  собственном `frozen_today` генератора (2026-07-16, полдень), а не на срезе v2;
  иначе C-кейсы `deadline_today_exact`/`deep_overdue` уехали бы на 14 дней.
- **Слой D не запускает модель:** правило `invalid` зеркально экспертному брифу
  (тип/знак/формат нарушен или обязательное поле отсутствует ⇒ `status=invalid`,
  `dom=none`, нулевые сплиты, колонка `invalid_reason`). Порог ставки 300%
  годовых: 59% МФО — валидно, 1200% слоя D — мусор.
- **id канонические** SP3-{i} (уникальные, стыкуются с ключом координатора).
  Дубли id слоя D — дефект уровня выгрузки: сборщик joined раунда 3 будет
  сопоставлять ответы экспертов **по порядку строк**, не по id (зафиксировано
  здесь и в докстрингах).

## 3. Слой D: вердикт робастности — 600/600, ноль ложных срабатываний

- `invalid` = **ровно слой D** (600/600); вне D невалидных нет (0/11 400) —
  ложноположительных у валидатора ноль, включая пограничные значения из брифа
  (ставка 59%, гиганты 1.9·10⁹, просроченные дедлайны).
- Причины (агрегировано): income не число 100 · кредитные поля битые 250 ·
  непарсящиеся даты 100 (в т.ч. маркер дублей id) · нет ключа deadline 50 ·
  нет поля income 50 · отрицательный доход 50 — все 12 kind пойманы, каждый со
  своей человекочитаемой причиной (юнит-тест `test_every_d_kind_caught_with_reason`).
- Модель не запускалась ни на одной битой записи, прогон без единого исключения.

Прочтение:

- **Статусные инварианты — 0 нарушений из 300 пар** (M2/M3/M4/M5 статус
  неизменен; M1 допускал только deficit→ok — и его не понадобилось).
- **M5 — модель однородна степени 1.** L1 = ровно 9.0 у всех пар означает, что
  каждый рубль сплита масштабировался точно ×10 ((10x−x)/x = 9): решение
  масштабо-инвариантно, абсолютные пороги (лимит АСВ и т.п.) победителя не
  сдвинули ни разу. Это сильный анти-регрессионный якорь для будущих правок.
- **M2/M3: нулевая чувствительность сплита — объяснимо, не подозрительно.**
  Равномерный +1 п.п. на ВСЕ кредиты сохраняет порядок лавины и может только
  добавлять кандидатов в «дорогие» (никого не выкидывает); сумма x_obl — доля
  сетки, от уровня ставки не зависит. Сдвиг ВСЕХ дедлайнов на +6 мес сохраняет
  относительный порядок целей. Неравномерные возмущения (одна ставка, один
  дедлайн) — кандидат в E-каталог v4.
- **Единичные смены доминанты в M1/M4 — граничные и легитимные:** Lt 2.42
  (кромка floor 2.0) и Lt 4.85 (кромка целевой подушки ~4.5–5) — ровно те
  места, где лексикографика передаёт слово SAW.
