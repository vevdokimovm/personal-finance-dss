# Стенд-замер: кросс-платформенная сверка прогонов

**Батч:** Волна 0, п. 0.5 (`docs/model/model_completion_plan.md` §4) ·
**Инструмент:** `tools/model_validation/cross_platform_check.py`
**Датасет:** синтетический, `PortraitGenerator(seed=20260813, version=2).generate()`,
12 000 портретов на платформу (полностью воспроизводимо по seed)

## Зачем

Модель обещает детерминированную воспроизводимость по seed
(`knowledge/model_validation/README.md`: «совпадение доказано сверкой rt/kind/risk
до копейки»), но эта гарантия раньше проверялась только МЕЖДУ ВЕРСИЯМИ генератора
на одной платформе, никогда — между разными ОС/архитектурами. Floating-point
арифметика теоретически может разойтись между libm/BLAS разных платформ
(порядок суммирования, округление последнего бита) — если бы это случилось,
модель давала бы разные советы разным пользователям на разном железе при
идентичном входе, что подрывает саму идею детерминированной СППР.

## Метод

`run_planning()` (полный пайплайн: generate/evaluate/filter/rank/crisis + график
погашения ADR-016) на 12 000 портретах, сериализация ключевых числовых полей
(`Rt`/`Lt`/`Dt`/`income_cv`, id и utility победителя, наличие кризисного плана,
`interest_saved`/`months_saved` графика погашения) в фиксированном формате
(6 знаков после запятой — без этого `repr(float)` сам по себе может отличаться
между платформами при равном значении), sha256 по каждому портрету + один
агрегатный хеш по всему прогону.

## Платформы

| Платформа | ОС/архитектура | Python |
|---|---|---|
| Локальная машина владельца | macOS 15.7.7, **Intel (x86_64)** | 3.13.1 |
| Docker-контейнер `python:3.13-slim` | Linux 6.12 (linuxkit), x86_64 | 3.13.15 (тот же образ, что CI) |

Оба образа — реальные раздельные среды (разные ядро/libc/сборка Python), не
косметическое различие. Контейнер соответствует `Dockerfile`/CI (`python:3.13-slim`,
`.github/workflows/ci.yml` — `ubuntu-latest`, Python 3.13).

## Результат (12 000 портретов на платформу)

| Метрика | macOS (Intel) | Linux (контейнер) |
|---|---|---|
| Портретов | 12 000 | 12 000 |
| Исключений | 0 | 0 |
| Агрегатный sha256 | `354b7369690ad57e33ef948a7dd624c58f08f252dfde73ea2d54c6666497bbdf` | `354b7369690ad57e33ef948a7dd624c58f08f252dfde73ea2d54c6666497bbdf` |

**Хеши идентичны бит-в-бит.** 0 расхождений на 12 000 портретов между Intel Mac
и Linux — воспроизводимость по seed подтверждена межплатформенно, не только
внутри одной ОС.

## Ограничения, которые нужно проговорить честно

- Проверены Intel Mac (x86_64) и Linux x86_64 (CI-образ) — это то, что просил
  исходный пункт плана («Linux / Intel Mac / CI»). Apple Silicon (arm64) не
  проверен: другая архитектура процессора, другой набор инструкций для
  floating-point — за рамками этого пункта, но не гарантирован автоматически
  тем же результатом. Стоит проверить, если/когда разработка перейдёт на
  arm64-машину.
- Проверка детерминизма ВЫЧИСЛЕНИЙ, не идентичности ОКРУЖЕНИЯ целиком (версии
  системных библиотек внутри `python:3.13-slim` могут со временем меняться при
  пересборке образа — воспроизводимость проверена на снимке образа на дату
  замера, не гарантирована навечно).

## Решение

Гарантия воспроизводимости по seed подтверждена межплатформенно. Отдельного
действия не требуется — механизм проверки (`cross_platform_check.py`) можно
перезапускать при подозрении на расхождение (например, после смены базового
Docker-образа или мажорного апдейта Python).

## Связанные документы

внутриплатформенной сверки между версиями генератора.
