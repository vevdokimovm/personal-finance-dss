# Стенд-замер: инфляционная индексация целей дальше ~3 лет

**Батч:** 0.1, Волна 0 · **Канон:** v3.5.0 → v3.6.0 · **ADR:** `adr_013_goal_inflation_indexing.md`
**Инструмент:** `tools/model_validation/goal_inflation_benchmark.py`
**Датасет:** `knowledge/model_validation/portraits_v2_seed20260702.jsonl.gz`, 12 000 портретов

## Зачем

Карта качества модели (`docs/model/model_quality_scorecard.md` ось 5 «адекватность»,
ось 10 «полнота охвата») называет инфляционную индексацию длинных целей единственной
**систематической** (не спорной, не требующей экспертного консенсуса) ошибкой во всей карте:
цель на 10–30 лет (пенсия, образование детей), посчитанная в номинальных рублях, — заведомое
занижение суммы, а не позиция, с которой можно не согласиться.

Индексация меняет $\Delta_s = T^{tgt}_s(1+\pi)^{\tau_s/12} - C_s$ (§11.3) → $S_n(a)$ →
потенциально argmax SAW-ранжирования. По правилу методологии (только по предзарегистрированной
гипотезе, прецедент ADR-006/ADR-009) — решение подтверждается замером, не только рассуждением.

## Метод

На каждом портрете датасета v2 (Rt>0, есть цели — 7512 из 12000) прогоняем полный цикл
generate → evaluate → filter → rank **дважды**, переключая
`app.core.goals_priority.GOAL_INFLATION_RATE`:

- **nom** (базлайн, до батча 0.1): rate = 0.0 — `inflated_target_amount` тождественна,
  поведение идентично v3.5.0;
- **idx** (текущий код, батч 0.1): rate = 0.04 (официальная цель Банка России по инфляции),
  горизонт 36 месяцев.

## Интерпретация

**Локализация — главный результат замера.** Ноль портретов без цели дальше 36 месяцев
сменили победителя. Это исполняемое доказательство того, что эффект бьёт ровно в заявленный
угол (длинные цели), а не размазан по всей модели побочным эффектом реализации — именно то,
что отличает целевой фикс от regression.

**Footprint мал (0.23%), и это ожидаемо, не тревожно.** Индексация НЕ добавляет новый критерий
и не меняет веса SAW — она уточняет входную величину ($\Delta_s$) для 53% портретов, но
доминанта решения (floor-резерв, затем SAW) в подавляющем большинстве случаев определяется
другими факторами (текущий поток, долговая нагрузка), а не тонкой правкой одного слагаемого
$S_n$. Малый footprint на 4015 «затронутых» портретах говорит о том, что индексация обычно НЕ
переворачивает решение — она делает его точнее там, где переворачивает (17 портретов) и честнее
показывает потребность там, где не переворачивает (остальные 3998 — сумма в объяснении
пользователю крупнее, план не меняется).

**Магнитуда там, где меняется, — не шум.** p95 сдвига сплита 32 684 ₽ — заметная для
пользователя сумма, не округление. Максимум 75 506 ₽. Это резонно: горизонт 20-30 лет при 4%
годовых даёт множитель $(1.04)^{25} \approx 2.67$ — цель почти утраивается в номинале, разница
может быть существенной долей месячного потока.

## Решение

Индексация принимается без изменений формулы/ставки/горизонта, предложенных в ADR-013.
Разбор альтернатив (константа vs динамическая ставка, порог 36 мес) — там же.
