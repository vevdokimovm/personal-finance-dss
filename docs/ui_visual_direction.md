# FINPILOT — три визуальных направления главного экрана (Э1)

Экран: дашборд распределения свободного денежного потока — свободный поток (Rt), ликвидность в
месяцах автономии (Lt), ПДН (Dt), распределение по долгам/резерву/целям (a\*), прогноз баланса
p10–p90. Планка — Т-Банк / Сбер / Альфа, аудитория РФ.

Все три — **один и тот же экран, одни и те же реальные числа** (профиль «anna» из
`docs/reference_profiles.md`), на **одной структуре токенов** (`--c-*`, `--r-*`, `--shadow-*` —
как в `frontend/static/css/styles.css`, плюс новые `--fs-*`/`--sp-*`, которых в текущем styles.css
нет вовсе — см. `docs/design_tokens_audit.md`). Различаются палитрой, типографикой, сеткой **и
плотностью данных/тоном** — не только цветом.

Макеты — статичный HTML, открываются прямо в браузере, у каждого есть переключатель тема
светлая/тёмная в правом верхнем углу:

- [`docs/ui_directions/calm/dashboard.html`](ui_directions/calm/dashboard.html) — «Спокойный»
- [`docs/ui_directions/precise/dashboard.html`](ui_directions/precise/dashboard.html) — «Выверенный»
- [`docs/ui_directions/confident/dashboard.html`](ui_directions/confident/dashboard.html) — «Уверенный»

Палитра/типографика/сетка каждого направления подробно расписаны в соседнем `notes.md`, токены —
в `tokens.css` той же папки.

## Сравнение

| | Спокойный | Выверенный | Уверенный |
|---|---|---|---|
| Ведущее прилагательное брифа | спокойный | выверенный | уверенный |
| Плотность данных | низкая — 3 метрики + 1 полоса + график | высокая — ledger-строка (7 чисел) + 4 метрики + таблица распределения + таблица прогноза | средняя — 4 метрики + полоса + график, без сырых чисел и таблиц |
| Тон | воздух, мягкие формы, тишина | точность, границы вместо теней, «бланк» | масштаб, один сигнатурный hero-жест |
| Шрифт | Manrope (один на всё) | IBM Plex Sans + IBM Plex Mono (точечно, для чисел в столбик) | Golos Text (один на всё, кириллица «родная») |
| Герой-число | 48px | 38px (самое компактное) | 58px (самое крупное, сигнатура) |
| Радиусы | 10/16/24/32 — мягкие | 4/6/10/14 — почти прямые | 8/12/20/28 + 32 у hero |
| Тени | мягкие многослойные | почти отсутствуют, граница вместо тени | почти отсутствуют, кроме одной приподнятой у hero |
| Undertone нейтралей | тёплый | холодный | тёплый, с зелёным подтоном |
| Персона, которой ближе всего | R01 (56 лет, простота) | «бухгалтер» (проверить каждую цифру) | никакая конкретно — «продающий» первый экран |

Контраст текст/фон и функциональных границ проверен на WCAG 2.2 AA (`docs/ui_ux_design_standard.md`
A11Y-01: ≥4.5:1 текст, ≥3:1 крупный текст/нетекстовые элементы) для всех шести палитр (3
направления × 2 темы) — расчётом по относительной яркости, не на глаз. Мобильная раскладка
проверена на 375px (Chrome DevTools) — реflow без горизонтального скролла на все три направления.
Кнопки/тумблер темы — ≥44px.

## О чём стоит знать перед выбором

**Разночтение с `docs/frontend_milestone8_plan.md` (Шаг 1.2, промпт для Claude Design).** Тот
промпт запрещает Inter, glassmorphism и «светящиеся карточки» — это защита от типовых дефолтов
генеративного инструмента. Но `docs/ui_visual_design_brief.md` §1.2 прямо благословляет Inter
(«отличный выбор, уже используется»), а §1.5 разрешает glassmorphism точечно (1–2 поверхности). Я
сознательно **не использовал Inter** ни в одном направлении (везде другая гарнитура с хорошей
кириллицей) — Inter самый частый дефолт SaaS-дизайна что у AI-инструментов, что у людей, и то же
самое предостережение по существу есть в обоих канон-документах, только сформулировано по-разному.
Glassmorphism нигде не использован как эффект стекла (`backdrop-filter`); в «Уверенном» есть один
тонкий радиальный градиент-акцент на hero — это не то же самое, что `.glass-panel` в текущем
`styles.css`. Стоит явно решить, какой документ обновлять, чтобы разночтение не всплывало на
каждом следующем заходе в дизайн.

**Прогноз p10–p90 — не дословная цифра из reference_profiles.md.** В файле нет строки с готовой
траекторией (там только текущие I/E/ΣP/Rt/Lt/Dt/BLR/a\*/U). Траектория во всех трёх макетах —
иллюстративная проекция: медиана = Rt × месяцы, ширина интервала растёт по `sqrt(t)` до ±35% к 12
месяцам, что соответствует документированному методу движка (SES + Monte-Carlo, 80% ДИ,
`docs/algorithm_stack.md`), но не числа из реального вызова `/api/planning/forecast`. Все текущие
показатели (не прогнозные) на экране — дословно из реального профиля «anna».

**Побочная находка, не по этому запросу:** в `docs/` одновременно лежат `math_model_v3_0_0.md`,
`math_model_v3_1_0.md` и `math_model_v3_5_0.md`, а `CLAUDE.md` называет каноном только v3.0.0.
Дизайна это не касалось, но стоит знать.
