# Направление «Спокойный» (Calm)

Ведущее прилагательное из `docs/ui_visual_design_brief.md` §0: **спокойный**. Низкая плотность,
щедрый воздух, один герой-номер на экран, вторичные метрики нарочно тише.

## Палитра

Тёплая нейтральная шкала (лёгкий подтон в сторону бумаги/дерева, не голубой).

## Типографика — Manrope

Одна гарнитура на всё (брифу §1.2 это ближе, чем display+body+mono), хорошая кириллица, тёплый
геометрический характер без резкости.

| Токен | px | Роль |
|---|---|---|
| `--fs-xs` | 13 | мелкие подписи |
| `--fs-sm` | 14 | вторичный текст |
| `--fs-base` | 16 | тело |
| `--fs-md` | 18 | под-заголовки, hero-статы |
| `--fs-lg` | 22 | заголовки панелей |
| `--fs-xl` | 28 | — |
| `--fs-2xl` | 38 | значения метрик |
| `--fs-3xl` | 48 | герой-число (самое скромное из трёх направлений — здесь тон держится на пространстве, не на размере) |

## Сетка и интервалы

База 4px, но с уклоном к большим ступеням: `4/8/12/16/24/32/48/64`. В разметке сознательно
использованы верхние ступени (24–64px) между секциями и внутри hero — это и есть «воздух» из
брифа §1.3, а не только цифра в токене. Радиусы крупные и мягкие: `--r-sm:10 --r-md:16 --r-lg:24
--r-xl:32` — ни одного острого угла на экране.

## Почему плотность ниже, а не только цвет другой

Три метрики после hero показаны как три спокойные карточки в ряд, без общей сетки на 4+ — в
отличие от «Выверенного», где та же информация плюс сырые входные числа даны в 7-колоночной
ledger-строке. Здесь ни одного дополнительного числа сверх того, что нужно для истории «резерва
нет — деньги идут в подушку».
