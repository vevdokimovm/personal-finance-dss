# Направление «Уверенный» (Confident)

Ведущее прилагательное: **уверенный**. Герой-число — сигнатурный элемент направления (в духе
frontend-design: «большая уверенная цифра» как тезис экрана, не шаблонный «большое число + мелкая
подпись + градиент» — здесь градиент есть, но один, тонкий и только на hero).

## Палитра

Тёплый тёмный уголь с лёгким зелёным подтоном (перекликается с акцентом, не нейтрально-серый, как
два других направления).

| Токен | Тёмная | Светлая | Роль |
|---|---|---|---|
| `--c-bg` | `#12140F` | `#F7F8F6` | фон страницы |
| `--c-bg2` / `--c-surface` | `#1B1E15` | `#FFFFFF` | карточки |
| `--c-border` | `rgba(220,230,210,.09)` | `#DEE2DB` | тонкий разделитель |
| `--c-border-hl` | `#616849` (3.16:1) | `#818B72` (3.36:1) | функциональная граница |
| `--c-text` | `#F3F5EE` | `#171A13` | основной текст |
| `--c-text2` | `#C2C7B5` | `#49503F` | вторичный |
| `--c-text3` | `#95997F` | `#6C7460` (4.58:1) | подписи |
| `--c-accent` | `#3FCB80` | `#0C7A43` (5.08:1) | текст/ссылки |
| `--c-accent-hl` | `#57DA93` | `#0F8A4C` | крупные числа, самый насыщенный из трёх направлений |

## Типографика — Golos Text

Кириллица «родная» (шрифт разработан для кириллицы, не адаптирован с латиницы) — уверенный
геометричный характер без заёмного западного дефолта. Одна гарнитура на всё, но с самым большим
шагом шкалы из трёх направлений.

| Токен | px | Роль |
|---|---|---|
| `--fs-xs` | 13 | подписи |
| `--fs-sm` | 14 | вторичный |
| `--fs-base` | 16 | тело |
| `--fs-md` | 18 | hero-статы |
| `--fs-lg` | 23 | заголовки панелей |
| `--fs-xl` | 30 | значения метрик |
| `--fs-2xl` | 42 | — |
| `--fs-3xl` | 58 | герой-число — самое крупное из трёх, сигнатурный элемент направления |

## Сетка, радиусы, сигнатура

База 4px, средний наклон: `4/8/12/16/20/28/40/56`. Радиусы средние везде (`--r-sm:8 --r-md:12
--r-lg:20 --r-xl:28`), но у hero-карточки отдельный `--r-hero:32` и единственная на весь экран
приподнятая тень `--shadow-hero` с едва заметным акцентным оттенком — это и есть «одна смелая
деталь» по правилу frontend-design «потратить дерзость в одном месте»: у остальных карточек тени
почти нет, только тонкая граница.

## Почему плотность и тон отличаются, а не только цвет

Средняя плотность между «Спокойным» и «Выверенным»: те же 4 метрики, что и у «Выверенного», но
без сырой ledger-строки и без таблиц — только карточки с крупными числами. Тон держится на
масштабе типографики и одном хero-жесте (радиус + тень + лёгкий радиальный акцент-градиент на
фоне), а не на количестве видимых чисел.
