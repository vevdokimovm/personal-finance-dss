# Юридический пакет FINPILOT

Финальный комплект юридических документов и UI-текстов для запуска сервиса FINPILOT.
Всё заполнено, плейсхолдеров нет.

## Принятые параметры

- **Оператор:** сервис FINPILOT (без реквизитов юрлица/ИП — по решению на этапе MVP).
- **E-mail для всех обращений и отзыва согласий:** finpilot.help@proton.me
- **Дата вступления в силу:** 29 июля 2026 г.
- **Хранение данных:** на территории РФ, трансграничная передача не осуществляется.
- **Аудитория:** 18+.

## Состав пакета

| Документ | Формат | Куда на сайте |
|---|---|---|
| Политика обработки персональных данных | md + docx | страница `/privacy` |
| Пользовательское соглашение | md + docx | страница `/terms` |
| Политика использования файлов cookie | md + docx | страница `/cookies` |
| Согласие на обработку персональных данных | md + docx | у чекбокса регистрации |
| Согласие на обработку финансовых данных | md + docx | у чекбокса подключения финданных |
| Согласие на рекламную рассылку | md + docx | у необязательного чекбокса |
| UI-тексты (баннер, дисклеймер, чекбоксы) | md | элементы интерфейса |

- `md/` — рабочие версии для вставки на сайт (рендерятся любым markdown-движком, таблицы — GFM).
- `docx/` — официальные экземпляры для печати и предъявления.

## Как разместить

1. Политику, Оферту и Cookie-политику — отдельными страницами; ссылки на все три в футер каждой страницы.
2. Три согласия — рядом с соответствующими чекбоксами при регистрации/подключении (тексты чекбоксов — в `ui-snippets.md`).
3. Cookie-баннер — всплывашка при первом заходе.
4. Дисклеймер 39-ФЗ — продублировать на самой странице с рекомендациями, а не только в оферте.
5. Ни один чекбокс не отмечен заранее; каждое согласие логируется с датой/временем на сервере.

## На будущее (не блокирует запуск)

- **Домен + почта на домене** — когда возьмёшь домен, e-mail и адрес сайта стоит обновить во всех документах.
- **Переход на ООО** — при росте меняется только блок «Оператор» (реквизиты вместо «сервис FINPILOT»); тело документов остаётся.
- **Защита от утечки** — главный реальный риск для финсервиса; данные в РФ + шифрование + разграничение доступа + план реагирования на инцидент (уведомление в 24 часа).
- **Уведомление в РКН** — сознательно отложено на этапе MVP; при росте видимости/аудитории стоит подать (бесплатно, ~30 минут).
