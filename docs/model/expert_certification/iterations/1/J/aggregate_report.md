# Экспертное заключение по набору из 12 000 финансовых портретов

**Дата анализа:** 2026-07-07 · **Методология:** детерминированный экспертный rule-set (диагностика → долговая стратегия → lump-sum → месячный waterfall → режим выживания)

## Параметры модели
| Параметр | Значение |
|---|---|
| Порог «дорогого» долга | ставка > r_bench + 2 п.п. (лавина: макс. ставка первой) |
| «Дешёвый» долг | ставка < r_bench → платить по графику, разницу инвестировать (арбитраж) |
| Целевая подушка | 6 мес. оттока (риск 1–2), 4 мес. (риск 3), 3 мес. (риск 4–5) |
| Доля акций в портфеле | 0/20/40/60/80 % по риск-профилю 1–5 |
| ПДН | ≥ 50 % — повышенный, ≥ 80 % — критический |
| Инструменты по горизонту цели | <12 мес — накопительный счёт; 12–36 — вклад/ОФЗ; >36 — портфель |
| Кризисный делеверидж | закрытие/частичное гашение из резерва, если p/A > дефицит/подушка или полный ремонт потока посилен; floor — 2 мес. расходов |

## Экспертные замечания по данным
1. **Долговая нагрузка синтетически экстремальна:** у 3 641 из 8 000 типовых портретов платежи ≥ 150 % дохода — генератор не связывает кредиты с доходом. Поэтому доминирующая рекомендация по набору — реструктуризация/рефинансирование, а не оптимизация портфеля; это свойство данных.
2. Подтверждено соответствие JSONL ↔ карточкам (SP-00006 сверен построчно); все суммы месячные, ₽.
3. Накопления целей учтены как обособленные от подушки; при survival-режиме показаны как резерв 2-го эшелона.
4. Контроль сохранения сумм: месячные бакеты = max(0, FCF), нарушений 0; lump ≤ deployable, нарушений 0.
