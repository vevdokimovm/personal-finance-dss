# Итерация 1 — архив артефактов первой сертификации (датасет v1)

> Перенесено из личных архивов четырёх аккаунтов 2026-07-17 (батч v6.15.0),
> постфактум: раскладка `iterations/` появилась только к раунду 2. Здесь —
> первичные улики раунда 1 как есть; вердикты и разбор той эпохи живут в
> исторических отчётах: `docs/reports/testing/independent_expert_review_2026_07.md`,
> `docs/reports/testing/expert_agreement_v3_1_0.md`,
> `docs/reports/retrospectives/model_calibration_retrospective_2026_07.md`.

Особенности формата раунда 1 (до появления CSV-брифа):

- Ответы — **jsonl** с богатой записью (`monthly_plan`, `lump_sum_plan`,
  `debt_plan`, `goal_plan`, `diagnostics`, `flags`, `verdict`) вместо позднейшего
  CSV `id,status,dom,...`; агрегирование в доминанты делал стенд.
- **Слепоты ещё не было:** записи содержат поле `kind` — эксперты видели типы
  портретов. Слепой протокол введён с раунда 2.
- Имена файлов — авторские, без нормализации (улики не переименовываем).
- У V и S сохранились два слоя: финальная сдача (корень) и полный рабочий набор
  из их собственных архивов (`full/`) — версии различаются (в `full/` jsonl с
  обоснованиями ~30 МБ). Вложенные zip распакованы, в репо архивов-в-архиве нет.
- Всё тяжёлое (`*.jsonl`, `*.csv`) сжато gzip побайтово — суммарно 18 МБ
  вместо ~110 МБ сырыми.

`run_metadata` в раунде 1 не собирались (введены обязательными с брифа v3).
