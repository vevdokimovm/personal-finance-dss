# Методология независимой финансовой экспертизы
### Распределение ресурсов домохозяйства по 12 000 портретам · дата анализа 2026-07-05

Документ формализует правила, по которым независимый эксперт (роль: банкир / персональный финансовый советник) строит рекомендацию по распределению средств для каждого портрета. Методология разработана **до и независимо от** оцениваемой СППР: используются только входные данные портрета; Rt/Lt/ПДН и иные производные показатели рассчитаны экспертом самостоятельно.

---

## 1. Входные данные портрета

Доход `I` (₽/мес), расходы без кредитов `E` (₽/мес), ликвидный резерв `B`, бенчмарк-ставка `r_bench` (безрисковая альтернатива размещения), риск-профиль `risk ∈ {1..5}`, минимальная ликвидность `L_min`, кредиты `{остаток A_j, ставка r_j, платёж m_j}`, цели `{цель T_k, накоплено C_k, дедлайн d_k | ∅}`.

## 2. Производные метрики эксперта

| Метрика | Формула | Смысл |
|---|---|---|
| Обслуживание долга | `M = Σ m_j` | обязательные платежи |
| Свободный поток | `FCF = I − E − M` | распределяемый ресурс |
| ПДН (DSTI) | `M / I` при `I > 0` | долговая нагрузка |
| Обязательные траты | `burn = E + M` | месячная стоимость жизни |
| Запас прочности | `runway = B / burn` | месяцы автономии |
| Целевая подушка | `max(L_min, k(risk) · burn)` | см. §4 |
| Требуемый взнос в цель | `(T_k − C_k) / mes(d_k)` | при наличии дедлайна |

Месяцы до дедлайна: `mes(d) = max(1, round((d − today) / 30.4375))`.

## 3. Триаж (порядок проверки строгий)

1. **`I = 0` → кризис «нет дохода».** Режим сохранения ликвидности: инвестиции и пополнение целей заморожены, по кредитам — минимальные платежи и превентивный запрос реструктуризации/каникул. Досрочное закрытие кредита из резерва допускается только если оно *удлиняет* запас прочности и оставляет `runway ≥ 6 мес.` (кэш при нулевом доходе — опциональность, расставаться с ним можно только за строгое улучшение выживаемости). Рекомендуется сокращение необязательных расходов на 20–30% и фокус на восстановлении дохода.
2. **`FCF < 0` → кризис «дефицит».** Сначала проверяется *оздоровление из резерва*: жадный перебор кредитов по убыванию `m_j / A_j` (максимум снятой нагрузки на рубль); погашение принимается, если после него остаётся резерв `≥ 3 мес.` нового `burn`. Если набор погашений выводит `FCF ≥ 0` — портрет считается оздоровлённым и дальше идёт по стандартному маршруту (§5) с фиксацией погашений в разовом плане. Порог 3 мес. (а не 6) обоснован: положительный поток после оздоровления сам восстанавливает подушку, тогда как отказ от оздоровления гарантированно проедает резерв. Если оздоровление невозможно: при `ПДН ≥ 100%` первоочередная мера — реструктуризация (приоритет — кредит с максимальной ставкой), затем сокращение расходов; при `ПДН < 100%` — сокращение расходов до нуля дефицита, при `ПДН ≥ 50%` дополнительно реструктуризация. Цели и инвестиции заморожены.
3. **`ПДН ≥ 50%` и есть кредиты дороже бенчмарка → «перегрузка».** Агрессивный режим: подушка только стартовая (1 мес.), весь остальной поток — лавинным методом в дорогие кредиты (режим «уменьшение платежа» для снижения ПДН), цели приостановлены, показано рефинансирование. Если при `ПДН ≥ 50%` все ставки ≤ бенчмарка — режим стандартный (досрочные погашения дешёвого долга ценностно-отрицательны), с флагом и советом рефинансирования.
4. Иначе — **стандартный маршрут** (§5–6).

## 4. Целевая подушка безопасности

`k(risk) = 3 + 0.75·(5 − risk)`: консервативный профиль (1) → 6 мес., агрессивный (5) → 3 мес. Диапазон 3–6 мес. соответствует стандартной консультационной практике; наклон отражает толерантность к риску ликвидности.

## 5. Разовое размещение избытка резерва (`B > подушка`)

Порядок (итеративно, т.к. погашения снижают `burn` и целевую подушку):

1. **Дорогие кредиты** (`r_j > r_bench`) — лавинным методом, полное или частичное погашение (частичное — «с сокращением срока»: максимизирует экономию процентов). Досрочное погашение — безрисковая доходность `r_j`, строго доминирующая над размещением под `r_bench`.
2. **Разовые пополнения целей с дедлайнами** (только вне агрессивного режима): ближайшие дедлайны первыми; пополнение до уровня, при котором остаточный требуемый взнос помещается в месячный поток.
3. **Инвестиционный транш** остатка по риск-профилю (§7).

Кредиты со ставкой `r_j ≤ r_bench` **не гасятся досрочно** ни разово, ни ежемесячно: деньги выгоднее размещать под бенчмарк (арбитраж ставок).

## 6. Ежемесячный водопад (`FCF > 0`)

1. **Стартовая подушка** — до 1×`burn` (весь поток).
2. **Токсичный долг** (`r_j ≥ r_bench + 5 п.п.`) — весь остаток потока в кредит с максимальной ставкой.
3. **Подушка до целевой** (пропускается в агрессивном режиме).
4. **Цели с дедлайнами** — требуемые взносы, ближайший дедлайн первым; недофинансированная цель получает флаг `GOAL_AT_RISK` (лечится разовым пополнением §5.2, переносом срока или снижением цели).
5. **Умеренно дорогой долг** (`r_bench < r_j < r_bench + 5 п.п.`) — лавинным методом.
6. **Инвестиции** остатка (§7); при наличии бессрочных целей остаток целево маркируется под них.

Обоснование позиции целей выше умеренно дорогого долга: взнос по дедлайну — обязательство с нефинансовой ценой срыва; токсичный долг тем не менее приоритетнее любых целей (гарантированные ≥15 п.п. сверх бенчмарка).

## 7. Инвестиционные профили (доли остатка)

| risk | депозиты/накоп. | облигации (ОФЗ/корп.) | акции | альтернативы |
|---:|---:|---:|---:|---:|
| 1 | 70% | 30% | — | — |
| 2 | 50% | 40% | 10% | — |
| 3 | 30% | 40% | 30% | — |
| 4 | 15% | 35% | 45% | 5% |
| 5 | 10% | 20% | 60% | 10% |

Ориентиры доходности: депозиты ≈ `r_bench`; облигации ≈ `r_bench + 1–2 п.п.`; акции — долгосрочно `r_bench + 3–5 п.п.` при существенной волатильности.

## 8. Константы методологии

| Константа | Значение | Роль |
|---|---:|---|
| Порог токсичности | `r_bench + 5 п.п.` | приоритет токсичного долга над целями |
| ПДН повышенный / высокий / критический | 30% / 50% / 80% | флаги и триаж |
| Стартовая подушка | 1 мес. `burn` | ступень 1 водопада |
| Резерв после оздоровления (дефицит) | ≥ 3 мес. | §3.2 |
| Резерв после погашения (нет дохода) | ≥ 6 мес. | §3.1 |

## 9. Форма результата

Для каждого портрета: `status`, метрики (§2), `lump_plan` (разовые погашения / пополнения целей / инвесттранш), `monthly_plan` (подушка, досрочные погашения по кредитам, взносы по целям, инвестиции с разбивкой), таблица целей с требуемыми и плановыми взносами, флаги, текстовое заключение эксперта.

## 10. Ограничения

Экспертиза статична (один горизонт принятия решения, без прогноза доходов и переоценки во времени), не моделирует налоги, страхование, досрочные комиссии и графики амортизации; ставки кредитов трактуются как эффективные годовые. Цели без дедлайна финансируются остаточно и не получают требуемого взноса по построению. Заключения по кризисным портретам предполагают доступность стандартных банковских инструментов (реструктуризация, каникулы, рефинансирование).

## 7.1. Инструменты по горизонту (дополнение)

| Горизонт | Инструмент |
|---|---|
| Подушка | накопительный счёт с мгновенным доступом |
| Цель ≤ 12 мес. | накопительный счёт / депозит до 12 мес. (без рыночного риска) |
| Цель 12–36 мес. | депозиты, фонды денежного рынка, короткие ОФЗ |
| Цель > 36 мес. или без срока | портфель по риск-профилю (§7) |

Инструментальная разметка не меняет суммы распределения — только способ размещения каждого бакета.
