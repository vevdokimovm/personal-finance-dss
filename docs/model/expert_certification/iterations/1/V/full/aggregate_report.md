## 1. Методология и константы

Полная формализация — `expert_methodology.md` (зафиксирована до обработки данных). Константы:

| Константа | Значение |
|---|---|
| Целевая подушка по риску 1…5 | 6.0 / 5.25 / 4.5 / 3.75 / 3.0 мес. обязательных трат |
| «Дорогой» долг | ставка > r_bench; «токсичный» — > r_bench + 5 п.п. |
| Пороги ПДН | 30% повышенный · 50% высокий · 80% критический |
| Стартовая подушка | 1 мес.; резерв после оздоровления: ≥3 мес. (дефицит) / ≥6 мес. (нет дохода) |
| Аллокация по риску 1…5 | деп/обл/акц/альт: 70/30/0/0 · 50/40/10/0 · 30/40/30/0 · 15/35/45/5 · 10/20/60/10 |
| Инструменты по горизонту | ≤12 мес.: депозит; 12–36: ден. рынок/короткие ОФЗ; >36 или без срока: портфель по риску |
| Порядок водопада | стартовая подушка → токсичный долг → подушка → цели по дедлайнам → умеренно дорогой долг → инвестиции |
