## (ж) Проблемы (номер · доказательство · последствие)

**P1. Долг оторван от дохода.** corr(доход, платежи): Пирсон +0.036, Спирмен +0.038; ПДН>100% у 6510 из 11555 носителей дохода (56%). Методичка требует задавать долг через ПДН×доход. → Тест-сет проверяет почти исключительно кризисную ветку модели; водопад распределения (подушка→долг→цели→инвестиции) получает ~19% покрытия.

**P2. Кризисная доминанта.** FCF<0 у 9697 (80.8%). Реалистичная популяция (слой A) так выглядеть не может; это не «стресс-слой по дизайну», потому что перекос сидит в базовом `plain` (мед. FCF -86 388 ₽). → Метрики качества модели будут измерять качество антикризисных советов, а не аллокации.

**P3. Инверсия меток kind.** См. (е): `overleveraged` мед. ПДН 68% < `plain` 129%. → Стратифицированные по kind метрики и «доли правильных ответов по типам» невалидны; сравнение экспертов по типам вводит в заблуждение.

**P4. Аннуитетная несогласованность.** 1482 кредитов (6.1%) не амортизируются (платёж ≤ месячному проценту — вечный долг); имплайд-срок: p50 31 мес., max 738 мес., >360 мес. — 16, <6 мес. — 20. Поля срока в схеме нет. → Модель, считающая графики/переплату, получает противоречивый вход; interest-only не помечен как осознанный кейс слоя C.

**P5. Цели оторваны от дохода и капнуты.** corr(доход, Σцелей) = -0.000; k = цель/годовой доход: p50 2.6, p99 16.3, max 55; 25% целей вне заявленного k∈[0.2, 5]. → Достижимость целей в основном определяется генератором, а не решением модели.

**P6. Жёсткие капы (нарушение §1.5 методички).** Остаток кредита: max 2 999 947 ₽, 823 значений в полосе 2.9–3.0 млн — стена на 3 000 000. Цель: max 1 999 962 ₽, 642 значений в полосе 1.95–2.0 млн — стена на 2 000 000. → Хвосты срезаны, стресс-кейсы больших сумм (в т.ч. заявленные ~10⁹) отсутствуют.

**P7. Дискретный бенчмарк.** r_bench принимает ровно 5 значений (10.00%, 12.81%, 14.00%, 15.96%, 20.00%) — §1.4 требует непрерывный. Ставка ровно == бенчмарку: 16 кредитов (кейс есть, закрепить в слое C). → Ось spread покрыта решёткой; пороговые эффекты «дорогой/дешёвый» тестируются в 5 точках вместо континуума.

**P8. Хрупкая ликвидность.** 3544 портретов (<1 мес.), 65% — меньше 3 мес., медиана 1.9 мес. → В связке с P1–P2 почти весь сет — «кризис», ветки размещения излишка почти не тестируются (кроме kind=huge_bliq).

**P9. Дедлайны без углов.** Мин 2.8 мес., макс 58.9 мес. (~4.9 года): нет «сегодня», нет просроченных, нет 5–10-летних горизонтов из каталога слоя C и §1.3. → Ветки просрочки/немедленного исполнения не покрыты.

**P10. Дыры дискретного покрытия.** Целей на портрет: нет 5–7 (скачок 4→8); кредитов ≤ 4; l_min ≡ 0 на всём сете (мёртвая ось); current==target «в копейку»: 0; перефинансирование max 1.20 (слабое); нет пучка целей с одним дедлайном. → Ряд задекларированных граничных кейсов слоя C фактически отсутствует.

**P11. Нет слоёв B/D/E.** Один случайный слой + 9 детерминированных типов; validity-записей нет (ID уникальны: True, отрицательных сумм/NaN: 0), метаморфических пар нет. → Устойчивость к мусору и монотонность (M1–M5) на этом сете не проверяемы.

**P12. Нет version-header (§4).** Первая строка JSONL — обычный портрет. → Ревью экспертов нельзя жёстко привязать к версии; итерации несравнимы.

## (з) Рекомендации к следующей итерации генератора

1. **ПДН-first:** сначала ПДН из бакетов ЦБ/НБКИ (хвост >80% — единицы процентов), затем M = ПДН×доход, затем аннуитет с явным сроком n∈[6,360] и остатком из формулы. Это одним ходом закрывает P1, P2, P4 и половину P3.
2. **Метки kind назначать пост-фактум** по фактическим метрикам (диагноз), а не как параметр генерации; либо генерить условно и валидировать реализацию (закрывает P3).
3. **Непрерывный r_bench** (равномерно/бета на [0.10, 0.22]); кейс «ставка == бенчмарк» оставить детерминированным в слое C (P7).
4. **Цели:** target = k × годовой доход, k∈[0.2, 5]; дедлайны смесью {null ≈ 25%, сегодня, просроченные, 3 мес.–10 лет}; кластер целей с одним дедлайном; снять капы 2М/3М — лог-нормальные хвосты (P5, P6, P9).
5. **Слой B (LHS/Sobol)** по нормализованным осям с pairwise-отчётом; добить n_goals 5–7 и l_min > 0 (P10).
6. **Слой D** (битые даты, отрицательные суммы, дубли ID, NaN, пустые массивы) и **слой E** (пары M1–M5) — по 5% (P11).
7. **Первая строка JSONL — метаданные** (dataset_version, seed, конфиг слоёв, корреляционная матрица) (P12).
8. **CI-приёмка из §3 методички.** Текущий сет: KS дохода **проходит** (p = 0.98); допуск корреляций **фейлится** (доход~платежи +0.04 при целевой связке через ПДН); доли диагностических состояний **фейлятся** (FCF<0 = 81%); аннуитетная согласованность **фейлится** (93.9%).
