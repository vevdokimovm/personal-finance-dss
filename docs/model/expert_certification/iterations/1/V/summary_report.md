## 1. Ключевой вывод о наборе данных

У **9697 из 12 000 (81%)** портретов свободный денежный поток (доход − расходы − платежи по кредитам) **отрицательный уже на входе**. Это свойство генератора: платежи по кредитам разыгрываются без привязки к доходу. Следствие для оценки СППР: на большинстве кейсов «правильный ответ» — не оптимизация распределения, а антикризисные меры (реструктуризация, сокращение расходов, оздоровление баланса из резерва).
