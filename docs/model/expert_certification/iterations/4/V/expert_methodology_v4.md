## 1. Базовые определения

| Величина | Формула | Комментарий |
|---|---|---|
| Свободный поток (FCF) | `income_total − expense_total − Σ monthly_payment` | по §1 брифа |
| Месячный burn | `expense_total + Σ monthly_payment` | **мой выбор базы ликвидности**: подушка должна покрывать все обязательные оттоки, включая платежи по кредитам, — при потере дохода дефолт по кредитам наступает раньше голода |
| ПДН | `Σ monthly_payment / income_total` | при `income = 0` и наличии платежей — ПДН = ∞ (флаг `pdn_undefined`) |
| Запас ликвидности, мес | `bliq / burn` | при `burn = 0` — ∞ (флаг) |
| Целевая подушка | `RESERVE_MONTHS[risk] × burn` | см. §2 |

Вся диагностика (FCF, ПДН, запас, статус) считается **по входному состоянию
портрета**. Разовые ходы (`lump`) — рекомендация движения капитала; месячный
сплит подчиняется бюджетному контракту §4.4 брифа: `res+debt+goal+inv ≤
max(0, FCF входного состояния)`. Высвобождение платежей после закрытия кредита
разовым ходом отражается в вердикте и планах, но не раздувает месячные бакеты
сверх входного FCF (допущение A7 в журнале).

## 2. Константы (не меняются по ходу обработки)

| Константа | Значение | Обоснование |
|---|---|---|
| `RESERVE_MONTHS` | риск 1→6, 2→5, 3→4, 4→3, 5→3 мес | консервативному инвестору — больший буфер; ниже 3 мес не опускаюсь ни для кого |
| `STARTER_MONTHS` | 1.0 мес | стартовый минимум ликвидности до агрессивного гашения долгов |
| `EXP_SPREAD` | +2.0 п.п. над `r_bench` | досрочное гашение — гарантированная «доходность» = ставке кредита; вклад под `r_bench` — до НДФЛ на проценты и с риском переоформления; спред 2 п.п. покрывает налог и трение |
| `TOXIC_RATE` | ≥ 45% годовых | заведомо МФО/штрафная зона; такой долг разрушает баланс быстрее, чем любой разумный актив растёт |
| `PDN_LEVELS` | комфорт ≤ 0.30 · повышенный (0.30–0.50] · критический > 0.50 | ориентиры ЦБ/НБКИ |
| `PDN_DELEVERAGE` | 0.50 | при ПДН > 0.50 включается режим разгрузки: досрочно гасим самый дорогой долг, даже если формально «дешёвый» |
| `DEBT_SHARE` | 0.70 | доля остатка потока на досрочное гашение дорогих долгов (после стартового резерва) |
| `RES_SHARE_THIN` | 0.50 (0.20 при токсичном долге) | доля потока в резерв, пока ликвидность < 1 мес |
| `SPLIT_PERP` | 0.50 | делёж хвоста потока между бессрочными целями и инвестициями |
| `MIN_LUMP` | 10 000 ₽ | разовые ходы мельче — операционный шум, не предлагаю |
| `LUMP_FLOOR_TOXIC` | 1 × burn | ради токсичного долга подушку можно осушить до 1 месяца |
| `LUMP_FLOOR_EXP` | целевая подушка | дорогие долги гасим только излишком сверх целевой подушки |
| `GOAL_CLOSE_HORIZON` | 12 мес | разово закрываем из излишка только цели с дедлайном ≤ 12 мес |
| `EXCESS_PLACE_BUFFER` | +1 × burn сверх цели | излишек размещаем, только если он превышает целевую подушку более чем на месяц burn |
| `REPLAN_MONTHS` | 12 мес | просроченный/сегодняшний дедлайн незакрытой цели → перепланирование на 12 мес (флаг `replan`) |

Инструменты по горизонту (влияют на текст рекомендаций, не на бакеты):
< 1 года — накопительный счёт / короткий вклад; 1–3 года — вклады/ОФЗ с
погашением к сроку; > 3 лет — ОФЗ + корпоративные облигации, доля акций по
риск-профилю {1: 0%, 2: 20%, 3: 40%, 4: 60%, 5: 80%}.

## 3. Критерий `invalid` (по §2 брифа, строгая трактовка)

Запись невалидна, если **хотя бы одно** из:

1. Отсутствует любой из 8 обязательных верхнеуровневых ключей
   (`id, income_total, expense_total, obligations, goals, bliq, r_bench, risk_tolerance`).
2. Денежное поле / ставка не является JSON-числом (строка «50000», `"0,2"`,
   булево, `null`, NaN/Infinity — дефект типа/формата). Числовые поля с
   отрицательным знаком там, где знак невозможен (`income, expense, bliq,
   amount, monthly_payment, target, current < 0`) — дефект знака.
3. `risk_tolerance` — не целое из 1..5 (целочисленный float 3.0 читаю как 3 —
   однозначно; 3.5 или строка — дефект).
4. `r_bench` вне [0; 1) — отрицательная или ≥ 100% безрисковая ставка — дефект.
5. Ставка кредита > 3.00 (300% годовых) — мусор по правилу §2.2. Ставки
   в (2.92; 3.00] — выше потолка ПСК, но по правилам брифа читаемы: оцениваю
   по существу как токсичные.
6. У цели отсутствует **ключ** `deadline` — дефект; явный `null` — валидная
   бессрочная цель. Строка дедлайна, не являющаяся реальной календарной датой
   `YYYY-MM-DD` (включая «30 февраля»), — дефект формата.
7. `obligations`/`goals` — не списки, либо элемент — не объект, либо в элементе
   отсутствует обязательный ключ.
8. Строка JSONL не парсится как JSON.

Любой дефект в любом элементе ⇒ вся запись `invalid` (совет по частично
мусорной записи не даю): `status=invalid, dom=none`, все суммы 0, `lump=0`.
Дубли `id` дефектом **не являются**: каждая строка оценивается по своим числам,
мерж запрещён, ответ позиционный.

Пограничные, но читаемые значения (ставка 292%, доход 8 млн, нулевая подушка,
нулевой доход, дедлайн в прошлом, `target == current`) — **валидны**, §2.4.

## 4. Классификация долгов

Для каждого валидного кредита:

- **токсичный**: `interest_rate ≥ TOXIC_RATE (45%)`;
- **дорогой**: `interest_rate > r_bench + EXP_SPREAD`;
- **дешёвый**: `interest_rate ≤ r_bench + EXP_SPREAD` — досрочно не гасим,
  минимальные платежи, свободные деньги работают под `r_bench` и выше.

Дополнительно помечаю **interest-only/растущий долг**: если `monthly_payment ≤
amount × interest_rate / 12` — платёж не покрывает проценты (флаг `interest_only`,
усиливает приоритет гашения этого кредита в вердикте).

## 5. Разовые ходы из накоплений (`lump`)

Последовательность, каждая ступень ограничена реально доступной ликвидностью
и `MIN_LUMP`:

1. **Токсичные долги** — по убыванию ставки, полное или частичное гашение,
   пока `bliq` не опустится до `LUMP_FLOOR_TOXIC = 1 × burn`.
2. **Дорогие долги** — по убыванию ставки, из излишка сверх целевой подушки
   (`LUMP_FLOOR_EXP`).
3. **Закрытие целей**: если после долгов остаётся излишек сверх целевой
   подушки и у цели дедлайн ≤ 12 мес, а остаток до цели ≤ излишка — закрыть
   (доплата из подушки), ближайшие дедлайны первыми.
4. **Размещение излишка**: остаток сверх (целевая подушка + 1 × burn) — разовый
   перевод в инвестиции по риск-профилю, только если не осталось токсичных и
   дорогих долгов.

`lump` в CSV — сумма всех ходов. При `burn = 0` полы равны нулю (весь `bliq` —
излишек). Правила одинаковы для `ok` и `deficit`; для `invalid` ходов нет.

## 6. Месячный водопад (при FCF > 0; при FCF ≤ 0 бакеты нулевые)

Состояние долгов и подушки для водопада берётся **после** разовых ходов
(гашёные разово кредиты не гасим повторно), бюджет — входной FCF.

1. **Стартовый резерв.** Если ликвидность < 1 мес: в `res` идёт
   `RES_SHARE_THIN` потока (0.20 при живом токсичном долге), но не больше
   разрыва до целевой подушки.
2. **Долги.** Есть токсичный → весь остаток в `debt`. Иначе есть дорогой, либо
   ПДН > 0.50 при любом долге (режим разгрузки), → `DEBT_SHARE = 70%` остатка в
   `debt` (цель — самый дорогой кредит, лавина по ставке). Иначе `debt = 0`.
3. **Цели с дедлайном.** Требуемый взнос `req = max(0, (target − current) /
   months_left)`, месяцы — от даты среза 2026-07-18, минимум 1; просрочка/
   сегодня при недоборе → `REPLAN_MONTHS = 12` и флаг. Финансирую жадно по
   возрастанию дедлайна из остатка потока.
4. **Докапитализация резерва.** Если подушка всё ещё ниже целевой — весь
   остаток в `res` (подушка важнее бессрочных целей и инвестиций).
5. **Хвост.** Есть бессрочные цели → 50/50 между `goal` и `inv`; нет → всё в
   `inv` (инструменты — по горизонту и риск-профилю).

Округление: бакеты до целых рублей вниз, остаточные рубли — в крупнейший бакет;
инвариант `res+debt+goal+inv ≤ floor(max(0, FCF))` гарантирован конструкцией.
Разовые ходы: **каждый ход приводится к целым рублям (floor) в момент хода**,
`lump` = сумма целых сумм ходов — не округление float-итога. Канон зафиксирован
после референс-сверки §9, поймавшей расхождение ±1 ₽ при обратном порядке.

## 7. `dom`, статус, вердикт

- `status`: `ok` при FCF ≥ 0, `deficit` при FCF < 0, `invalid` — §3.
- `dom` = крупнейший из {`debt`, `reserve`, `goals+` = goal+inv}; при равенстве
  приоритет `debt > reserve > goals+`; все нули → `none`.
- Вердикт — одна строка по-русски, из статуса и флагов (дефицит, токсичный
  долг, разгрузка ПДН, тонкая подушка, перепланирование целей и т.п.).

## 8. `confidence` — детерминированное правило движка

Старт 5, за каждый признак «кейса на кромке» −1, клип в [1; 5]:

| Признак кромки | Порог |
|---|---|
| Поток около нуля | `abs(FCF) < 0.02 × max(income, 1)` |
| Кредит у границы дорогой/дешёвый | `min_кредиты abs(rate − (r_bench + 0.02)) < 0.02` |
| Кредит у границы токсичности | `abs(rate − 0.45) < 0.05` |
| Подушка у целевой отметки | `abs(liq_months − target_months) < 0.5` |
| ПДН у порога разгрузки | `abs(ПДН − 0.50) < 0.03` |
| Слабая доминанта | `(top − second) < 0.10 × FCF` при FCF > 0 |
| Горящий дедлайн | ближайший дедлайн ≤ 60 дней от среза либо просрочен при недоборе |

`invalid` — всегда 5: критерий §3 однозначен и не зависит от порогов.
