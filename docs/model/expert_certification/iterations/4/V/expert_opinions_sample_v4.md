# Выборка обоснований — 40 портретов (раунд 4)

**Отбор:** детерминированный, каждая 300-я строка входа (позиции 0, 300, …, 11700), зафиксирован в методологии §9 до обработки.

**Ручная сверка.** Каждый портрет пересчитан независимой референс-реализацией «на бумаге» (прямое повторение формул методологии отдельным кодом, без общих внутренностей с движком). Первый прогон сверки поймал расхождение на 5 из 40 портретов — ровно 1 ₽ в `lump` из-за порядка округления (движок приводит к целым рублям каждый разовый ход, референс округлял итоговую сумму). Канон зафиксирован: **каждый ход — целые рубли, `lump` — сумма целых**. После фиксации канона — **40/40 совпадений** по всем полям (`status, dom, res, debt, goal, inv, lump`). Расхождений по существу решений не найдено.
