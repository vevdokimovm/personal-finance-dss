# Журнал допущений — раунд 4

Каждое место, где данные или бриф допускали больше одной честной трактовки.
Все счётчики посчитаны программно (движок ведёт счётчики допущений;
`aux/run_summary.json`, `aux/stats.json`). Формат: что неоднозначно → варианты
→ выбор и почему → затронуто записей.

- **A1. Bool вместо числа** (`income_total: true`, пример SP4-00250).
  Варианты: (а) трактовать `true`=1; (б) дефект. Выбор: **дефект, класс
  near-miss** — «истина» вместо дохода финансово нечитаема, но синтаксис почти
  верен (уверенность 3). Затронуто: 20 значений.
- **A2. Числоподобная строка** (`'0,2'` в ставке, SP4-00008). Варианты:
  распарсить с заменой запятой; дефект. Выбор: **дефект near-miss** — чинить
  формат = додумывать данные, что прямо запрещено брифом §2.1. Затронуто: 13.
- **A3. Лишние поля.** Служебное поле `id` присутствует в 100% кредитов и целей
  (в схеме §1 его нет); верхнеуровневых лишних полей — 0. Варианты: дефект;
  игнорировать. Выбор: **игнорировать** — систематический артефакт CRM, чтению
  не мешает. Затронуто: все записи с кредитами/целями.
- **A4. Пустая строка в имени** кредита/цели. Выбор: валидна с флагом
  `empty_name` (имя не влияет на финансовую читаемость; нечисловое имя —
  дефект). Затронуто: 0 (не встретилось).
- **A5. `r_bench` вне [0; 1]** → дефект (доходности >100% в легальном контуре
  РФ нет). Затронуто: 0 (не встретилось).
- **A6. Ставки за потолком.** Бриф: >300% — мусор; потолок ПСК ≈292%.
  Неоднозначна зона (292%; 300%]: легально невозможна, но «не мусор» по брифу.
  Выбор: **(292; 300] — валидный токсичный долг с флагом `suspicious_rate`;
  >300% — дефект** (3.01 — near-miss, 12.0 и −0.15 — грубый). Затронуто:
  запретная зона — 0 записей (в датасете пусто, см. P9 ревью); дефектных
  ставок — 108 (3.01×25, 12.0×39, −0.15×44).
- **A7. Формат даты дедлайна.** Выбор: строго `YYYY-MM-DD` + календарная
  проверка; календарно невозможная при верном формате (`2026-02-30`,
  `2026-13-45`) — near-miss-дефект; иной формат (`'не скажу'`) — грубый дефект.
  Datetime-строки трактовались бы как дефект (не встретились). Затронуто: 111
  (99 невозможных дат + 12 мусорных).
- **A8. `amount = 0` при `monthly_payment > 0`.** Выбор: доверять платежу
  буквально (в burn), долг закрыт, флаг. Затронуто: 0 (не встретилось).
- **A9. Отсутствие ключа `deadline` ≠ `null`** (бриф §2.3 задал явно). Выбор:
  отсутствие ключа — дефект записи; явный `null` — бессрочная цель. Затронуто:
  39 записей-дефектов; бессрочных целей 9 229.
- **A10. Доходность в проверке достижимости целей = 0%** (только взносы).
  Варианты: капитализировать под `r_bench`; 0%. Выбор: **0%** — консервативная
  верхняя оценка требуемого взноса, инвестдоход не гарантирован; при
  капитализации часть моих «недостижимо» станет «на грани». Затронуто: 28 071
  активная датированная цель.
- **A11. Знаменатель запаса ликвидности = полный burn** (расходы + платежи).
  Вариант «только расходы» даёт более красивые месяцы, но при потере дохода
  платежи по кредитам не исчезают. Затронуто: все 11 400 валидных.
- **A12. Разовые ходы в дефиците.** Бриф разрешает lump при дефиците, но не
  говорит когда. Выбор: токсичные гасятся всегда (растут быстрее подушки);
  дорогие — **только если серия закрытий выводит поток в ≥0 и остаётся ≥3
  месяцев нового burn**; излишки/цели в дефиците не трогаются (кэш = runway).
  Затронуто: 598 дефицитных строк с закрытиями, «вылечившими» бюджет.
- **A13. Дубли id** — две независимые строки, ответ позиционный, без мержа
  (бриф §2.5). Флаг `duplicate_id`. Затронуто: 260 строк (130 пар).
- **A14. Строка, не читаемая как JSON,** → `invalid` с пустым `id` (позиция
  сохраняется). Затронуто: 0 (не встретилось).
- **A15. `risk_tolerance` как целочисленный float** (`3.0`) принимается.
  Затронуто: 0 (не встретилось).
- **A16. Отрицательные денежные значения** (доход, остаток, платёж, суммы
  целей, подушка) — сломанный знак → дефект, не «модуль» и не «ноль».
  Затронуто: 115 записей.
- **A17. Просроченный дедлайн** (и «сегодня») — валидная цель с потребностью
  «немедленно»: месячный взнос = весь остаток, достижимость к дедлайну — нет
  (если не закрыта разовым ходом); рекомендация — пересмотр срока. Затронуто:
  100 просроченных + 100 «сегодня».
- **A18. Перефинансированная цель** (`current > target`) — цель закрыта,
  излишек не изымается (консервативно: деньги уже «в конверте» цели).
  Затронуто: 60 целей.
- **A19. «Киты» и стресс-магнитуды** (доход ≥5 млн; поля ≥10⁹) — валидны и
  считаются теми же правилами (шкалонезависимость), только флагируются.
  Затронуто: 585 китов, 100 стресс-строк.
- **A20. Содержимое `id` не валидируется** (echo как есть). Отклонений от
  шаблона SP4-NNNNN: 0.
- **A21. Бюджет месячных бакетов = входной поток** (буквальное чтение §1+§4.4
  брифа). После lump-закрытий реальный поток выше (платежи высвободились), но
  высвобожденные платежи в бакеты **не** кладутся — они упомянуты в вердикте.
  Иная трактовка (бюджет = пост-lump поток) дала бы формальные нарушения
  контроля сумм у координатора. Затронуто: 2 256 строк с закрытиями долгов
  (из 3 841 строки с lump).
- **A22. Составные дефекты**: запись «грубая», если хотя бы один дефект грубый;
  near-miss (уверенность 3) — только если **все** дефекты near-miss.
  Затронуто: 25 записей с 2+ классами дефектов; 164 записи чистого near-miss.
