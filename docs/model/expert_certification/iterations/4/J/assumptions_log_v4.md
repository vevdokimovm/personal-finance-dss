# Журнал допущений (§10)

> Каждое место, где данные допускают больше одной честной трактовки, — отдельная
> пронумерованная запись: что неоднозначно, какие трактовки возможны, что выбрано
> и почему, сколько записей затронуто (посчитано программно на срезе v4).
> Констант это не меняет — они заморожены в `expert_methodology_v4.md`.

---

**A1 — источник разовых ходов: только `bliq`, не накопления по целям.**
*Неоднозначно:* «реально доступная ликвидность» (§3.3 брифа) — это подушка
`bliq` или ещё и `current_amount` по целям? *Трактовки:* (а) только `bliq`;
(б) `bliq + Σ current_amount` (цели тоже ликвидны). *Выбор:* (а). Накопленное по
цели — earmarked и, возможно, в неликвидных инструментах; советник по телефону не
разбирает целевые копилки ради гашения. *Затронуто:* 10 135 валидных портретов
имеют цель с `current_amount > 0`. Пример влияния A1b: 60 перефинансированных
целей (`current > target`), чей излишек я **не** увожу в `lump` по умолчанию
(только помечаю `overfunded_goal` и советую перенаправить). Ключевая зона
расхождения — см. `disagreement_forecast_v4.md`.

**A2 — подушка и запас ликвидности считаются от `monthly_burn` (расходы + платежи
по кредитам), а не от одних расходов.** *Неоднозначно:* что должна покрывать
подушка при потере дохода. *Трактовки:* (а) только расходы на жизнь; (б) расходы
+ обязательные платежи по долгам. *Выбор:* (б) — при потере дохода долг не
исчезает до реструктуризации, и подушка обязана держать весь обязательный отток.
Это консервативнее: цели-подушки больше, «здоровье» запаса ниже. *Затронуто:*
8 944 валидных портрета с платежами по кредитам > 0 (у остальных выбор
безразличен). Прямо влияет на `reserve_target` и порог разовых ходов.

**A3 — дефект в любом вложенном элементе делает `invalid` всю запись.**
*Неоднозначно:* можно ли «спасти» запись с чистым верхним уровнем, но одним
битым кредитом/целью. *Трактовки:* (а) отклонить всю запись; (б) отбросить
битый под-элемент, оценить остальное. *Выбор:* (а) — §2.1 брифа прямо запрещает
чинить и додумывать; частичная оценка = додумывание. *Затронуто:* из 600 дефектных
**421** имеют полностью корректный верхний уровень (доход/подушка/риск читаемы),
и только вложенный дефект их «топит». При трактовке (б) эти 421 попали бы в
скоринг — это самая крупная развилка по критерию `invalid`.

**A4 — потолок «мусорной» ставки — строго > 3.00 (300%).** *Неоднозначно:* граница
между «дорогим легальным долгом» и дефектом. *Трактовки:* порог 2.92 (легальный
ПСК), 3.00 (headline §2.2), где-то между. *Выбор:* > 3.00, т.к. данные пусты в
зазоре [2.92, 3.01] — любой порог там эквивалентен, а near-miss методички —
именно «301% при пороге 300%». *Затронуто:* 64 записи со ставкой > 3.0 (значения
3.01 и 12.0) → `invalid`. Ставка 2.92 остаётся валидным токсичным долгом.

**A5 — отсутствие ключа `deadline` ≠ явный `null`.** *Неоднозначно:* как читать
цель без поля `deadline`. *Трактовки:* (а) считать бессрочной (как `null`);
(б) считать дефектом. *Выбор:* (б) — §2.3 брифа: отсутствие ключа — дефект, а
явный `null` — валидная бессрочная цель. *Затронуто:* 39 записей с целью без
ключа `deadline` → `invalid`; при этом 9 229 целей с явным `null` корректно
приняты как бессрочные.

**A6 — токсичный долг = ставка ≥ 35% ИЛИ спред ≥ 20 п.п. над `r_bench`.**
*Неоднозначно:* где кончается «дорогой» и начинается «токсичный». *Трактовки:*
только абсолютный порог; только спред; их дизъюнкция. *Выбор:* дизъюнкция — при
низком `r_bench` карта 36% токсична по абсолюту, при высоком `r_bench` МФО
токсичен по спреду. *Затронуто:* 2 581 портрет с ≥1 токсичным долгом (2 965
токсичных кредитов). Влияет на глубину разового хода (токсичный — до `starter`,
дорогой — до полной подушки).

**A7 — при дефиците всё равно даю разовый ход и вердикт.** *Неоднозначно:* что
выдавать, когда `fcf < 0`. *Трактовки:* (а) только нули; (б) месячные нули, но
разовые ходы и вердикт — если уместны. *Выбор:* (б) по §3 брифа. Дефицитник с
большой подушкой и токсичным МФО обязан гасить его из подушки — это главный ход.
*Затронуто:* 2 361 дефицитный портрет получает `lump > 0` (гашение токсичного/
дорогого долга из подушки), несмотря на нулевые месячные бакеты.

**A8 — нулевой доход и `burn = 0` — валидные граничные случаи, не дефект.**
*Трактовки:* считать 0 дефектом vs читаемым значением. *Выбор:* читаемое (§2.4).
При `income = 0` → `pdn = ∞`, флаг `no_income`; при `burn = 0` → `reserve_target =
0`, запас `∞`. *Затронуто:* 100 портретов с нулевым доходом, 35 — с нулевым
обязательным оттоком.

**A9 — просроченный дедлайн: catch-up (требуемый взнос = весь остаток) + флаг.**
*Неоднозначно:* как финансировать цель, чей срок уже прошёл. *Трактовки:*
(а) игнорировать цель; (б) требовать остаток немедленно; (в) растянуть заново.
*Выбор:* (б) с флагом `overdue_goal` и советом пересмотреть срок, если нереально.
*Затронуто:* 200 просроченных целевых позиций (дедлайн ≤ срез, остаток > 0).

**A10 — отрицательный знак денежного поля — дефект, а не читаемое значение.**
*Неоднозначно:* §2.4 разрешает «нулевой доход», но молчит про отрицательный.
*Трактовки:* (а) читать как есть; (б) дефект знака (§2.1). *Выбор:* (б) —
отрицательный доход/остаток/ставка не имеют финансового смысла. *Затронуто:* 159
дефектных записей содержат отрицательный знак хотя бы в одном поле (карточки
рендерят их без `!`, но по §2.1 это дефект).

**A11 — стресс-магнитуда (поле ≥ 1e8) обрабатывается по существу, без обрезки.**
*Неоднозначно:* считать ли доход 2 млрд/мес дефектом. *Трактовки:* (а) кап/отказ;
(б) обрабатывать (правила масштабно-инвариантны). *Выбор:* (б) с флагом
`stress_magnitude` — §2.4 прямо называет доход 8 млн читаемым, а мои правила
инвариантны к масштабу (проверка M5). *Затронуто:* 405 валидных портретов.

**A12 — горизонт цели считаю в месяцах как `round(days / 30.44)`, минимум 1.**
*Неоднозначно:* дробные месяцы до дедлайна. *Трактовки:* округление вверх/вниз/к
ближайшему; календарные месяцы. *Выбор:* к ближайшему по 30.44 дн, пол = 1, чтобы
требуемый взнос не делился на 0 и не взрывался на «завтра». *Затронуто:* 28 158
целей с дедлайном (влияет на требуемый месячный взнос второго-третьего знака).
