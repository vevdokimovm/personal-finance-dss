# Метаданные прогона (раунд 4)

| Поле | Значение |
|---|---|
| Роль | независимый эксперт по личным финансам (РФ, 2026), слепой раунд |
| Модель | `claude-opus-4-8` (агентная среда с исполнением кода) |
| Дата прогона | 2026-07-18 (совпадает со срезом датасета `FROZEN`) |
| Инструменты | Python 3.11.15; numpy 2.4.4; scipy 1.17.1; Linux x86-64 |
| Датасет | `dataset_version = 4`, 4 части × (1 meta + 3000 строк) = **12 000** портретов |
| Полнота | **полная, все 12 000** — не выборка; программная детерминированная обработка |
| Длительность скоринга | ~1.0 c на полный прогон движка (12 000 строк) |
| Способ обработки | единый OOP-движок `engine_v4.py`; константы заморожены до обработки; правила детерминированы и одинаковы для всех строк |
| Позиционный контракт | ровно одна строка ответа на входную строку, порядок входа сохранён; дубли `id` не мержатся (проверено: 0 расхождений позиций) |
| Ручные вмешательства в скоринг | **нет** — ни одной записи не правил и не оценивал вручную; все 12 000 прошли через движок |
| Правки кода при разработке (до финального прогона) | (1) обнуление суб-рублёвого остатка долга после флора разового гашения — убирает фантомный бакет `debt=1`; (2) исправление вспомогательной функции сверки `independent_lump` (условие surplus по остатку, а не по наличию класса долга). Обе — до финального прогона; движок и ответы согласованы. |
| Контроль сумм | 0 нарушений (месячные бакеты ≤ `max(0,⌊fcf⌋)`, `lump ≤ bliq`) — `self_validation_v4.md` |
| Сверка с карточками | 0 расхождений позиций, 0 валидных с маркером `!`, 41 портрет детально — 0 числовых расхождений |
| Воспроизводимость | `python engine_v4.py` → 3 основных файла; `dataset_stats_v4.py`, `validate_answers_v4.py`, `card_crosscheck_v4.py`, `sensitivity_run_v4.py`, `gen_opinions_v4.py` — все standalone |
