# Приёмка датасета v4 — гейты внешнего аудитора (до оценки портретов)

Считано программно (`dataset_stats_v4.py`, полный проход 12 000 строк).
Срез дат: 2026-07-18. Валидных записей по моему критерию `invalid`
(методология §6): **11 400**, дефектных: **600** (5.0% — заявленная доля слоя
validity). Все числа ниже — по валидной части, если не сказано иное.

## Гейт 1. Целостность — ПРОШЛО (с оговоркой)

- NaN/None/строки/булевы в денежных полях среди валидных записей: **0** — все
  такие случаи (93 `income_total`, 82 `obligation.amount`, 34
  `obligation.interest_rate` и др.) корректно изолированы в дефектный слой.
- Отрицательные суммы среди валидных: **0** (56 отрицательных доходов, 59
  остатков, 44 ставки — все в дефектном слое).
- Обязательные ключи: все на месте у 11 400 валидных; отсутствие ключей
  (`income_total` — 30, `goal.deadline` — 39 и др.) — только в дефектном слое.
- Лишних верхнеуровневых ключей: **0**. Внутри кредитов/целей есть служебный
  `id` — не мешает, не дефект.
- Оговорка: дефекты распределены по ~13 типам с близкими объёмами (34…99) —
  «рандомизированные объёмы» из методички соблюдены лишь отчасти, синтетичность
  слоя D угадывается по равномерности. На оценку не влияет.
