# Метаданные прогона — v4

| Параметр | Значение |
|---|---|
| Эксперт-модель | Claude (Anthropic), сессия claude.ai с выполнением кода |
| Инструменты | Python 3.12 (Linux-песочница), стандартная библиотека + numpy 2.4.4, scipy 1.17.1; flake8 для контроля PEP 8 |
| Дата работы | 2026-07-18 (совпадает с датой среза датасета) |
| Длительность | одна рабочая сессия, ~1 час чистого машинного+аналитического времени |
| Полнота | **все 12 000 входных строк**, программная обработка, без выборок |
| Способ обработки | детерминированный движок `engine_v4.py` (ООП, PEP 8, flake8 = 0); одна строка ответа на одну входную строку, позиционно |
| Данные | 4 части `expert_portraits_v4_part1..4_jsonl.gz` (метастроки: v4, по 3 000 строк, срез 2026-07-18) + карточки `portraits_v4_seed20260718_cards.md` |
| Порядок работ | фиксация методологии → приёмка датасета → полный прогон → самопроверка → выборка обоснований → чувствительность → отчёты (порядок §13 брифа соблюдён) |
| Ручные вмешательства в ответы | **нет.** Ответы движка руками не правились. Единственные ручные правки по ходу — баг проверочного скрипта кросс-чека (индекс группы регулярки; см. `self_validation_v4.md` §6) и косметика генератора прозы выборки; на `expert_allocations_v4.csv` / `summary_v4.csv` / `recommendations_v4.jsonl.gz` они не влияли |
| Повторяемость | движок детерминирован: контрольный перепрогон на повторно загруженных исходниках дал байт-идентичный основной CSV; сид выборки кросс-чека 20260718, выборка обоснований — каждая 300-я позиция |
| Чувствительность | 10 дополнительных полных прогонов (`sensitivity_runner_v4.py` поверх `engine_v4.py --set`), по одной константе за раз |
| Независимость | работа только с приложенными файлами; память, прошлые сессии и внешние методики не использовались; уточняющих вопросов не задавалось — неоднозначности закрыты допущениями A1…A15 |
