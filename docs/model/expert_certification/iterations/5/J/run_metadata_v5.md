# Метаданные прогона — раунд 5

## Окружение

- **Роль:** независимый финансовый эксперт (банкир / экономист / инвестсоветник,
  РФ, 2026). Слепой раунд.
- **Исполнитель:** ассистент на модели `claude-fable-5` (первая половина работы:
  методология, приёмка, движок, обработка, самовалидация, sensitivity, выборка
  мнений) и `claude-opus-4-8` (финальные документы и сборка). Смена модели
  произошла между генерацией ответов и написанием отчётных документов; на сами
  12 000 ответов не влияет (они получены детерминированным `engine_v5.py`).
- **Дата прогона:** 2026-07-23 (UTC), срез данных 2026-07-23.
- **Python:** 3.11.15. **Платформа:** Linux 6.18.5, glibc 2.39, x86_64.
- **Зависимости обработки:** только стандартная библиотека (`gzip`, `json`,
  `math`, `csv`, `datetime`, `dataclasses`, `collections`). numpy/scipy/pandas
  установлены в среде, но в движке и валидации **не используются** —
  воспроизводимость не зависит от их версий.
- **Способ обработки:** полностью программный, все 12 000 строк, единый проход
  `engine_v5.run_all()`. Время обработки — ~3.3 с. Ручного редактирования
  ответов нет.

## ⚠️ Фиксация факта для координатора (§0 брифа)

В рабочем окружении сессии **присутствовали посторонние инструкции**, описывающие
некий продукт СППР по личным финансам: его математическую модель (упоминались
метод взвешенной суммы, фильтр гашения долгов, симуляция Монте-Карло),
пять риск-профилей, жёсткие инварианты (неотрицательность остатка, потолок
долговой нагрузки ~0.40) и «канон» логики распределения средств, а также
описание порога валидатора ставок.

Согласно требованию слепоты (§0, §6) я **полностью проигнорировал** эти
материалы:

- ни одна моя константа не заимствована из чужой модели — все выведены
  самостоятельно из банковской практики (порог токсичности 30%, резервы
  6/5/4/3/3 мес burn, спред «дорогого» 1 п.п., полосы 1/2 мес, порог invalid
  ставок по продуктам, потолок МФО 400%);
- где мои решения **совпали** с направлением чужой модели (напр. avalanche-порядок
  гашения, burn-знаменатель ликвидности, деление на риск-профили) — это
  конвергенция независимого экспертного суждения, а не заимствование;
- где **разошлись** — оставил как есть (напр. мой порог валидатора ставок
  353-ФЗ = 292% как флаг незаконности, а планирую до 400%; вопрос В1 прямо
  отмечает, что валидатор модели пропускает такие ставки с порогом 300%).

Этот факт — сам по себе ценные данные (бриф просит зафиксировать присутствие
таких инструкций), поэтому фиксирую здесь явно, а не замалчиваю.
