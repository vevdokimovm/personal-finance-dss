# Методология независимого эксперта — раунд 5 (датасет v5)

**Эксперт:** независимый специалист по личным финансам (банковская практика РФ, инвестиционное консультирование), 2026 г.
**Дата фиксации:** 2026-07-23, **до** какой-либо статистической обработки датасета.
Просмотрено на момент фиксации: бриф, методичка, служебные `__meta__`-строки, первые ~10 карточек (для понимания формата полей). Никакие агрегаты по 12 000 записей не считались.

Все константы ниже — окончательные. По ходу обработки не меняются. Изменения возможны только фиксацией отдельным пунктом в `assumptions_log_v5.md` с пометкой «после фиксации» — таких пунктов быть не должно, и их нет.

## 1. Профессиональная рамка

Я рассуждаю как практикующий консультант по личным финансам в России 2026 года:

- Ключевая ставка ЦБ прошла пик 2024–2025 гг.; безрисковая доходность после НДФЛ
  в данных (`r_bench`) — порядка 12–20% годовых. Это делает **дешёвый долг**
  (льготная ипотека 6–9%, рассрочки 0–5%) объективно выгодным к удержанию,
  а не к досрочному гашению.
- Регуляторная рамка: 353-ФЗ (ПСК, потолок для МФО ≈ 292% годовых = 0.8%/день),
  макропруденциальные лимиты ЦБ с порогами ПДН 50% и 80%.
- Поведенческая рамка: подушка ликвидности — страховка потребления семьи, поэтому
  измеряется в **месяцах полного обязательного оттока** (burn = расходы + платежи
  по кредитам), а не в месяцах «чистых расходов». Это моё осознанное экспертное
  решение (методичка подтверждает, что это ожидаемый выбор экспертов, — и я не
  считаю его находкой о датасете).

## 2. Диагностика портрета (считается для каждой валидной записи)

| Величина | Формула |
|---|---|
| `payments` | Σ `monthly_payment` по обязательствам |
| `FCF` | `income_total − expense_total − payments` (свободный месячный поток) |
| `burn` | `expense_total + payments` (полный обязательный отток) |
| `liq_months` | `bliq / burn`; при `burn == 0` → +∞ |
| `ПДН` (DSTI) | `payments / income_total`; при `income == 0` и `payments > 0` → +∞ |
| `target_reserve` | `T_res(risk) × burn` (см. §4) |
| `debt_total` | Σ `amount` |
| `k_goal` | Σ `target_amount` / (12 × `income_total`), диагностически |

Диагностические флаги (в `summary_v5.csv` и в вердиктах, на распределение влияют
только там, где это явно сказано ниже): `pdn_elevated` (ПДН > 0.50),
`pdn_critical` (ПДН > 0.80), `growing_debt` (платёж ≤ месячному проценту:
`monthly_payment ≤ amount × rate / 12` при `amount > 0`), `illegal_mfo_rate`
(МФО со ставкой > 2.92), `whale` (доход ≥ 5 млн ₽/мес), `stress_magnitude`
(любое денежное поле ≥ 10⁸), `overfunded_goal` (`current > target`),
`deadline_overdue`, `zero_flow` (FCF == 0 точно).

## 3. Классификация долгов (константы)

Ставки сравниваются с `r_bench` портрета (после НДФЛ — корректная база сравнения
с досрочным гашением, которое «доходно» ровно на ставку долга без налога).

| Класс | Критерий | Экономика |
|---|---|---|
| **Токсичный** | `rate ≥ TOXIC_RATE = 0.30` | 30%+ годовых удваивает долг за ~2.4 года; выше любой разумной ожидаемой доходности; гашение приоритетнее достройки подушки |
| **Дорогой** | `r_bench + SPREAD < rate < 0.30`, `SPREAD = 0.01`; **или** долг растущий (`growing_debt`) независимо от ставки | Досрочное гашение доминирует безрисковое размещение; растущий долг без досрочки не гасится вообще |
| **Дешёвый** | `rate ≤ r_bench + 0.01` | Гасить досрочно невыгодно: деньги на депозите под `r_bench` зарабатывают больше; платим только минимум |

Порядок гашения внутри классов — **строго по убыванию ставки** (avalanche).
Это стандартный математически оптимальный порядок; поведенческий snowball
сознательно не применяю: рекомендация даётся рациональному планировщику.
Обоснование порога 30%: верх диапазона банковского потребкредитования и низ
МФО-диапазона; при `r_bench` 12–20% это ≈ `r_bench` + 10–18 п.п. — за пределами
любой достижимой безрисковой или умеренно-рисковой доходности.

## 4. Резерв ликвидности (константы)

Целевой резерв по риск-профилю, в месяцах burn:

| risk_tolerance | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| `T_res`, мес | 6 | 5 | 4 | 3 | 3 |

Пороги полос: `FLOOR = 1.0` мес (критическая зона), `BAND = 2.0` мес
(верх «полосы тонкой подушки»).

**В3 (крупные доходы) — позиция:** правило остаётся **относительным** — резерв
измеряется в месяцах burn и при доходе 50 млн ₽/мес. Подушка страхует поток
потребления, который у такого домохозяйства действительно исчисляется миллионами;
абсолютного капа не ввожу. Масштабная эквивариантность методологии — осознанное
свойство (все правила безразмерны: месяцы, доли, ставки).

## 5. Месячное распределение FCF (каскад)

Применяется при `status = ok` и `FCF > 0`. Бюджет: `res + debt + goal + inv ≤ FCF`.
Внутри долговой корзины деньги идут на самый дорогой prepay-worthy долг.

**S1. Критическая зона, `liq_months < 1`:**
- нет токсичных/дорогих долгов → резерв 100%;
- есть токсичный → резерв 50% / долг 50% (выживание и кровотечение одинаково срочны);
- есть только дорогой → резерв 70% / долг 30%.

**S2. Полоса тонкой подушки, `1 ≤ liq_months < 2` (главная спорная зона, В2):**
- токсичный долг → резерв 30% / долг 70%;
- дорогой долг → резерв 50% / долг 50%;
- нет prepay-worthy долгов → резерв 70% / цели 30%.
- **Критическая цель** (имя «Лечение», дедлайн ≤ 6 мес, недофинансирована):
  её требуемый месячный взнос выделяется первым, кап 30% FCF; остаток — по правилам выше.

**В2 — позиция явно:** в полосе 1–2 мес я **не** добиваю подушку до двух месяцев
прежде долга и **не** бросаю всё на долг: гибрид со смещением по токсичности
(70% на долг ≥ 30% годовых; 50/50 на просто дорогой). Близкий (< 6 мес) дедлайн
обычной цели («Отпуск», «Техника») ответ **не меняет** — потребительская цель
не оправдывает ни задержку подушки, ни проценты; меняет только критическая цель
здоровья. Это главная ожидаемая зона расхождений — см. `disagreement_forecast_v5.md`.

**S3. Достройка, `2 ≤ liq_months < T_res`:**
- токсичный → резерв 15% / долг 85%;
- дорогой → резерв 30% / долг 70%;
- нет prepay-worthy → резерв 40% / цели+инвестиции 60%.

**S4. Подушка укомплектована, `liq_months ≥ T_res`:**
- токсичный → долг 100% (кроме карва критической цели ≤ 20% FCF);
- дорогой → сначала требуемые взносы датированных целей с дедлайном ≤ 12 мес
  (суммарный кап 40% FCF) + «длинная привычка» (см. В5) — остальное в долг;
- только дешёвые/нет долгов → требуемые взносы всех датированных целей →
  остаток: 50% на недатированные/недофинансированные цели (пропорционально
  разрыву) / 50% в `inv`; нет целей → 100% `inv`.

`inv` — свободные инвестиции сверх именованных целей; инструмент зависит от
риск-профиля (1–2 — депозиты/ОФЗ ≈ `r_bench`; 3 — смешанный; 4–5 — рыночный
риск), но **сплит от профиля не зависит** — профиль меняет инструмент, не долю.

**В5 (длинные цели против дорогого долга) — позиция:** долг со ставкой выше
`r_bench + 4 п.п.` (моя оценка премии ожидаемой долгосрочной рыночной доходности
после налогов над безрисковой в РФ) математически доминирует инвестирование под
длинную цель ⇒ пока есть токсичный долг — на цели длиннее 10 лет **0**;
пока есть просто дорогой — «взнос-привычка» `LONG_HABIT = 10%` FCF на длинные
(> 10 лет) цели, остальное в долг. Дисциплина регулярного взноса имеет
поведенческую ценность, но не ценой 30%+ годовых.

**Требуемый взнос цели:** `req = max(0, target − current) / months_left`;
`months_left = max(1, floor((deadline − 2026-07-23) / 30.4375 дн))`;
дедлайн сегодня/завтра → 1 месяц; **просроченный дедлайн** → цель жива,
пересрок на `OVERDUE_MONTHS = 6` месяцев. Датированные цели наполняются
в порядке дедлайнов. `target ≤ current` → взнос 0 (перефинансированная цель —
законный кейс, средства цели не трогаю).

**FCF == 0.0 точно:** `status = ok`, все месячные корзины 0, `dom = none`,
lump-ходы разрешены.

## 6. Разовые ходы из накоплений (`lump`)

Развёртываемый излишек считается от **пост-hoc burn** (после ходов):

1. **Токсичные долги** — гасятся из накоплений до пола `1.0 × burn_после`
   (ради 30%+ годовых допускаю просадку подушки до одного месяца).
2. **Дорогие долги** — гасятся только из излишка сверх `target_reserve` (после токсичных).
3. Полное закрытие — приоритет (освобождает платёж); частичное — только по
   самому дорогому незакрываемому долгу. Для карт частичное гашение снижает
   минимальный платёж пропорционально остатку (платёж = доля остатка);
   для аннуитетов платёж считаю неизменным (сокращается срок) — кэшфлоу
   не меняется, экономия только на процентах.
4. Дешёвые долги из накоплений **не** гасятся никогда.
5. После долгов: излишек сверх `target_reserve` → разовое пополнение
   недофинансированных целей с дедлайном ≤ 24 мес (в порядке дедлайнов).
6. Остаток сверх `INVEST_EXCESS = 12` месяцев burn → разовая инвестиция
   (`invest_surplus`) при `risk ≥ 3` и `burn > 0`; иначе остаётся в накоплениях.

**Дефицит (`FCF < 0`) — спасательный lump:** закрытия долгов из накоплений
с сохранением ≥ 1 месяца **итогового** burn, порядок — по убыванию
`monthly_payment / amount` (освобождённый платёж на рубль накоплений — жадный
критерий кэшфлоу; в кризисе кэшфлоу важнее процентной математики), плюс
частичное гашение карт, если оно способно поднять FCF. Месячные корзины при
дефиците — нули по контракту; вердикт описывает пост-lump ситуацию.

## 7. Статусы и валидность

`deficit` — `FCF < 0`. `invalid` — по критериям ниже, `dom = none`, все числа 0.
Иначе `ok`.

**Invalid (общие правила серии):** отрицательные деньги; нечисловое значение
(строка/`null`/булево — булево проверяется отдельно от int) в денежном поле,
ставке или риск-профиле; отсутствующий обязательный ключ; несуществующая дата;
ставка, физически невозможная для продукта. **Не** invalid: нулевой доход/расходы/
подушка, отсутствие целей, просроченный дедлайн, дубль `id`, `current > target`,
остаток вне продуктовой спеки (задекларирован намеренным).

**Мои числовые пороги «физически невозможной ставки»** (продукт по имени кредита):

| Продукт | Invalid при rate > | Логика |
|---|---|---|
| Ипотека | 0.40 | залоговый регулируемый продукт; 40%+ не существует ни при какой ключевой |
| Автокредит | 0.50 | залоговый; аналогично |
| Потребкредит | 0.60 | выше макропруденциального потолка ПСК необеспеченных |
| Кредитная карта | 0.60 | аналогично |
| Рассрочка | 0.30 | рассрочка с 30%+ — это не рассрочка, а мисклассификация записи |
| МФО | 4.00 | см. В1 |
| Неизвестное имя | 4.00 | консервативный глобальный потолок |

Также invalid: `r_bench` вне [0; 1]; `risk_tolerance` вне {1..5} (float с целым
значением коэрцируется с записью в лог); любая ставка < 0.

**В1 (кромка ПСК) — позиция:** ставка МФО в (2.92; 4.00] — **валидный вход
с незаконно дорогим долгом**, не invalid. Договор с превышением потолка ПСК
юридически оспорим, но экономически существует: у клиента реальные платежи,
и отказ планировать ему не помогает. Планирую как токсичный долг высшего
приоритета + в вердикте флаг `illegal_mfo_rate` с рекомендацией оспаривания
(353-ФЗ) — это единственный правильный «финансовый» ответ практикующего
консультанта. Invalid начинается там, где продукта не может быть даже в серой
зоне письменного договора: > 400% годовых. Порог 400% выбран как ~0.8%/день × 365
+ запас на «почти легальные» конструкции; выше — только криминальное
ростовщичество, которое не является кредитным продуктом.

## 8. `dom` и `confidence`

`dom` = argmax(res, debt, goal + inv); тай-брейк: debt > reserve > goals+.
Все корзины нули (FCF == 0, или дефицит, или invalid) → `none`.

`confidence` — детерминированные правила:
- База 4. Invalid c жёстким дефектом (тип/ключ/знак/дата) → 5; invalid по
  суждению (пороговые ставки, enum) → 4.
- Дефицит: глубокий (`FCF < −0.1 × burn`) → 5, иначе 4.
- Повышение до 5 (ok): токсичный долг при полной подушке; нет долгов и
  `liq ≥ T_res`; «чистый» портрет без напряжений.
- Минус 1 за каждое (мин. 1): полоса В2 (1–2 мес + prepay-worthy долг);
  сосуществование длинной (>10 лет) цели и prepay-worthy долга; кит/стресс-
  магнитуда; остаток кредита вне продуктовой спеки; МФО в кромке [2.90; 3.00];
  коэрцированные поля.

**В6 — позиция:** пятёрки я ставлю там, где решение следует из доминирования
без трейд-оффа: мусор с жёстким дефектом; токсичный долг при полной подушке
(гасить); отсутствие долгов при полной подушке (цели/инвестиции); глубокий
дефицит (кризисный протокол). Если алгоритм расходится со мной именно там —
это расхождение философий (например, приоритет целей над avalanche или жёсткий
floor подушки), и порогами оно не лечится; смотреть надо на сам каскад приоритетов.

## 9. Ответы на открытые вопросы — сводно

- **В1:** 2.93–4.00 — валидно, токсично, флаг незаконности + совет оспаривать; invalid только > 4.00.
- **В2:** гибрид 70/30 в пользу токсичного долга, 50/50 для дорогого; обычная близкая цель ответ не меняет, критическая («Лечение», ≤ 6 мес) — получает требуемый взнос первым (кап 30%).
- **В3:** правило месяцев burn остаётся относительным без абсолютного капа; профиль масштабно-эквивариантен.
- **В4:** порог токсичности — **30% годовых** (абсолютный, ≈ `r_bench` + 10–18 п.п. в условиях 2026 г.); отдельно долг «растущий» приравнен к дорогому при любой ставке.
- **В5:** при токсичном долге длинные цели получают 0; при просто дорогом — 10% FCF «привычки»; после долгов — полный требуемый взнос (длинный горизонт делает его небольшим).
- **В6:** пятёрки — в зонах доминирования (см. §8); расхождения там — сигнал о каскаде, не о порогах.
