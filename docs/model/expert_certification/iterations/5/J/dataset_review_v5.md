# Ревью датасета v5 — два прохода

**Эксперт:** независимый (раунд 5). Числа воспроизводятся `dataset_stats_v5.py`
(результат — `dataset_stats_v5.json`); сверка карточек — `card_crosscheck_v5.py`.
Машиночитаемый список находок — `dataset_review_v5.json`. Данные не чинились.

## Проход 1 — дескриптивы и маргиналы

**Объём:** 12 000 записей (4 × 3000), JSON валиден в 100% строк, служебные
`__meta__`-строки консистентны.

**Доход, ₽/мес (по 11 378 валидным):** min 0 · p25 46 853 · медиана 90 810 ·
p75 235 151 · p99 9.80 млн · max 1.98 млрд (стресс). Медиана и межквартильный
размах правдоподобны для РФ-2026; правый хвост — задекларированные киты и
стресс-страта, отделяются порогами 5 млн и 10⁹.

**Свободный поток:** p25 −1 149 · медиана +9 231 · p75 +34 585. Отрицательный
поток у 25.9% — жёстко, но осмысленно (в v1-серии, по брифу, было 80%).

**Ликвидность:** медиана 2.42 мес burn, p25 1.18 — заметная масса портретов
сидит ровно в «полосе тонкой подушки» 1–2 мес (В2): полоса намеренно усилена.

**Риск-профиль:** 2236/2287/2269/2283/2303 по профилям 1–5 — равномерно by
design, как задекларировано (это не популяционная структура РФ).

**`r_bench`:** 1 394 различных значения в [0.10; 0.205] — непрерывен,
дискретности v2 нет.

**Кредиты:** 19 476 шт. Продукты: потреб 6 818 · карта 5 195 · рассрочка 2 873 ·
ипотека 1 723 · автокредит 1 626 · МФО 1 241. Ставки — 100% внутри продуктовых
спек (вне — только 3 МФО-пробы и дефектный слой). Остатки вне спеки — 8.7–14%
по продуктам (сводно 12.44% против задекларированных 12.01% — расхождение
объясняется тем, что мой пересчёт включает дефектные записи). Портретов
без кредитов — 2 083.

**Цели:** 44 541 шт., портретов без целей — 1 093; и без целей и без кредитов —
332. Распределение количества: 1–4 цели у большинства, 5/6/7/8 целей —
1002/827/696/618 (страты DOE). `k_goal` фактический [0.19909; 4.99812] —
совпадает с декларацией в 4-м знаке: дефект v4 закрыт.

**KS лог-нормальности доходов:** заявлено 0.0183 по «основной популяции».
Вслепую не воспроизводится: слой A не изолируется без ключа. Моё приближение
по смеси всех валидных доходов 1 т.–5 млн даёт 0.1007 — ожидаемо хуже из-за
примеси слоёв B/C. Не считаю дефектом; см. рекомендацию R1.

## Проход 2 — перепись границ и скан слоя E

**Перепись граничных кейсов (валидные записи):**

| Кейс | Счёт |
|---|---|
| FCF ровно 0.0 (float) | 122 |
| ПДН ровно 0.40 | 29 (полоса 0.39–0.41 — 274) |
| `target == current` в копейку | 56 |
| Перефинансированная цель (`current > target`) | **0** → F2 |
| Дедлайн в день среза / завтра / просрочен | 77 / 74 / 92 |
| Цели длиннее 10 лет / 20 лет; максимум | 1560 / 741; 359 мес |
| Нулевой доход / нулевые расходы / нулевая подушка | 112 / 86 / 115 |
| 8 целей с единым дедлайном | 50 |
| Растущий долг (платёж ≤ проценту) | 697 портретов |
| Ставка == `r_bench` точно / в пределах ±0.5 п.п. | 79 / 442 |
| МФО в кромке [2.90; 2.92] / пробы выше | 61 / 3 (2.93, 2.95, 2.95) |

Каталог слоя C методички закрыт данными практически полностью; единственная
потеря — перефинансированная цель (F2).

**Дубли `id`:** 133 группы = 102 пары + 31 тройник. Формы пар: 74 «обе валидные»,
9 «обе битые» (заявленная форма), 19 смешанных (F5). Сортировка/дедупликация
по id уничтожила бы 297 строк — позиционный контракт критичен, соблюдаю.

**Слой дефектов (моими правилами invalid):** 622 записи (5.183%), из них
жёстких (тип/знак/ключ/дата) 538, «по суждению» (пороговые ставки, enum) 84.
Составных (≥2 независимых причин) — 97 = 15.6% слоя (декларировано «13.1%
слоя» — согласуется с точностью до методики счёта причин). Верхушка полей:
income_total 124 · amount 102 · expense_total 71 · interest_rate 82 ·
monthly_payment 50 · bliq 34 · target_amount 29 · r_bench 26 · risk_tolerance 14+.
Формы near-miss: строки-числа («0,2», «сто тысяч»), None, True/False, пустые
строки, «2026-02-30», «не скажу», отсутствующие ключи (в т.ч. 21 отсутствующий
`deadline`), ставки 3.00 и ровно 12.0 на банковских продуктах.

**Механизм дефекта ставок (гипотеза):** все 18 аномальных ставок «12.0» равны
ровно 12 — похоже на unit-confusion «проценты вместо доли» (12 vs 0.12).
Обрабатываю как есть (по моим капам — invalid), гипотезу фиксирую для
координатора.

**Скан слоя E (метаморфические пары, слепая эвристика):** в бакетах
(risk, n_кредитов, n_целей): 171 пара с ≤2 отличающимися полями (кандидаты
M1–M4, вкл. неравномерные возмущения) и 44 пары «все деньги ×k при неизменных
ставках» (кандидаты M5; наблюдаемые k вплоть до 10.0). Слой присутствует и
обнаружим; меток не имею и в оценке их не использую.

**Карточки против JSONL:** позиционное соответствие 12 000/12 000; 231 953
поля сравнено; **0 расхождений**. Особенность рендера: отсутствующий ключ
`deadline` карточка показывает маркером `!нет поля deadline!` (21 шт), прочие
битые значения — в `!..!` как задекларировано.

## Находки и рекомендации (полный список — `dataset_review_v5.json`)

- **F1.** Бриф (В1) заявляет пробы ставок «2.93, 2.95 и 3.00». Фактически на
  МФО — 2.93/2.95/2.95; «3.00» существует только на банковских продуктах
  (7 шт: карта/потреб). Вопрос В1 в части «МФО ровно 3.00» — теоретический;
  моя позиция от этого не зависит.
- **F2.** Перефинансированная цель (`current > target`) — 0 случаев на 44 541
  цель, кейс каталога слоя C в v5 потерян (при 56 точных `target == current`).
  Рекомендация: вернуть в v6.
- **F3.** Мин-платёж карт: 8.9% вне заявленной полосы 2–5% (факт 1.04–6.7%).
  Часть — дефектный слой, но доля превышает его ёмкость; рекомендация:
  задекларировать джиттер полосы явно.
- **F4.** KS 0.0183 вслепую невоспроизводим (нет изоляции слоя A).
  Рекомендация R1: публиковать в декларации критерий отбора записей, по
  которым посчитана статистика (без раскрытия принадлежности конкретных строк).
- **F5.** Смешанные дубль-пары (валидная + битая), 19 шт — четвёртая форма
  сверх трёх заявленных. Не мешает, но декларацию форм стоит дополнить.
- **F6.** Подтверждения исправлений v4→v5 (все проверены): доля дефектов
  не круглая (622); кап 10⁸ на целях снят (max цели ~10¹⁰); длинные горизонты
  массовые (1 560); лимиты МФО легальны (max ровно 1 млн); карта на
  мин-платеже; `k_goal` совпал с декларацией.
- **F7.** Ставок в «дыре» между потолком МФО и дефектами (3.00 < r < 12.0) нет
  вообще: кромка «незаконно, но бывает» представлена только тремя пробами.
  Для калибровки порога invalid-ставки этого мало; рекомендация: в v6 добавить
  пробы 3.5–6.0 на МФО.
