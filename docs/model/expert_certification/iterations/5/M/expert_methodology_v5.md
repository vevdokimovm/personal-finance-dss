## 1. Философия

Я планирую деньги домохозяйства в следующем порядке приоритетов: **защита от
катастрофы → остановка кровотечения (токсичный долг) → страховой резерв → дорогие
долги → цели → свободные инвестиции**. Это лексикографический каскад с двумя
смягчениями: (а) в переходных зонах поток делится между соседними приоритетами
фиксированными весами, а не переключается ступенькой; (б) избыточная ликвидность
сверх целевого резерва — не «священная корова», а рабочий капитал для разовых ходов.

Все правила сформулированы в **относительных** величинах (месяцы полного оттока,
спреды к безрисковой ставке, доли потока). Это осознанно: рекомендация обязана быть
инвариантной к масштабу денег — портрет, умноженный на k, должен получать
рекомендацию, умноженную на k. Абсолютных рублёвых порогов в методологии нет.

Ставку каждого долга я сравниваю не с абстрактным «психологическим» порогом, а с
`r_bench` конкретного портрета — безрисковой доходностью после НДФЛ, доступной
этому человеку на момент среза. Досрочное гашение долга — это безрисковая
«инвестиция» под ставку долга; всё решается спредом.

## 2. Диагностика (считается по каждому валидному портрету)

Дата среза: **2026-07-23**. Все горизонты — от неё. Месяц = 30.4375 дня.

- `pay_sum = Σ monthly_payment` по всем кредитам;
- `burn = expense_total + pay_sum` — полный месячный отток (я сознательно считаю
  запас ликвидности от полного оттока, а не от одних расходов: подушка нужна, чтобы
  пережить потерю дохода, а кредиторы в этот момент платежей не прощают). Знаю, что
  этот вопрос в серии закрыт (§«закрыто» брифа) — это не находка, это моя рабочая
  рамка;
- `fcf = income_total − burn` — свободный денежный поток на входе;
- `pdn = pay_sum / income_total` (при `income_total = 0`: +∞, если платежи есть;
  0, если платежей нет);
- `liq_m = bliq / burn` — запас ликвидности в burn-месяцах (+∞ при `burn = 0`);
- по каждому долгу: `spread = interest_rate − r_bench`;
  `growing = monthly_payment < amount × interest_rate / 12` (платёж не покрывает
  даже проценты — долг растёт);
- по каждой цели: `gap = max(0, target_amount − current_amount)`;
  `months = (deadline − срез)/30.4375 дня`; эффективный горизонт
  `months_eff = max(1, months)` при наличии дедлайна (просроченный или сегодняшний
  дедлайн → 1 мес: «нужно было вчера»), `months_eff = HORIZON_OPEN = 120` для
  целей без дедлайна (бессрочная цель = длинная, десятилетний горизонт);
  требуемый взнос `required = gap / months_eff`.

## 3. Валидность записи (status = invalid)

Инвалидна **запись, с которой нельзя ответственно планировать**, т.е. битые данные,
а не тяжёлая жизненная ситуация. Правила (совпадают с рамкой §3 брифа, детализация моя):

1. Отсутствие любого обязательного ключа портрета
   (`id, income_total, expense_total, obligations, goals, bliq, r_bench, risk_tolerance`) → invalid.
2. Денежные поля (`income_total, expense_total, bliq`; у долга `amount,
   monthly_payment`; у цели `target_amount, current_amount`) обязаны быть числом
   (int/float, **не** bool, не строка, не null), конечным и **≥ 0**. Иначе → invalid.
3. `interest_rate` — конечное число ≥ 0 и не выше **физического потолка своего
   продукта** (§3.1 ниже). Иначе → invalid.
4. `r_bench` — число в диапазоне **[0; 0.60]**. Отрицательная или заоблачная
   безрисковая ставка в РФ-2026 — битый параметр рынка, планировать по нему нельзя.
5. `risk_tolerance` — целое 1–5 (принимаю и float с целым значением; bool не
   принимаю). Иначе → invalid.
6. `obligations`/`goals` — списки (возможно пустые); каждый элемент — объект с
   полным комплектом обязательных ключей (`id, name, amount, interest_rate,
   monthly_payment` / `name, target_amount, current_amount, deadline`); `name` —
   строка. Иначе → invalid. (Поле `id` у цели встречается в данных, но контрактом
   брифа не заявлено — его отсутствие инвалидностью не считаю.)
7. `deadline` — `null` или строка ISO `YYYY-MM-DD`, являющаяся **существующей**
   календарной датой (строгий парсинг; «2026-02-30» → invalid). Дата в прошлом —
   валидна (просрочка — жизнь, не мусор).
8. `id` — непустая строка. Дубли `id` — валидны (позиционный контракт).

**Не** инвалидно: нулевой доход, нулевые расходы, нулевая подушка, отсутствие целей
и/или кредитов, просроченный дедлайн, `target == current`, платёж 0, остаток 0,
дубль `id`.

Для invalid-строк: `dom = none`, все числовые поля ответа = 0, включая `lump`.

### 3.1. Физические потолки ставок по продуктам (мои, для правила 3)

Продукт определяю по подстроке имени кредита (регистронезависимо): «ипотек» /
«автокред» / «потреб» / «карта» / «рассрочк» / «мфо | микрозайм | займ»; иначе —
«неизвестный».

| Продукт | Потолок ставки (доля годовых) | Логика |
|---|---|---|
| Ипотека | 0.35 | залоговый банковский продукт; ставка 35%+ не существует даже в худших рыночных эпизодах |
| Автокредит | 0.45 | залоговый, но с худшим коллатералем |
| Потребкредит | 0.60 | верх банковской розницы с учётом штрафных реструктуризаций |
| Кредитная карта | 0.80 | с учётом штрафных ставок и просрочки |
| Рассрочка | 0.25 | продукт по определению дешёвый; «рассрочка под 40%» — это не рассрочка |
| МФО | 3.65 | 1% в день — фактическая верхняя кромка серого рынка |
| Неизвестный | 3.65 | консервативно, по максимуму |

**Позиция по В1 (кромка ПСК)** — см. §10. Кратко: ставка выше легального потолка
292%, но ниже физической кромки рынка — **валидный вход** (договор существует
де-факто, долг реален, платить по нему приходится), гасить в первую очередь;
инвалидность — свойство данных, а не законности договора.

## 4. Классификация долгов

| Класс | Критерий | Что делаю |
|---|---|---|
| **Токсичный** | `interest_rate ≥ 0.40` **или** `spread ≥ 0.25` | гасить немедленно, в т.ч. из подушки до уровня 1.0 burn-мес |
| **Дорогой** | не токсичный и `spread ≥ 0.06` | гасить досрочно после минимального резерва; из подушки — только излишком сверх целевого резерва |
| **Дешёвый** | `spread < 0.06` | только контрактные платежи; досрочно не гасить никогда (арбитраж в пользу накоплений) |

Эскалация: **растущий долг** (`growing`, платёж не покрывает проценты) поднимается
на один класс вверх (дешёвый → дорогой, дорогой → токсичный). Долг, который не
амортизируется, — это тикающая бомба независимо от ставки: сначала остановить рост.

Порядок гашения внутри классов — **лавина**: по убыванию `interest_rate`; при
равенстве ставок — раньше больший остаток. Снежный ком не применяю: я оптимизирую
рублёвую стоимость долга, психологическую мотивацию оставляю живому консультанту.

## 5. Резерв ликвидности

Целевой резерв — в burn-месяцах, зависит от риск-профиля (консерватору спокойнее
с большим тылом, агрессивный принимает больший риск сознательно):

| risk_tolerance | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| Целевой резерв, burn-мес (`RES_TARGET_M`) | 6.0 | 4.0 | 3.0 | 3.0 | 2.0 |

- Минимальный резерв `MIN_RES_M = 1.0` burn-мес — ниже него состояние считаю
  кризисом ликвидности.
- При гашении **токсичного** долга из подушки допускаю просадку до
  `KEEP_TOX_M = 1.0` burn-мес (но не ниже): пожар под 100%+ годовых опаснее
  недобранной подушки, однако полностью раздевать человека нельзя — новый шок
  загонит его в то же МФО.
- **Позиция по В3 (крупные доходы):** правило остаётся относительным — резерв
  в месяцах полного оттока, без абсолютного капа. Расходы богатого домохозяйства
  масштабируют и его риски. «Мёртвых десятков миллионов в кэше» не возникает,
  потому что всё сверх целевого резерва каскад немедленно выталкивает в работу
  (разовые ходы §6). Это же свойство даёт масштабную инвариантность (×k).

## 6. Разовые ходы из накоплений (lump)

Считаются до месячного плана и меняют состояние (пост-lump остатки долгов, burn и
ликвидность). Порядок:

1. **Токсичные долги**: направить `max(0, bliq − 1.0×burn)` по лавине до полного
   покрытия остатков (допускается частичное гашение — снижение тела под 200%
   годовых ценно само по себе; платёж при частичном гашении из burn не убирается,
   при полном — убирается).
2. **Дорогие долги**: направить остаток сверх **целевого** резерва
   (`max(0, bliq' − RES_TARGET_M×burn')`) по лавине.
3. **Цели с дедлайном ≤ 24 мес** (`GOAL_LUMP_HORIZON_M = 24`, включая просроченные):
   закрыть гэпы из остатка сверх целевого резерва, от ближайшего дедлайна.
4. **Свободная инвестиция**: весь оставшийся излишек сверх целевого резерва —
   разовым переводом в инструменты (для консерватора это депозит/ОФЗ — тоже
   «инвестиция» в терминах ответа).

Шаги 3–4 выполняются только при неотрицательном пост-lump потоке (при дефиците
избыток ликвидности — взлётная полоса, его не трогаю). Шаги 1–2 выполняются и в
дефиците: выкуп дорогого платежа — единственный законный способ починить поток
без роста дохода.

`lump` в CSV = сумма всех разовых ходов строки; детализация — в
`lump_sum_plan` (`recommendations_v5.jsonl.gz`), словарь действий:
`repay_debt` / `fund_goal` / `invest_surplus`.

## 7. Месячный каскад

Бюджет месячного сплита: `budget = max(0, fcf)` **по входным данным** (контракт
приёмки §8 брифа). Если lump-ходы высвободили платежи и реальный располагаемый
поток стал больше, это отражено в `monthly_plan.post_lump_fcf` в JSONL, но CSV
не выходит за входной FCF. При `fcf ≤ 0` месячный сплит нулевой.

Состояние ликвидности (пост-lump): `S0` — `liq_m < 1.0` (кризис);
`S1` — `1.0 ≤ liq_m < RES_TARGET_M` (строим резерв); `S2` — `liq_m ≥ RES_TARGET_M`
(резерв полон). Наличие токсичных/дорогих — по непогашенным пост-lump остаткам.

| Состояние | Веса первичного распределения |
|---|---|
| S0 + токсичный долг | 30% резерв / **70% долг** (`W_RES_CRISIS_TOX = 0.30`) |
| S0 + дорогой (без токсичного) | **60% резерв** / 40% долг (`W_RES_CRISIS_EXP = 0.60`) |
| S0, долгов дорогих нет | 100% резерв |
| S1 + токсичный | **100% долг** |
| S1 + дорогой | 50% резерв / 50% долг (`W_RES_BUILD_EXP = 0.50`) |
| S1 без дорогих, есть целевые гэпы | 70% резерв / 30% цели (`W_RES_BUILD_CHEAP = 0.70`) |
| S1 без дорогих и без целей | 100% резерв |
| S2 + токсичный | 100% долг |
| S2 + дорогой | **80% долг** / 20% цели (`W_DEBT_POSTRES = 0.80`); нет целевых гэпов → 100% долг |
| S2 без дорогих | цели по required (от ближайшего дедлайна), остаток → инвестиции |

Правила перелива (капы):

- Долговая корзина идёт лавиной и ограничена суммарным пост-lump остатком
  токсичных+дорогих; излишек переливается: резерв (если не полон) → цели → инвестиции.
- Резервная корзина ограничена гэпом до целевого резерва; излишек → цели → инвестиции.
- Целевая корзина: каждой цели — до её `required`, в порядке возрастания
  `months_eff`; излишек → инвестиции (при живом дорогом долге — обратно в долг).
- **Пока есть токсичный или дорогой долг, свободных инвестиций нет** (`inv = 0`):
  инвестировать под `r_bench`, держа долг под `r_bench + 6пп+`, — гарантированный
  минус. Целевые взносы под дедлайны — исключение (дисциплина обязательств).
- Дешёвым долгам сверх контрактного платежа не достаётся ничего и никогда.

**Позиция по В5 (длинные цели против дорогого долга):** делит тот же спред-порог.
Дорогой/токсичный долг (спред ≥ 6 пп) забирает поток целиком (кроме целевой квоты
20% в S2) — гашение долга под 25–30% при бенчмарке 15–17% математически бьёт
любую дисциплину дальних взносов. Дешёвый долг (ипотека 9% при бенчмарке 17%)
не гасится вовсе — весь свободный поток уходит в цели, включая пенсию на 25 лет
(`required = gap/months`), остаток — в инвестиции. Бессрочная цель = горизонт
120 мес. Никакой отдельной «пенсионной квоты при дорогом долге» не выделяю:
арбитраж важнее привычки, три года лавины — терпимая пауза для 25-летней цели.

`dom` = argmax(долг, резерв, цели+инвестиции) месячного сплита; при нулевом сплите
`none`; тай-брейк в порядке долг → резерв → цели+.

## 8. Статусы

- `invalid` — §3. Вердикт «данные битые», нули.
- `deficit` — `fcf < 0` на входе. Месячный сплит нулевой, lump-ходы разрешены;
  вердикт: реструктуризация/рефинанс + резка расходов; при `income = 0` — режим

- `ok` — всё остальное, включая ровно нулевой поток (сплит нулевой, вердикт hold).

## 9. Уверенность (confidence, 1–5)

Стартую с 4, применяю модификаторы, клип в [1; 5]:

**5 ставится**, когда решение лексикографически очевидно (один доминирующий
приоритет): жёстко битая запись (типы/отрицательные/несуществующая дата); глубокий
дефицит (`fcf < −20% дохода` или `pdn > 0.60` или доход 0 при платежах > 0);
токсичный долг, съедающий решение (lump-гашение или ≥ 70% потока в долг); профицит
без долгов при полном резерве (чистая раздача в цели/инвестиции); ровно нулевой
поток.

**Вычитаю 1** за каждый признак пограничности (до floor 1):

- пост-lump `liq_m` в пределах ±0.25 мес от границы состояния (1.0 или целевого);
- любой долг со `spread` в ±0.02 от 0.06, или ставкой в ±0.03 от 0.40, или
  спредом в ±0.03 от 0.25 (кромка класса);
- `|fcf| < 5%` дохода (поток на ноже) — кроме ровно нулевого;
- `pdn ∈ [0.35; 0.45]` (кромка перегрузки);
- стресс-магнитуда (любое денежное поле ≥ 10⁸ ₽) или доход ≥ 5 млн ₽/мес — зона,
  где мои правила напрягаются (В3);
- конфликт «тонкая подушка + дорогой долг + цель с дедлайном ≤ 6 мес» (полоса В2);
- invalid только по правдоподобию ставки/бенчмарка (не по типам) — конфидент 4,
  не 5: другой добросовестный эксперт может счесть такую запись валидной.

**Позиция по В6** — см. §10.

## 10. Явные ответы на открытые вопросы раунда (В1–В6)

**В1. Кромка ПСК.** Моя граница инвалидности — **физическая, не юридическая**.
Ставка 2.93–3.00 для МФО — валидный вход: такие договоры существуют (нелегальные
и «серые» займы, начисленные штрафы), долг реален, и человек приходит к
консультанту именно с ним. Признать запись мусором — значит отказать в плане тому,
кому он нужнее всех. Юридическая незаконность ставки — аргумент **внутри** плана
(оспаривание, жалоба в ЦБ, суд — упоминаю в вердикте токсичного долга), а не
причина выбросить запись. Инвалидна ставка, невозможная физически для продукта
(§3.1): «ипотека под 50%» — это битые данные, а не дорогая ипотека. Порог для
МФО — 3.65 (1%/день, кромка серого рынка).

**В2. Полоса тонкой подушки (1–2 мес).** Гибрид с фиксированными весами, а не
ступенька: при токсичном долге — 100% в долг (подушка ≥ 1 мес уже есть, пожар
дороже); при дорогом — 50/50; без дорогих — 70/30 в пользу резерва. Наличие цели
с дедлайном ≤ 6 мес **не** меняет сплит: обязательства и безопасность старше
желаний; цель либо закрывается разовым ходом из избытка (если он есть), либо
сдвигается. Единственное, что цель меняет, — мою уверенность (−1, зона
конфликта).

**В3. Крупные доходы.** Правило остаётся относительным (месяцы burn) без
абсолютного капа. Обоснование: (а) расходы масштабируют риски; (б) каскад сам
выталкивает всё сверх целевого резерва в разовые инвестиции — «мёртвого кэша»
модель не порождает; (в) относительность даёт масштабную инвариантность —
портрет ×k обязан получать ответ ×k, это свойство я считаю обязательным для
любой вменяемой методологии. Цена позиции: при доходе 10⁹ ₽/мес мои советы —
формально корректная экстраполяция, а не банковская практика (таких клиентов
обслуживают family office); это отражено в уверенности (−1), не в правилах.

**В4. Порог токсичности.** Двухкритериальный: `ставка ≥ 40%` годовых **или**
`спред к r_bench ≥ 25 пп`. Абсолютная компонента — потому что выше 40% долг
разрушает бюджет при любом мыслимом бенчмарке; спредовая — потому что при
бенчмарке 15% долг под 41% и долг под 39% не различаются по существу, и честнее
мерить расстояние до безрисковой альтернативы. Порог «дорогого» долга — спред
6 пп: ниже него досрочное гашение проигрывает простому депозиту с учётом
опционной ценности ликвидности. Растущий долг эскалируется на класс вверх
независимо от ставки.

**В5. Длинные цели.** Ответ в §7: дорогой долг (спред ≥ 6 пп) старше пенсии на
25 лет — три года лавины стоят дешевле, чем 25 лет параллельного донорства
кредитору; дешёвый долг младше любой цели. Пенсионная цель финансируется по
`required = gap/months` как обычная цель, без спецрежима; бессрочная цель ==
горизонт 10 лет.

**В6. Уверенность против расхождения.** Мои «пятёрки» — классы с одним
доминирующим приоритетом: жёсткая битость; глубокий дефицит; токсичный долг
(гасить, вопрос только чем); полный резерв без долгов (раздача в цели/инвестиции);
ровно нулевой поток. В этих зонах я жду наибольших расхождений с алгоритмом
при наименьших расхождениях между экспертами: живой эксперт в очевидной зоне
действует **лексикографически** (вся масса — в доминанту), а скоринговые модели
и там продолжают взвешенно размазывать поток по корзинам. Такое расхождение
не лечится сдвигом порогов — оно про форму решающего правила (argmax против
смеси), и именно его я предсказываю как главный источник инверсии
«уверенность↑ — согласие↓».
