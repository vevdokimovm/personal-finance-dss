# Агрегированный отчёт — распределение рекомендаций по 12 000 портретам

**Эксперт:** независимый специалист по личным финансам, РФ, 2026 (слепое ревью).
**Движок:** `advisor_engine.py` (детерминированный, PEP 8, ООП). **Дата среза:** 2026-07-11.

## Методология и константы (зафиксированы ДО обработки данных)

Среда: ключевая ставка высокая (r_bench в данных 10–20%), поэтому управляющий арбитраж —
**гасить кредит досрочно только если его ставка выше безрисковой (r_bench)**; иначе деньги
выгоднее держать на депозите под r_bench.

| Константа | Значение | Обоснование |
|---|---|---|
| Целевая подушка (мес. полного оттока = расходы + обслуживание долга) | rt1:6, rt2:6, rt3:5, rt4:4, rt5:3 | Толерантнее к риску → тоньше подушка |
| Стартовый минимум подушки (floor) | 1 мес. оттока | Ликвидная безопасность до всего остального |
| «Дорогой»/погашаемый долг | ставка > r_bench + 0.0 | Гарантированная доходность от досрочного погашения > депозита |
| Порядок гашения дорогих долгов | по убыванию ставки (avalanche) | Максимум сэкономленных процентов |
| Разовое закрытие цели из подушки | дедлайн ≤ 12 мес. и хватает излишка | Близкие почти-закрытые цели |
| Доля акций по риск-профилю (концептуально) | rt1:0.10 … rt5:0.85 | Инструменты по горизонту/риску |

**Водопад свободного потока (FCF > 0):**
стартовый минимум подушки (1 мес.) → дорогие долги (avalanche, пока хватает потока) →
добор подушки до целевой → цели под дедлайн (требуемый месячный взнос = разрыв / мес. до
дедлайна; просрочка → добор за 1 мес.) → остаток в инвестиции.

**Разовые ходы (lump) из подушки:** развёртывается только излишек `bliq − целевая_подушка`
(если > 0 и доход > 0). Порядок: погашение дорогих долгов → закрытие близкой почти-готовой
цели → размещение остатка в инвестиции. Для дефицитных клиентов из излишка гасится **только
долг** (делеверидж), без инвестиций. Нулевой доход → lump = 0 (сохраняем «взлётную полосу»).

**Обработка граничных веток:** нулевой доход и FCF<0 → `deficit`, бакеты 0; подушка < целевой
→ весь поток в резерв; перефинансированные цели → взнос 0; цели без дедлайна → финансируются
из остатка после дедлайн-целей; экстрим-масштаб → правила линейны и масштаб-эквивариантны
(×k на входе → ×k на выходе).

## Контроли (методичка §5, п. 4–5)

- **Сохранение сумм:** `res + debt + goal + inv ≤ ⌊FCF⌋` для всех ok; дефицитные — все бакеты 0.
  **Нарушений: 0 из 12 000.** Разовые ходы не превышают развёртываемый излишек.
- **Отрицательные бакеты:** 0.
- **Сверка JSONL ↔ .md:** совпадение на SP-00000, SP-05000, SP-11999.
- **Детерминизм:** правила и константы одинаковы для всех портретов; обработка полная
  (все 12 000, не выборка).
