# Методология независимого эксперта — раунд 2 (12 000 портретов)

**Дата среза:** 2026-07-11. Константы зафиксированы ДО обработки данных и применены
детерминированно и одинаково ко всем 12 000 портретам. Движок: `expert_engine.py`.

## Базовые определения

- Свободный поток: `FCF = income_total − expense_total − Σ monthly_payment`.
- `status = ok` при FCF ≥ 0, иначе `deficit`.
- Обязательный месячный отток: `essential = expense_total + Σ monthly_payment`.
- ПДН = Σ платежей / доход (при доходе 0 и платежах > 0 — ∞).

## Разовые ходы (lump), статус ok

1. Из подушки **сверх 1 × essential** гасим токсичные долги (полностью или частично).
2. **Излишек сверх целевой подушки** разворачиваем целиком, если он материален:
   сначала в «дорогие» долги, затем в дефициты целей по близости дедлайна, остаток —
   в инвестиции по риск-профилю. lump = п.1 + п.2, всегда ≤ bliq.

## Разовые ходы (lump), статус deficit

Жадно закрываем кредиты **целиком** по убыванию (платёж / остаток) — максимум
месячного облегчения на рубль. Ход засчитывается только если в итоге FCF′ ≥ 0 **и**
остаётся ≥ 1 × essential′ подушки; иначе lump = 0 (кэш — runway; частичное гашение
платёж не снижает). Месячные бакеты при дефиците — нули, dom = none.

## Месячный водопад (ok), бюджет = ⌊FCF⌋

1. Стартовая подушка до 1 × essential.
2. Токсичный долг — весь остаток потока (до остатка тела).
3. Карв 40% остатка — цели с дедлайном (взнос цели = дефицит / месяцев до дедлайна).
4. «Дорогой» долг — 60% остатка (до остатка тела).
5. Подушка до целевой.
6. Добор целей до суммарного требуемого взноса (включая бессрочные, горизонт 60 мес).
7. Остаток — инвестиции (инструментовка по риск-профилю — за рамками CSV).

`dom` = максимум из {debt, res, goal+inv}, тай-брейк debt → reserve → goals+;
`none` при дефиците или нулевых бакетах.

## Контроль сохранения сумм и сверка

- ok: Σ(res, debt, goal, inv) ≤ FCF; deficit: Σ = 0; lump ≤ bliq.
  **Нарушений: 0 из 12 000.** Средняя утилизация потока при FCF ≥ 1 ₽: 99.9%.
