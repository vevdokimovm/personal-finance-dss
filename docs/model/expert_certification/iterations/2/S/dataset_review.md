### (ж) Проблемы P1…P9 (с числовыми доказательствами)

**P1. Бенчмарк дискретен.** `r_bench` принимает ровно 5 значений (10.00 / 12.81 / 14.00 /
15.96 / 20.00%) по ~2 400 записей каждое — прямое нарушение требования методички
(«бенчмарк непрерывный, не дискретный»). Последствие: ось спреда «ставка − бенчмарк»
тестируется в 5 точках; поведение порогов дорогого долга между ними не покрыто.

**P2. Слой D (validity/adversarial) отсутствует.** Битых записей 0: нет NaN,
отрицательных сумм, битых дат, дублей id, пустых обязательных полей (заявлено ~5%,
т.е. ~600 записей). Последствие: устойчивость модели к мусору не тестируется вообще.

**P3. Слой E (метаморфические пары) отсутствует.** Глобальный поиск пар с
×k-масштабированием всех денежных полей и точных структурных дублей дал 0 кандидатов.
Последствие: свойства M1–M5 (монотонность по доходу/ставке/дедлайну/подушке,
масштабная инвариантность) проверить нечем — а это самый дешёвый детектор багов,
не требующий разметки.

**P4. Цели оторваны от дохода.** corr(income, Σ target) = 0.04 Pearson (ядро) /
0.09 Spearman (весь сет) при требовании методички «target ~ k × годовой доход»;
10.1% целей вне заявленного k ∈ [0.2…5] (p99 = 5.0, max = 12.1). Последствие:
доминируют комбинации «цель 1.7 млн при доходе 30 тыс.», и тест достижимости целей
смещён в сторону заведомо недостижимых.

**P5. Горизонты дедлайнов обрезаны.** Максимум 58.8 мес при заявленных «от 3 мес. до
10 лет»; страта >60 мес пуста (p90 = 52.9). Последствие: ветки длинных горизонтов
(выбор инструментов, дисконтирование) не покрыты.

**P6. Interest-only фактически не представлен, аннуитет не везде согласован.**
Interest-only (платёж ≈ проценту): 3 шт.; растущий долг (платёж < процента): 25 шт. —
итого 0.2% кредитов при явном пункте каталога слоя C. Имплицитный аннуитетный срок
вне [6, 360] мес — 76 кредитов (в т.ч. срок < 1 мес: платёж кратно превышает остаток);
срок «похож на целый» лишь у 87.6% (заявлена 100% согласованность вне слоёв C/D).

**P7. Смесь не лог-нормальна — приёмочный KS-тест методички невыполним на полном сете.**
KS для log(income) по ядру: D = 0.201, p ≈ 0; skew(log) = −4.28, kurt = 22.6 (тяжёлый
левый хвост от DOE-слоя и нулевых доходов). Последствие: критерий «KS p > 0.05» из §3
методички осмыслен только по-слойно, но слоевых меток в выгрузке нет (см. P9).

**P8. Недостающие точки каталога граничных случаев.** `target == current` в копейку —
0 записей (перефинансированных при этом 286); `bliq == 0` — нет (минимум 1 ₽,
ровно 1 запись); `FCF == 0` точно — 0 записей. Ветки «цель закрыта в копейку»,
«нулевая подушка», «нулевой поток» не покрыты.

**P9. Гигантский блок без меток обесценивает агрегаты.** 285 записей с суммами до
1.3×10¹¹ ₽ дают mean(income) = 59 млн при медиане 71.7 тыс. — любые моменты полного
сета бессмысленны без стратификации. Слепота эксперта по `kind` — законный протокол,
но у координатора должен существовать манифест слоёв, чтобы приёмочные тесты и ревью
шли по-слойно, а не по смеси (сейчас слои реконструируются только эвристикой).

### (з) Рекомендации для следующей итерации генератора

1. `r_bench` — непрерывный (лог-нормаль/треугольное в коридоре 8–24% с якорями
   ключевой ставки) либо сетка ≥ 25 значений; в приёмку — тест числа уникальных значений.
2. Добавить слой D (~5%) с манифестом ожидаемых отказов и слой E с парным манифестом
   id ↔ id+δ по M1–M5 — это главный бесплатный детектор багов модели.
3. Дедлайны растянуть до 120 мес; отдельная страта > 60 мес; долю null держать явной
   константой конфига (сейчас 24% — ок, но не задокументировано).
4. Вернуть копульную связь целей с доходом в слое A (k ∈ [0.2…5] как маргинал
   при условии дохода); DOE-независимость осей оставить только слою B; долю k вне
   диапазона — в приёмочный тест (§3 п.6).
5. Дополнить каталог C: `target == current` точно, `bliq = 0`, `FCF = 0`,
   interest-only блок ~1% кредитов, растущий долг как явный подслой.
6. Починить 76 кредитов с имплицитным сроком < 6 мес (платёж кратно больше остатка) —
   либо явно пометить их слоем C как «досрочно доплаченные».
7. Приёмочные тесты §3 гонять по-слойно по манифесту; KS/корреляции на смеси не
   осмысленны (см. P7, P9).
