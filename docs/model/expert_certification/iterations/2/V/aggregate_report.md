# Методология независимого эксперта — раунд 2 (12 000 портретов)

**Дата среза:** 2026-07-11. Все суммы — ₽, потоки — месячные, ставки — годовые.
Методология зафиксирована ДО обработки данных. Правила детерминированные, единые для всех портретов, обработка программная и полная (`expert_engine.py`).

## 1. Базовые определения

- Свободный поток: `FCF = income_total − expense_total − Σ monthly_payment`
- Месячное сжигание: `burn = expense_total + Σ monthly_payment`
- Запас ликвидности: `L = bliq / burn` (мес.)

## 2. Константы (профессиональное суждение эксперта)

| Параметр | Значение | Обоснование |
|---|---|---|
| Минимальная подушка `L_min` | 1 × burn | стартовый резерв до любых манёвров |
| Целевая подушка `L_target` | риск 1→6, 2→5, 3→4, 4→3, 5→3 мес × burn | консервативным — больший буфер |
| «Дорогой» долг (гасить досрочно) | ставка ≥ r_bench + 2 п.п. | +2 п.п. компенсируют НДФЛ на депозитный доход и потерю ликвидности; ниже — арбитраж в пользу вклада (в т.ч. льготные ипотеки не гасим) |
| «Токсичный» долг | ставка ≥ r_bench + 15 п.п. или ≥ 35% абс. | МФО/карты — гасить даже в ущерб подушке (до L_min) |
| Защита целей при долгах | только дедлайн ≤ 12 мес, ≤ 30% FCF | ближние обязательства не срываем, дальние — на паузу до выхода из дорогих долгов |
| Lump-цели | дедлайн ≤ 24 мес | разово закрывать из излишка только близкие цели |
| Мин. лот разового размещения | 10 000 ₽ | пыль не размещаем |
| r_bench по умолчанию (если поле битое) | 0.13 | ориентир безрисковой ставки, середина 2026 |

## 3. Месячный каскад (FCF > 0), суммы целые, `res+debt+goal+inv = ⌊FCF⌋`

**A. Кризис ликвидности (`bliq < L_min`):** цели и инвестиции = 0.
- есть токсичный долг → 50% резерв / 50% долг;
- есть дорогой (не токсичный) → 70% резерв / 30% долг;
- долгов дорогих нет → 100% резерв.

**B. Есть дорогой долг (`bliq ≥ L_min`):** инвестиции = 0.
- резерв: 10% FCF, если `bliq < L_target`, иначе 0;
- цели: `min(Σ требуемых взносов по целям с дедлайном ≤ 12 мес, 30% FCF)`;
- долг: весь остаток (доминанта), порядок гашения — «лавина» (по убыванию ставки).

**C. Дорогих долгов нет:**
- резерв: `min(30% FCF, L_target − bliq)`;
- цели: требуемые взносы по всем целям с дедлайном (`need / max(1, мес. до дедлайна)`, просрочка → 1 мес), кап — остатком потока;
- остаток: при наличии недофинансированных бессрочных целей — 50/50 цели/инвестиции, иначе 100% инвестиции.

Требуемый взнос по цели: `max(0, target − current) / max(1, (deadline − today)/30.44)`.

## 4. Разовые ходы (`lump`)

- **FCF > 0:** развёртываемый излишек = `bliq − L_target` (при токсичном долге допускаю проседание до `L_min`, но только под гашение долга). Порядок: (1) досрочно закрыть дорогие долги (до суммы их тел), (2) закрыть дефицит целей с дедлайном ≤ 24 мес, (3) остаток ≥ 10 000 ₽ — разово разместить в инструменты по риск-профилю. `lump` = сумма всех трёх.
- **FCF ≤ 0 (deficit):** `lump = min(max(0, bliq − L_min), Σ тел дорогих долгов)` — гашение дорогих долгов сокращает burn и может вернуть поток в плюс. Ниже L_min подушку не трогаем, дешёвые долги из подушки в дефиците не гасим (съедает runway).

## 5. dom и status

- `status = deficit`, если FCF < 0; иначе `ok`.
- `dom` = наибольший бакет из {debt, reserve, goals+ (goal+inv)}; при равенстве приоритет debt > reserve > goals+; при FCF ≤ 0 или нулевом распределении → `none`.

## 6. Санитизация битых записей (консервативно, без падений)

- `income`/`expense` невалидны (NaN/отрицательные/нечисло) → запись неоцениваема → `deficit,none,0,0,0,0,0`;
- `bliq` невалиден → 0; `r_bench` вне (0;1) → 0.13; `risk_tolerance` вне 1–5 → 3;
- кредит: битый платёж → 0 в FCF; битые ставка/тело → исключён из кандидатов на досрочное гашение;
- цель: битый target → цель игнорируется; битый current → 0; нечитаемая дата → бессрочная;
- дубликаты id обрабатываются построчно (одна строка входа = одна строка выхода).
