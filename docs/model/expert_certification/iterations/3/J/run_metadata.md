# Метаданные прогона — экспертная оценка v3

## Модель и инструменты

- Эксперт-модель: Claude (Anthropic), веб-интерфейс claude.ai со средой
  выполнения кода.
- Обработка: детерминированный Python 3.12-скрипт (только stdlib:
  json/gzip/csv/datetime/math/statistics). Ответы по записям не назначались
  вручную — ни одна строка CSV не написана «руками».
- Скрипты приложены: `expert_engine.py` (движок распределения),
  `audit_pass1.py`, `audit_pass2.py` (статистический аудит датасета).

## Дата и длительность

- Дата прогона: 2026-07-17 (дата среза дедлайнов в расчётах — 2026-07-16,
  по мета-строке датасета).
- Чистое время движка по 12 000 строк: ~0.5 с. Полный цикл сеанса
  (структурный скан → фиксация методологии → движок → верификация →
  статистический аудит → сверка карточек → отчёты): в пределах одного
  сеанса, ориентировочно 30–60 минут.

## Полнота

- Обработаны **все 12 000 входных строк** (4 файла × 3000 данных; 4
  мета-строки пропущены по инструкции). Подвыборка не использовалась.
- Ровно одна строка ответа на каждую входную строку, порядок входа сохранён
  (part1 → part4, внутри файла — построчно). Оба экземпляра каждого из 50
  дублей `id` получили независимые ответы.

## Способ обработки

1. Структурный скан схемы и дефектов (типы полей, счётчики аномалий).
2. Фиксация методологии и констант до прогона — `expert_methodology_v3.md`.
3. Прогон движка → `expert_allocations_v3.csv` (12 000 строк + шапка).
4. Независимая верификация выхода вторым скриптом.
5. Статистический аудит датасета → `dataset_review.md`.
6. Сверка JSONL ↔ карточки на 3 случайных портретах.

Денежная арифметика статуса — в целых копейках (устранение двоичного
float-шума на граничном слое «поток = 0»).

## Контрольные проверки выхода (нарушений — 0)

| Контроль | Результат |
|---|---|
| Строк данных в CSV | 12 000 + шапка |
| `res+debt+goal+inv ≤ F` для всех `ok` | 0 нарушений; для F > 0 сумма = ⌊F⌋ (полное распределение потока, точность до ₽) |
| `lump ≤ bliq` | 0 нарушений |
| `status` ↔ знак потока (в копейках) | 0 расхождений |
| `dom` — независимый пересчёт | 0 расхождений |
| Дефицит/invalid: месячные бакеты = 0, `dom = none` | выполнено |
| Сверка карточек (3 случайных портрета) | 3/3 полное совпадение |
