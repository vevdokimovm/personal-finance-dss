# Метаданные прогона — раунд 3 (датасет v3)

- **Модель/эксперт:** Claude (Anthropic, семейство Claude 5), сессия claude.ai
  с песочницей Python.
- **Инструменты:** Python 3.12 (stdlib: json, gzip, csv, datetime, math, re) —
  движок решений; pandas 3.0.2 / numpy 2.4.4 / scipy 1.17.1 — статистический аудит.
  Файлы кода приложены: `engine.py` (движок), `dataset_analysis.py` (аудит).
- **Дата обработки:** 2026-07-17, 04:59–05:06 UTC. Длительность полного цикла
  (методология → движок → прогон → верификация → аудит) ≈ 7 минут машинного
  времени; сам прогон 12 000 записей — секунды (потоковая обработка).
- **Полнота:** обработаны **все 12 000 записей** всех четырёх частей, без
  подвыборок. Мета-строки (4 шт.) пропущены по протоколу. Одна строка ответа на
  каждую входную строку, порядок входа сохранён (верифицировано программно 1:1
  по id и позиции); 50 дублей id получили по отдельному ответу каждый.
- **Способ обработки:** полностью программный (скрипт), без ручной обработки
  записей. Методология и константы зафиксированы в `expert_methodology_v3.md`
  **до** прогона данных (временные метки файлов это отражают); решения по всем
  записям приняты единым детерминированным алгоритмом.
- **Верификация:** нарушений инварианта `res+debt+goal+inv ≤ поток` — 0;
  нарушений согласованности `dom` с бакетами — 0; расхождений порядка/ID — 0;
  выборочная ручная сверка расчётов на SP3-00000 и SP3-00001 — совпадение до рубля;
  сверка JSONL ↔ карточки на 3 случайных портретах — совпадение.
- **Независимость:** методология построена из общей практики личного финансового
  консультирования (подушка 3–6 мес., спреды к безрисковой ставке, каскад
  долги → резерв → цели → инвестиции); никакие описания тестируемого алгоритма,
  проектные документы или ожидания заказчика при построении правил не
  использовались и в сессию не загружались.
- **Итоговое распределение:** ok — 7198, deficit — 4252, invalid — 550;
  dom: debt — 3651, reserve — 1837, goals+ — 1637, none — 4875
  (дефицит + invalid + 73 записи с потоком < 1 ₽); записей с lump > 0 — 5191.
