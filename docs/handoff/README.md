# Передачи вахты

Сюда кладутся **только** документы передачи между сессиями и аккаунтами — по одному на дату.
Имя: `HANDOFF_<ГГГГ-ММ-ДД>[_<время суток>].md`.

Заведено 18.09.2026 по требованию владельца: до этого файлы падали в корень `docs/`
и тонули среди трёх десятков рабочих документов.

**Что обязан нести файл передачи:**
1. где стоим — очередь, что закрыто, что в работе прямо сейчас;
2. канонический порядок работ (его легко сломать, и его уже ломали);
3. правила, установленные владельцем, с датой и дословной цитатой;
4. дефекты и долги, которые нельзя потерять;
5. что ждёт владельца — деньги, ключи, логины;
6. обстановка и техника: сеть, лимиты, VPN, известные помехи;
7. первое действие новой вахты, одной строкой.

Актуальная передача — та, у которой позже дата в имени. Старые не удаляются:
по ним видно, как менялось состояние проекта.
