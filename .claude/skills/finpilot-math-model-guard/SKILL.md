# Канон матмодели — только v3.0.0

Авторитет — `docs/math_model_v3_0_0.md` и код. Не память, не инструкции, не прошлые чаты.
Разночтения между кодом и текстом ВКР ведутся в `docs/model/model_history.md`.

## Опорные факты

**Ликвидность `Lt`** — stock-based, месяцы автономии: `Lt = B_liq / Σe`.
Ортогональна ресурсу. Это не поток.

**Ресурс `Rt`** — поток: `Rt = CF − ΣP`. Баланс `Bt` в ресурс **не входит**.

**Альтернативы:** `|A| = 66`, шаг дискретизации 10%.

**`r_bench`** — динамический: ключевая ставка ЦБ × (1 − НДФЛ). Фолбэк 0.14 при
недоступности источника. В проде — зеркало `cbr-xml-daily.ru`: `cbr.ru` отдаёт 403
датацентровым адресам, это защита от нагрузки, а не баг.

**Доверительный интервал прогноза — 80%** (p10–p90).

**Жёсткие инварианты:** `Rt >= 0` и `ПДН <= 0.40`. Только эти два.
Отсев по ликвидности мягкий: `L_min = 0`, по умолчанию выключен.

## Запрещённая legacy v2.x

Если в коде или обсуждении всплыло что-то из этого списка — это ошибка, а не альтернативный
подход:

| Устаревшее v2.x — не использовать | Канон v3.0.0 |
|---|---|
| v2.x: `Lt = Rt / (Σe + ΣP)`, flow-based — устарело | `Lt = B_liq / Σe`, stock-based |
| v2.x: `\|A\| = 21`, шаг 20% — устарело | `\|A\| = 66`, шаг 10% |
| v2.x: CI 95% интервал — устарело | CI 80% (p10–p90) |
| v2.x: `L_min = 0.30` жёстко — устарело | `L_min = 0`, мягко, выключен |
| v2.x: `r_bench = 0.14` статично — устарело | Динамический от ключевой ставки |

`v2.0.2` — исторический документ ВКР, не источник для кода.

## Веса целей

Немонотонны нестрого: между профилями 2 и 3 плато на 0.20. В тестах сравнивать
нестрого — строгое сравнение даст ложное падение.
