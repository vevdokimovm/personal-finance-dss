# Публичные release notes зеркала `finpilot` (private-only источник)

> **Что это.** Тексты релизов ПУБЛИЧНОГО зеркала. Публикатор
> (`finpilot_publish_public.sh`, фаза `publish_release`) берёт секцию `## [X.Y.Z]`
> отсюда; если секции нет — генерирует нейтральную заготовку. Приватные
> `CHANGELOG.md`/`docs/WATCHLOG.md` в паблик-описания НЕ попадают никогда:
> там внутренняя кухня (вахты, аккаунты, процесс).
>
> **Правила текста.** Пишем ДЛЯ публики: продукт и инженерия, без имён, без
> процесса, без «вахт/аккаунтов/Claude». Перед публикацией текст проходит
> `guard_notes` — совпадение с приватными паттернами роняет публикацию.
> Сам этот файл наружу не уходит (deny-list по имени).
>
> **Формат секции** (как в CHANGELOG): `## [X.Y.Z] — заголовок`, дальше тело
> в Markdown. Заголовок попадает в имя релиза: `FINPILOT vX.Y.Z — заголовок`.
