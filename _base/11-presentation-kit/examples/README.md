# examples — рабочие примеры визуала

🔴 **Не иллюстрации к тексту, а проверенные запуском артефакты.** Каждый
собран командой из `DIAGRAMS.md` 04.09.2026 и просмотрен глазами.

| Файл | Чем собран | Проверяет |
|---|---|---|
| `pipeline.svg` | написан как код, 851 байт | 🔴 **кириллица на схеме точная** — то, чего не даёт генерация растра |
| `pipeline.png` | `rsvg-convert -w 1200` | SVG → PNG локально, без сети |
| `progress-frame.svg` | кадр гифки, 412 байт | кадр анимации — тоже код |
| `progress.gif` | `ffmpeg` + `palettegen` | сборка GIF из кадров, 3 кадра / 6 040 байт |

**Зачем примеры лежат в репе.** Документ, обещающий работающую команду,
проверяется только запуском; артефакт рядом с командой доказывает, что она
отработала **на этой машине**, а не в общем случае. Пример дороже описания:
следующая вахта скопирует его и получит результат, а не будет выяснять,
почему `marker-end` ставится не там.

🔴 **Вес держится в границах** (`06-volume-compression.md`: картинка в репе
≤ 0.5 МБ). Здесь суммарно **19 КБ** — потому что всё, кроме `.png` и `.gif`,
это текст.
